# 快速排序

**快速排序**（Quick Sort）是一种**原地**（in-place）分治排序算法。它通过选择一个**基准**（pivot）元素，将数组划分为两个子数组，使得左侧所有元素 ≤ 基准 ≤ 右侧所有元素，然后递归地对两个子数组进行排序。

# 核心步骤（[[分治]]三阶段）
| 阶段     | 动作            | 说明                                             |
| :----- | :------------ | :--------------------------------------------- |
| **分解** | 分区（Partition） | 选取基准元素，重新排列数组，返回基准元素的最终索引位置，使得左子数组 ≤ 基准 ≤ 右子数组 |
| **解决** | 递归排序          | 对基准左侧和右侧的子数组分别递归调用快速排序（基线条件：子数组长度 ≤ 1）         |
| **合并** | 无需合并          | 由于是原地排序，子数组在递归完成后整体自然有序（这是与归并排序最大的不同）          |

# 伪代码

输入：A数组vector，p=数组最左边的下标，r=数组最右边的下标
输出：排好序的数组A


```
  算法 Quicksort(A, p, r)
  1.  if p < r then
  2.      q ← Partition(A, p, r)     // 划分，q 是枢轴最终位置
  3.      A[p] ↔ A[q]               // 把枢轴放到正确位置
  4.      Quicksort(A, p, q-1)       // 递归左半
  5.      Quicksort(A, q+1, r)       // 递归右半
```

输入：A数组vector，p=数组最左边的下标，r=数组最右边的下标
输出：j，A的首元素排号序后所在的位置

```

  Partition(A, p, r)
  1.  x ← A[p]          // 选首元素为枢轴
  2.  i ← p
  3.  j ← r+1
  4.  while True do
  5.      repeat j ← j-1 until A[j] ≤ x    // j 从右往左，找比 x 小的
  6.      repeat i ← i+1 until A[i] > x    // i 从左往右，找比 x 大的
  7.      if i < j
  8.          then A[i] ↔ A[j]             // 交换这对错位元素
  9.      else return j                    // 指针交叉，划分结束

```

一次排序结束后：
p——j-1就是比基准元素小的子数组；j就是当前排序的基准元素；j+1——r就是比基准元素大的子数组

随后再对左子数组和右子数组递归排序

# 一次排序的具体示例

  A = \[27, 99, 0, 8, 13, 64, 86, 16, 7, 10, 88, 25, 90]
        ↑                                  ↑            ↑
        i=p=1                             ...        j=r+1=14

  枢轴 x = 27

  第 1 轮扫描：
    j 左移：90...25  停在 25（≤27）
    i 右移：99       停在 99（>27）
    交换 → \[27, 25, 0, 8, 13, 64, 86, 16, 7, 10, 88, 99, 90]

  第 2 轮扫描：
    j 左移：88,10    停在 10
    i 右移：0,8,13,64 停在 64
    交换 → \[27, 25, 0, 8, 13, 10, 86, 16, 7, 64, 88, 99, 90]

  第 3 轮扫描：
    j 左移：7         停在 7
    i 右移：86,16     停在 86
    交换 → \[27, 25, 0, 8, 13, 10, 7, 16, 86, 64, 88, 99, 90]

  第 4 轮扫描：
    j 左移：16        停在 16
    i 右移：86        停在 86
    i > j → 交叉！返回 j=8

  最后：A\[1] ↔ A\[8]
        \[16, 25, 0, 8, 13, 10, 7,  27, 86, 64, 88, 99, 90]
                            ↑ 枢轴 27 在最终位置
        左半都 ≤ 27               右半都 ≥ 27

这是一轮排序，再次对左右子数组排序
