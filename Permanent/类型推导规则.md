# 核心

类型推导（Type Inference）的核心，就是让[[编译器]]帮你“猜”出变量或表达式的类型，让你在编写代码时，可以写出 `x = 5` 这样简洁的语句，而不必每次都繁琐地声明 `int x = 5`


# 符号规则：

#### `Γ`：类型环境

它是一个从变量名到其类型映射的上下文，在编译器里就是[[符号表]]。例如 `Γ = { x: int, b: bool }` 表示在环境 `Γ` 中，变量 `x` 是整数类型，`b` 是布尔类型。

类型环境的操作：
- 查表，Γ（x）：返回 x 的类型（若 x 不在 Γ 中则为未定义）
- 扩展，Γ, x : T：在 Γ 中新加入变量 x 的类型 T（用于处理局部变量或函数参数）
- 收缩：去掉某个变量的类型
- 替换，Γ(T/x)：对 Γ 中所有**自由出现**的 `x`（作为类型变量，表示一类类型）进行替换为类型T后的新环境。
	注意：Γ\[T/x\](y)也就等于Γ(y)

#### `⊢`：推断符号

读作“**可以推导出**”，它连接了环境 `Γ` 和要判断的表达式 `e`，如 `Γ ⊢ e : T` 表示“在环境 `Γ` 下，**可以推导出**表达式 `e` 具有类型 `T`。

#### `e : T`：类型断言

这是整个系统的核心判断形式，表明程序实体 `e` 拥有类型 `T`。比如 `x : int` 断言变量 `x` 是整数类型。

### `∧`: 逻辑与

表示前后两个表达式通过逻辑与连接在一起

### `→`: 蕴含符号 
`P → Q` 读作 **“如果 P 则 Q”** 或 **“P 蕴含 Q”**


# 推导规则

### （e<sub>1</sub>：int ∧ e<sub>2</sub>：int）→e<sub>1</sub>+e<sub>2</sub>：int
