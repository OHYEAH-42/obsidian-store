# 什么是未初始化内存泄露

**未初始化内存泄露**（Uninitialized Memory Disclosure）是程序把未正确初始化的内存暴露给不应读取它的主体，使旧数据或其他敏感内容被观察到的缺陷。物理页在进程之间复用时，若没有在交付前正确初始化，即使新旧进程的页表从未同时共享该页，也可能发生泄露。[[内存清零]]是防止这类跨进程残留泄露的一种措施。
