# 什么是LLM的模型训练

**LLM 的模型训练**是利用数据和训练目标，学习或调整[[大语言模型|LLM]]参数，使模型获得语言能力并适应目标任务的过程。它属于[[模型训练]]，通常可以围绕[[预训练]]和[[后训练]]两个阶段理解。

- **[[预训练]]**：在大规模语料上学习可复用的语言表示和知识。常见生成式 LLM 使用预测下一个词元的自监督目标，训练后得到可作为后续训练起点的基座模型。
- **[[后训练]]**：在预训练模型基础上继续训练，改善指令遵循、对话行为、人类偏好和特定能力。常见方法包括用示范回答进行[[监督微调|SFT]]，以及利用反馈或奖励进行进一步优化。

一条常见的训练主线是：**预训练 → 基座模型 → 后训练 → 面向使用需求的模型**。后训练中的具体方法和顺序由训练方案决定，可以包含多个步骤和多轮迭代。

两个阶段都通过训练调整模型参数，主要区别在于数据、目标和所希望形成的能力。预训练与后训练共同影响最终表现，不能简单理解为前者只学知识、后者只学回答格式。

参考：[The Llama 3 Herd of Models，§2、§3、§4](https://arxiv.org/html/2407.21783v3#S2)。
