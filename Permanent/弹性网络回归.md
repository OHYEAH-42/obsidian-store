# 什么是弹性网络回归

**弹性网络回归**（Elastic Net）是在[[线性回归]]中同时使用 L1 与 L2 惩罚的[[正则化]]方法：

$$
\min_{\boldsymbol w,b}
\frac1n\sum_{i=1}^n(y_i-\boldsymbol w^{\mathsf T}\boldsymbol x_i-b)^2
+\lambda_1\sum_j|w_j|+\lambda_2\sum_jw_j^2
$$

其中 $n$ 为样本数，$\boldsymbol w,b$ 为参数，$\lambda_1,\lambda_2\ge0$ 分别控制 L1 与 L2 强度，此处不惩罚 $b$。它结合[[Lasso回归]]的稀疏性与[[岭回归]]的收缩作用；具体效果取决于两种惩罚的比例。

参考：[定义与公式来源](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.ElasticNet.html)。
