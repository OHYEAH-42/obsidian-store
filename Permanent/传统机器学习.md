# 什么是传统机器学习

**传统机器学习**通常指相对于现代深度学习而言，以线性模型、树模型、核方法、近邻方法和概率模型等为代表的一组方法。“传统”是习惯用语，没有统一、严格的数学边界，也不表示这些方法已经过时。

它不是一种独立的学习信号：这些方法可以用于[[监督学习]]、[[无监督学习]]，也可以组成半监督等学习流程。在许多结构化数据任务中，特征表示、模型选择与可靠评估都非常重要。

# 主要内容

以下是常见主干，不是一份穷尽所有方法的清单：

| 近邻方法     | [[最近邻方法]]                                         | [[kNN]]                       | 按相似样本进行分类或回归     |
| 间隔与核方法   | [[支持向量机]]                                         | [[SVM]]、[[核函数]]               | 线性或非线性分类，也可扩展到回归 |
| 概率模型     | [[朴素贝叶斯]]、[[高斯混合模型]]                              | [[GMM]]                       | 类别推断、数据分布建模与软聚类  |
| 树模型      | [[决策树模型]]、[[随机森林]]                                | 根据特征条件预测类别或数值                 |                  |

# 算法、策略与工具的关系

[[集成学习]]是组合多个模型的总体思路。Bagging、Boosting、Stacking 是不同的组合策略；随机森林、AdaBoost、GBDT 是相关的具体方法。[[自助采样]]是 Bagging 常用的数据重采样方式。

[[XGBoost]]、[[LightGBM]]、[[CatBoost]]是梯度提升相关的软件实现体系，各自提供训练机制和工程优化，不能简单理解为三种全新的学习范式。

[[逻辑回归]]通常完成分类，虽然名字含“回归”；SVM 和树模型则都可以有分类与回归版本。任务与模型不是一一对应关系。

# 配套基础与建模流程

掌握传统机器学习还包括以下内容：

- **数据表示**：[[特征工程]]、[[特征选择]]、[[标准化]]、[[独热编码]]。需要对距离或系数进行比较的方法，尤其要关注特征尺度。
- **概率与统计**：[[均值]]、[[方差]]、[[协方差]]、[[正态分布]]、[[贝叶斯定理]]、[[最大似然估计]]。
- **泛化与复杂度**：[[拟合]]、[[过拟合]]、[[欠拟合]]、[[正则化]]、[[偏差与方差]]。
- **开发与模型选择**：[[训练集]]、[[验证集]]、[[测试集]]、[[交叉验证]]和[[超参数]]。
- **评价与可靠性**：[[混淆矩阵]]、[[分类评价指标]]、[[回归评价指标]]与[[数据泄漏]]。

预处理、特征筛选和模型训练应作为完整流程评估。比如先用全部数据挑出“最相关”的特征，再划分测试集，会把测试信息带入建模过程。参考：[scikit-learn 常见陷阱](https://scikit-learn.org/stable/common_pitfalls.html)。

# 与深度学习的关系

传统方法常更多依赖显式构造或选择特征，[[深度学习]]则侧重通过多层网络学习表示；这只是常见差异，并非绝对边界。两类方法可以组合，例如先用神经网络提取向量，再用线性分类器或聚类方法处理。

数据规模、特征类型、任务指标、计算成本和可解释性需求会影响模型选择。可靠的比较需要相同的数据划分和评价规则，不能仅凭算法名字判断优劣。
