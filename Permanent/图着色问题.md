# 问题

给定无向图 $G = \langle V, E \rangle$ 和 $m$ 种颜色，问能否用这 $m$种颜色给每个顶点着色，使得相邻顶点颜色不同？
若问最少需要几种颜色 — 那就是[[图的色数问题]]。


# 回溯算法
## 分析

### 解向量：

$X = \langle x_1, x_2, ..., x_n \rangle$，$x_i \in {1, 2, ..., m}$ 表示顶点 $i$的颜色编号

### 搜索空间：

m叉树，每个顶点有 m 种颜色可选，$m^n$ 个叶子

### 约束条件（多米诺性质成立）

顶点 $i$ 选颜色 $x_i$ 时，只需检查它和已着色的相邻顶点颜色是否冲突：

对任意 $j < i$，若 $(i, j) \in E$，则 $x_i \neq x_j$

每个顶点的约束只依赖前面已确定的顶点，多米诺性质成立 ✓

## 算法

### 基本要素：

解向量及搜索空间：$X = \langle x_1, x_2, ..., x_n \rangle$，$x_i \in {1, 2, ..., m}$ 表示顶点 $i$的颜色编号
搜索空间：满m叉树

剪枝操作：第i个节点画上第$x_i$可行《\==》第i个结点有边相连的任何节点j满足$x_i≠x_j(1≤j<i)$

```
// m种颜色，n个顶点，图用邻接矩阵G表示
// G[i][j] = 1 表示顶点i+1与j+1相邻

void graphColor(int k) {
    if (k > n) {
          // 找到一个合法着色方案
          输出解 x[1..n];
          return;
      }

      for (int c = 1; c <= m; c++) {   // 尝试m种颜色
          x[k] = c;

          // 约束剪枝：检查与已着色的相邻顶点是否冲突
          bool ok = true;
          for (int j = 1; j < k; j++) {
              if (G[k][j] == 1 && x[k] == x[j]) {
                  ok = false;
                  break;
              }
          }

          if (ok) {
              graphColor(k + 1);       // 不冲突，继续下一顶点
          }
          // 冲突则自动回溯，尝试下一种颜色
      }
  }
```
