# 函数的渐近界

一共有五种符号：


| 记号      | 定义条件                 | 直观含义      | 极限判断            |
| ------- | -------------------- | --------- | --------------- |
| O(g(n)) | f(n) ≤ c·g(n) (n≥n₀) | 上界，阶不超过g  | lim f/g < ∞     |
| Ω(g(n)) | f(n) ≥ c·g(n) (n≥n₀) | 下界，阶至少为g  | lim f/g ≠ 0     |
| Θ(g(n)) | c₁g ≤ f ≤ c₂g        | 紧确界，阶恰好是g | lim f/g = c > 0 |
| o(g(n)) | ∀c, f(n) < c·g(n)    | 严格上界      | lim f/g = 0     |
| ω(g(n)) | ∀c, f(n) > c·g(n)    | 严格下界      | lim f/g = ∞     |



## O(g(n)) 

设 f(n)和g(n)均是从自然数集到非负实数集上的函数。如果存在常数c>0和一个自然数n0，使得对于任意的n<sub>0</sub>，均有 f(n) < cg(n), 则称 f(n) 的渐近的上界是 g(n)，记作f(n)=O(g(n))。 
- 含义：阶至多为g(n)的函数；上限 
- 读法：O(g(n))读作“大Ohg(n)” 
- 用法：若有lim<sub>n→∞</sub>      f(n)/g(n)<∞, 则有f(n)=O(g(n))

![[Pasted image 20260619174210.png|645]]

 ▎ O 是最常用的上界——我们说一个算法的时间是 O(n²)，意思是最坏情况下不会超过n²级别。


## Ω(g(n))

设f(n)和g(n)均是从自然数集到非负实数集上的函数。如果存在常数c>0和一个自然数n<sub>0</sub>使得对于任意的n<sub>0</sub>，均有 f(n) > cg(n), 则称f(n)的渐近的下界是g(n)，记作f(n)=Ω(g(n))。 
- 含义：阶至少为g(n)的函数；下限 
- 读法：Ω(g(n))读作“omegag(n)” 
- 用法：若有lim<sub>n→∞</sub>     f(n)/g(n)≠0,则有 f(n)= Ω(g(n))

![[Pasted image 20260619174910.png]]

 ▎ Ω 描述下界——一个问题被证明是 Ω(n log n)，意味着任何算法都至少需要n log n 级别的时间。


## Θ(g(n))

设f(n)和g(n)均是从自然数集到非负实数集上的函数。如果存在一个自然数n<sub>0</sub>和两个正常数c<sub>1</sub>，c<sub>2</sub>，使得对于任意的n >n<sub>0</sub> ， 均有 c<sub>1</sub>g(n) ≤ f(n) ≤ c<sub>2</sub> g(n), 则 f(n)=Θ(g(n))。 
- 含义：阶恰好为g(n)的函数； 
- 读法：Θ(g(n))读作“thetag(n)” 
- 用法：若有limn→∞f(n)/g(n)=c>0,则有f(n)= Θ(g(n))。

  ▎ Θ 是最精确的描述——说一个算法是 Θ(n²) 意味着无论最好最坏，精确就是 n² 级别。

# 最好/最坏/平均复杂度

以顺序检索为例子，在数组L中查找X：


```
  算法 Search(L, x)
  1.  j ← 1
  2.  while j ≤ n and x ≠ L[j] do j ← j+1
  3.  if j > n then j ← 0
  4.  return j
```

基本运算： L\[x]≠L\[j]

| 情况      | 含义             | 比较次数                    | 渐近   |
| ------- | -------------- | ----------------------- | ---- |
| 最好 B(n) | x 恰好在 L\[1]    | 1                       | Θ(1) |
| 最坏 W(n) | x 不在数组中        | n                       | Θ(n) |
| 平均 A(n) | x 在每位等概出现（1/n） | (1+2+...+n)/n = (n+1)/2 | Θ(n) |


三个概念的精确定义

B(n) = 对规模为 n 的所有实例，基本运算的 最少 执行次数
W(n) = 对规模为 n 的所有实例，基本运算的 最多 执行次数
A(n) = 对规模为 n 的所有实例，按概率分布的 加权平均 执行次数


# 分析复杂度的主要步骤

1.  选取基本运算     (最为关键)
2.  统计基本运算频数    （三种方法）
3.  渐近表示结果            （O/Ω/Θ） 


## 选取基本运算

定义：执行频数最高（相差常数因子意义上）的元运算。

  元运算：时间耗费不超过某常数的基本操作——加、减、乘、除、比较、赋值、指针赋值。

  选取原则：

| 算法类型  | 基本运算选什么 |
| :---- | :------ |
| 排序、查找 | 元素的比较   |
| 矩阵乘法  | 数的乘法    |
| 链表遍历  | 指针赋值/更新 |
| 图遍历   | 访问结点的操作 |

## 统计基本运算频数

1. 直接数循环
```
  for i ← 1 to n
      for j ← 1 to n
          count ← count+1      // 执行 n² 次
```
基本运算执行 n² 次

2. 建立递归方程
例如：归并排序：
W(n) = 2W(n/2) + n-1,  W(1) = 0
解出：W(n) = n·log n - n + 1

3. 平摊分析（适用于操作序列，单次操作代价波动大）


## 渐进表示

把频数 f(n) 化简为 O / Ω / Θ 形式。
例如归并排序：f(n) = n·log n - n + 1 → Θ(n log n)


# [[递归方程]]求解


递归方程的通用形式
$$
T(n) = a \cdot T\left(\frac{n}{b}\right) + f(n)
$$
- $a$：子问题个数
- $b$：子问题规模缩小的倍数
- $f(n)$：分解与合并的开销

## 定积分近似求和

**用途**：当求和没有封闭公式时，用积分夹逼

**核心公式**：
 如果 f 单调递增：
      ∫<sup>n</sup><sub>m-1</sub>  f(x)dx  ≤  Σ<sub>m≤j≤n</sub> f(j)  ≤   ∫<sup>n+1</sup><sub>m</sub>  f(x)dx
 如果 f 单调递减：
       ∫<sup>n+1</sup><sub>m</sub>  f(x)dx  ≤ Σ<sub>m≤j≤n</sub> f(j)  ≤   ∫<sup>n</sup><sub>m-1</sub> f(x)dx


三个经典结论：
  (1) Σ(j=1→n) 1/j    = Θ(log n)       ← 调和级数
  (2) Σ(j=1→n) log j  = Θ(n log n)     ← 对数求和
	  (3) Σ(j=1→n) j^k    = Θ(n^{k+1})     ← 幂求和，k ≥ 1

> [!NOTE]  推导示例：证明 Σ log j = Θ(n log n)
> 
>   ∫(1→n) log x dx  ≤  Σ log j  ≤  ∫(1→n+1) log x dx
>
>   左边：n log n - n + 1 ≈ n log n
>   右边：(n+1)log(n+1) - n ≈ n log n
>   
>   所以 Σ log j = Θ(n log n)


## [[主定理]]


**标准形式**
T(n) = a·T(n/b) + f(n)
其中：a ≥ 1（子问题个数），b > 1（缩小的因子）

**关键参数**
d = log_b a    ← 比较的基准

**三种情况**

1. ：f(n) 远小于 nᵈ（递归部分主导）
  条件：f(n) = O(n^{d-ε})，ε > 0
  结论：T(n) = Θ(n^d)

2. ：f(n) 等于 nᵈ（平分秋色）
  条件：f(n) = Θ(n^d)
  结论：T(n) = Θ(n^d · log n)

3. ：f(n) 远大于 nᵈ（合并开销主导）
  条件：f(n) = Ω(n^{d+ε})，ε > 0
      且 af(n/b) ≤ c·f(n)，c < 1  （正则条件）
  结论：T(n) = Θ(f(n))

**解题模板** 
  第 1 步：找到 a, b → 计算 d = log_b a
  第 2 步：比较 f(n) 与 n^d 的阶
  第 3 步：套对应情况


## 递归树方法

适用场景：主定理不适用时（特别是 f(n) 带 log 因子）。

  方法步骤

  1. 画出递归树
     - 根节点代价 = f(n)
     - 每个节点产生 a 个子节点，每个子节点规模 = n/b

  2. 逐层求和
     - 第 k 层有 a<sup>k</sup> 个节点
     - 每个节点代价 = f(n/b<sup>k</sup>)
     - 该层总代价 = a<sup>k</sup> · f(n/b<sup>k</sup>)

  3. 层数 ≈ log_b n

  4. 总代价 = Σ(所有层代价)

  示意图（归并排序 T(n) = 2T(n/2) + n-1）

                 n-1                ← 第 0 层：1个节点，代价 n-1
            /          \
        n/2-1         n/2-1         ← 第 1 层：2个节点，代价 n-2
        /    \        /    \
     n/4-1 n/4-1  n/4-1 n/4-1      ← 第 2 层：4个节点，代价 n-4
      ...     ...     ...    ...
        1      1       1     1      ← 第 k 层：2^k 个节点

  每层代价 ≈ n（忽略常数）
  层数 = log₂ n
  总代价 = n · log n = Θ(n log n)



## 迭代法

迭代法就是反复代入，一直展开到初始条件

### **核心思路**
把 T(n) 中的递归项反复用自身公式替换，直到露出 T(1) 或 T(0)，然后求和。
T(n) → 代公式 → 还有 T(?) → 再代 → 还有 T(?) → 一直代 → T(1) → 结束

### 例 1：Hanoi 塔

  T(n) = 2T(n-1) + 1,   T(1) = 1

  逐次代入：

  T(n) = 2T(n-1) + 1                           // 公式本身
       = 2\[2T(n-2) + 1] + 1 = 4T(n-2) + 2 + 1  // 把 T(n-1) 展开
       = 4\[2T(n-3) + 1] + 2 + 1
       = 8T(n-3) + 4 + 2 + 1                   // 再展开
       = ...
       = 2^{n-1} · T(1) + 2^{n-2} + ... + 4 + 2 + 1   // 一直展开到 T(1)
       = 2^{n-1} · 1 + (2^{n-1} - 1)           // 等比数列求和
       = 2^n - 1
       = Θ(2^n)


### 例 2：分而治之型

  T(n) = 2T(n/2) + n,   T(1) = 0,   n = 2^k

  T(n) = 2T(n/2) + n
       = 2\[2T(n/4) + n/2] + n
       = 4T(n/4) + n + n                     // n 出现 2 次
       = 4\[2T(n/8) + n/4] + 2n
       = 8T(n/8) + n + n + n                 // n 出现 3 次
       = ...
       = 2^k · T(1) + n + n + ... + n        // k 个 n
       = n · 0 + k · n
       = n · log₂ n
       = Θ(n log n)
