# 问题描述

**问题**：给定字符集 $C=\{x_1,...,x_n\}$ 和频率 $f(x_i)$，构造一个**前缀码**（任一字符的编码都不是其他字符编码的前缀），使编码总长度 $\sum f(x_i) \cdot d(x_i)$ 最小。

> **为什么必须前缀码？** 非前缀码会产生解码歧义。例如 a: 001, b: 00，则 0100001 可解为 d,b,a 或 c,b,d。

**数学模型**：前缀码 ↔ 二叉树（树叶代表字符，路径代表编码：左0右1）
$$\text{最小化 } B(T) = \sum_{i=1}^{n} f(x_i) \cdot d_T(x_i)$$
其中 $d_T(x_i)$ 是叶节点 $x_i$ 在树中的深度。

**定长码 vs 变长码**：

|      | 定长码    | 变长码（Huffman） |
| ---- | ------ | ------------ |
| 编码长度 | 所有字符等长 | 高频字符短，低频字符长  |
| 效率   | 较低     | 最优           |

**实例**：a:45, b:13, c:12, d:16, e:9, f:5（单位：千次）

| | a | b | c | d | e | f | 总位数 |
|---|---|---|---|---|---|---|---|
| 定长码 | 000 | 001 | 010 | 011 | 100 | 101 | 300,000 |
| Huffman | 0 | 101 | 100 | 111 | 1101 | 1100 | 224,000 |

节省约 25%。

# 算法

**Huffman算法伪代码**：

```
1. 将所有字符按频率放入优先队列 Q（最小堆）
2. for i = 1 to n-1:
3.   取出 Q 中频率最小的两个节点 x, y
4.   创建新节点 z，f(z) = f(x) + f(y)
5.   z.left = x, z.right = y
6.   将 z 插入 Q
7. return Q  // Q中只剩一棵树
```

```
初始: f:5, e:9, c:12, b:13, d:16, a:45

取5,9 → 合并为14(ef)
  14(ef), c:12, b:13, d:16, a:45

取12,13 → 合并为25(bc)
  14(ef), d:16, 25(bc), a:45

取14,16 → 合并为30(def)
  25(bc), 30(def), a:45

取25,30 → 合并为55(bcdef)
  a:45, 55(bcdef)

取45,55 → 合并为100(根)
```

最终得到最优前缀码：a=0, b=101, c=100, d=111, e=1101, f=1100

**时间复杂度**：O(n log n)（堆操作）

**正确性证明**（数学归纳法）：

两个关键引理：
- **引理4.2**：频率最小的两个字符 $x, y$ 的码字等长，且仅在最后一位不同（即它们是兄弟叶节点）
- **引理4.3**：若 $x, y$ 是兄弟叶节点，$z$ 是它们的父节点，$f(z)=f(x)+f(y)$，则 $B(T) = B(T') + f(x) + f(y)$

归纳证明：
1. $n=2$ 时，0和1显然最优
2. 假设对 $k$ 个字符成立，考虑 $k+1$ 个字符：取频率最小的 $x_1, x_2$，合并为 $z$，得到 $k$ 个字符的最优树 $T'$，再把 $x_1, x_2$ 加到 $z$ 下面得 $T$。若 $T$ 不是最优，存在更优 $T^*$，去掉 $T^*$ 中 $x_1, x_2$ 得 $T^*{'}$ 比 $T'$ 更优，矛盾。
