# 正则文法

**正则文法（Regular Grammar）** 是 [[乔姆斯基谱系]] 中 **3型文法**（Type-3 Grammar），是限制最严格、表达能力最弱的一类形式文法。它对应着 **正则语言（Regular Language）**，与 [[正则表达式]] 和 [[有限自动机]] 等价。

---

## 定义

一个形式文法 $G = (V, T, P, S)$ 被称为**正则文法**，当且仅当其产生式 $P$ 满足以下形式之一：

### 右线性文法（Right-Linear Grammar）

每个产生式形如：

- $A \to aB$
- $A \to a$
- $A \to \varepsilon$（可选）

其中 $A, B \in V$（非终结符），$a \in T$（终结符）。

### 左线性文法（Left-Linear Grammar）

每个产生式形如：

- $A \to Ba$
- $A \to a$
- $A \to \varepsilon$（可选）

> [!note] 等价性
> 左线性文法和右线性文法**表达能力等价**——它们都生成正则语言。但二者**不能混用**：如果一个文法同时包含左线性和右线性产生式，它就不属于正则文法（可能生成[[上下文无关文法|上下文无关语言]]）。

## 示例

### 例 1：标识符（Identifier）

生成形如 `letter (letter | digit)*` 的标识符：

```
S → lS | lA
A → dA | ε
```

其中 $l$ 代表字母，$d$ 代表数字。

### 例 2：二进制偶数

生成以 `0` 结尾的二进制串：

```
S → 0S | 1S | 0
```

或等价地：

```
S → 0 | 1S
S → 0
```

> [!tip] 非终结符的作用
> 注意 `S → 0S | 1S | 0` 描述的是"以 0 结尾的任意二进制串"——S 约等于一个"正在构建中的后缀"。

### 例 3：自然数（无前导零）

```
S → 1A | 2A | … | 9A
S → 0 | 1 | … | 9
A → 0A | 1A | … | 9A
A → 0 | 1 | … | 9
```

## 与有限自动机的关系

**核心定理**：一个语言是正则语言 $\iff$ 它可由某个 [[有限自动机|有限自动机（FA）]] 识别 $\iff$ 它可由某个正则文法生成。

| 正则文法 | 有限自动机 |
|---------|-----------|
| 非终结符 $A$ | 状态 $q_A$ |
| 产生式 $A \to aB$ | 转移 $\delta(q_A, a) = q_B$ |
| 产生式 $A \to a$ | $q_A$ 为接受状态，读入 $a$ 后接受 |
| 产生式 $A \to \varepsilon$ | $q_A$ 为接受状态（空串） |

> [!abstract] 转换方法
> 给定右线性文法，可直接构造一个 $\varepsilon\text{-NFA}$：
> 1. 每个非终结符对应一个状态
> 2. 新增一个接受状态 $q_f$
> 3. 对 $A \to aB$：添加 $\delta(A, a) = B$
> 4. 对 $A \to a$：添加 $\delta(A, a) = q_f$
> 5. 对 $S \to \varepsilon$：起始状态 $S$ 为接受状态
>
> 反过来，给定 [[DFA]]，也可通过逆过程得到右线性文法。

## 与正则表达式的关系

[[正则表达式与正则文法的相互转换方法]]

**定理**：正则文法 $\iff$ [[正则表达式]]。

| 正则文法模式 | 对应正则表达式 | 说明 |
|------------|---------------|------|
| $A \to aA \mid a$ | $a^+$ | 一个或多个 $a$ |
| $A \to aA \mid \varepsilon$ | $a^*$ | 零个或多个 $a$ |
| $S \to aA, A \to bS \mid b$ | $(ab)^+$ | 交替结构 |
| 多个起始分支 | $(a\mid b\mid c)$ | 选择 |

> [!example] 转换示例
> 文法：
> ```
> S → aS | bA
> A → aA | bB
> B → aB | ε
> ```
> 等价正则表达式：$a^*ba^*ba^*$（恰好含两个 $b$ 的串）

## 泵引理（Pumping Lemma for Regular Languages）

**泵引理**是判断一个语言**不是**正则语言的重要工具。

> [!theorem] 正则语言的泵引理
> 若 $L$ 是正则语言，则存在常数 $p$（泵长度），使得对任意长度 $\ge p$ 的串 $w \in L$，可将 $w$ 拆分为 $w = xyz$，满足：
> 1. $|xy| \le p$
> 2. $|y| \ge 1$
> 3. $\forall i \ge 0,\ xy^iz \in L$
>
> 换言之，$y$ 部分可以被"泵"任意多次。

### 泵引理的应用——证明语言非正则

**例**：证明 $L = \{a^n b^n \mid n \ge 0\}$ **不是**正则语言。

1. 假设 $L$ 是正则的，则存在泵长度 $p$
2. 取 $w = a^p b^p$，显然 $|w| = 2p \ge p$
3. 由泵引理可写 $w = xyz$，其中 $|xy| \le p$，$|y| \ge 1$
4. 因为 $|xy| \le p$，所以 $xy$ 全由 $a$ 组成
5. 令 $y = a^k$（$k \ge 1$），则 $xy^2z = a^{p+k} b^p$
6. 此时 $a$ 的个数与 $b$ 的个数不相等，$\notin L$，矛盾
7. 故 $L$ 不是正则语言

> [!important] 意义
> 这表明**嵌套结构**（如括号匹配、`{n} {n}` 计数）超出了正则文法的表达能力，需要更强大的 [[上下文无关文法]]。

## 正则文法的封闭性

正则语言（即正则文法生成的语言）在以下运算下封闭：

| 运算 | 说明 |
|-----|------|
| 并 $L_1 \cup L_2$ | 仍是正则的 |
| 交 $L_1 \cap L_2$ | 仍是正则的 |
| 补 $\overline{L}$ | 仍是正则的 |
| 连接 $L_1L_2$ | 仍是正则的 |
| 闭包 $L^*$ | 仍是正则的 |
| 反转 $L^R$ | 仍是正则的（对称性） |
| 同态 $h(L)$ | 仍是正则的 |
| 逆同态 $h^{-1}(L)$ | 仍是正则的 |

## 在编译中的应用

正则文法是编译前端**词法分析**阶段的理论基础：

```
源代码 → 词法分析器（Lexer） → Token 流 → 语法分析器（Parser）
              ↑
         由正则文法描述
```

- [[Lex]] / [[Flex]]：基于正则文法的词法分析器生成器
- [[正则表达式]] 是描述词法规则的主要方式
- Token 类型（标识符、关键字、数字字面量、运算符等）均由正则文法定义

> [!example] Token 的正则文法
> ```
> ID      → letter (letter | digit)*
> NUM     → digit digit*
> OP      → + | - | * | /
> KW      → if | else | while | return
> WS      → (space | tab | newline)+
> ```

## 与其他文法的对比

| 特性 | 正则文法（3型） | [[上下文无关文法\|上下文无关文法（2型）]] | [[上下文有关文法\|上下文有关文法（1型）]] |
|------|---------------|-----------------------------------|-----------------------------------|
| 产生式形式 | $A \to aB$ 或 $A \to a$ | $A \to \alpha$ | $\alpha A \beta \to \alpha \gamma \beta$ |
| 自动机 | [[有限自动机\|FA/NFA/DFA]] | [[下推自动机\|PDA]] | [[线性有界自动机\|LBA]] |
| 表达能力 | 最低 | 中等 | 较高 |
| 典型应用 | 词法分析 | 语法分析 | 语义分析/类型检查 |
