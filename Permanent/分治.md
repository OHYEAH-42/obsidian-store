## 基本思想

分治通常使用递归来实现，包括**分**和**治**两个步骤：（也可以在中间加上解决问题这一个阶段）
- **分**（划分阶段）：递归地将原问题分解为多个子问题，直至到达最小子问题的时候终止。
- **治**（合并阶段）：从已知解的最小子问题开始，从底至顶地将子问题的解进行合并，从而构建出原问题的解。

常见的运用分治策略的算法：[[二分检索]]、[[归并排序]]

### 选择问题

#### (1) 选最大元素

```c
Findmax(L, n)
    max ← L[1]; k ← 1
    for i ← 2 to n
        if max < L[i] then max ← L[i]; k ← i
    return max, k
```

- 最坏比较次数：$W(n) = n - 1$
- 下界也是 $n - 1$ → **最优算法**（一次比较至多淘汰一个元素）

#### (2) 同时选最大和最小

**算法1——顺序比较**：每次比较一个候选 max 和一个候选 min

- 每个元素先跟 max 比，再跟 min 比 → $2n - 2$ 次比较

**算法2——两两分组（分治）**：

```
1. n 个元素两两一组，每组 1 次比较
2. 得 ⌊n/2⌋ 个较小者和 ⌊n/2⌋ 个较大者
3. 从较小者中找 min
4. 从较大者中找 max
```

- 比较次数：$\lfloor n/2 \rfloor$（两两比较）+ $2\lceil n/2 \rceil - 2$（各组找极值）
- $W(n) = \lceil 3n/2 \rceil - 2$
- **$\approx 1.5n$ 次比较**，比 $2n$ 好

**算法3——递归分治**：

```
在 L[1..n] 中找最大最小:
    if n ≤ 2: 直接比较得结果
    else:
        在 L[1..mid] 找最大最小 x1, y1
        在 L[mid+1..n] 找最大最小 x2, y2
        x = min{x1, x2}, y = max{y1, y2}
```

- 比较次数：$W(n) = 3n/2 - 2$（n 为 2 的幂）
- 空间：递归深度 → $S(n) = O(\log n)$

#### (3) 找第二大元素（锦标赛算法）

**思想**：淘汰赛机制[锦标赛排序_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1op4y1i7gp/?spm_id_from=333.337.search-card.all.click&vd_source=c227331cf783fe00078b3fe3d8d0b19c)

```
1. 两两分组比较，胜者进入下一轮
2. 每个"输家"记录自己输给了谁（链表记录）
3. 最终胜出者为 max
4. max 的淘汰链表中找最大者 → 第二大
```

- max 经历的比较次数：$\lceil \log n \rceil$
- 总比较：$W(n) = n + \lceil \log n \rceil - 2$
- 空间：$S(n) = O(n)$（淘汰链表存储）

**复杂度分析**（命题 2.2）：

设本轮有 $t$ 个元素，淘汰后至多 $\lceil t/2 \rceil$。若 $2^d < n \leq 2^{d+1}$，$k = \lceil \log n \rceil$ 轮后只剩 max。

最坏情况时间：$W(n) = n + \lceil \log n \rceil - 2$, 空间 $S(n) = O(n)$

#### (4) 一般性选择（第 k 小元素）—— 二次取中法，$O(n)$

**问题**：找数组 S\[1..n] 中第 k 小元素

**算法1——排序后选**：$O(n \log n)$

**算法2——简单分治**：

```
以某元素 v 划分：S1 = {s < v}, S2 = {s = v}, S3 = {s > v}
    if |S1| ≥ k: 在 S1 中找第 k 小
    elif |S1| + |S2| ≥ k: return v
    else: 在 S3 中找第 k-|S1|-|S2| 小
```

- 最坏（选到极端枢轴）→ $O(n^2)$

**算法3——二次取中法**（保证 $O(n)$）：

```
SELECT(S, low, high, k):
1. p ← high-low+1
2. if p < 39: 排序后返回 S[k]          // 小规模直接解
3. 分成每组 5 个元素，共 ⌈p/5⌉ 组
4. 每组找中项，组成集合 M
5. m* ← Select(M, 1, |M|, ⌈|M|/2⌉)   // 中位数的中位数
6. 用 m* 划分：S1 < m*, S2 = m*, S3 > m*
7. case:
      |S1| ≥ k: return Select(S1, 1, |S1|, k)
      |S1|+|S2| ≥ k: return m*
      否则: return Select(S3, 1, |S3|, k-|S1|-|S2|)
```

其实可以分成两个部分看：
- 选择合适枢轴v
	分5组，选取5组的中位数为一个数值，再从这5个中位数中选择中位数为枢轴
- 使用算法2简单分治

**复杂度分析**：

|B|（比 m* 大的元素数）$\geq 3\lceil\lfloor n/5\rfloor / 2\rceil \geq 3\lfloor n/5\rfloor / 2 \geq 3(n-4)/10$

$$
\begin{aligned}
|S_1| &\leq n - |B| \leq n - \frac{3(n-4)}{10} = 0.7n + 1.2 \leq \lfloor 3n/4 \rfloor \quad (n \geq 39) \\
|S_3| &\leq \lfloor 3n/4 \rfloor \quad (n \geq 39)
\end{aligned}
$$

递推方程：

$$W(n) \leq W(\lfloor n/5 \rfloor) + W(\lfloor 3n/4 \rfloor) + cn, \quad n \geq 39$$

- 用数学归纳法可证：$W(n) \leq 20cn$
- **$W(n) = O(n)$**，空间 $S(n) = O(n)$

**关键思想**：用"中位数的中位数" m* 做枢轴，保证每次至少排除 $n/4$ 的元素，使子问题规模按比例缩小。

### 2.4.3 n-1 次多项式在全体 2n 次方根上求值（FFT 基础）

**问题**：$A(x) = a_{n-1}x^{n-1} + \cdots + a_1x + a_0$，对 $x$ 为 1 的 $2n$ 次方根的所有 $x$，计算 $A(x)$。

**1 的 2n 次根**：$\omega_j = e^{2\pi ij/2n} = \cos\frac{\pi j}{n} + i\sin\frac{\pi j}{n}$，$j=0,1,\ldots,2n-1$

**算法1——Horner 规则对每个 x 求值**：$O(n^2)$

**算法2——分治算法**（设 n 为偶数）：

拆分为奇偶系数：

$$A_{\text{even}}(x) = a_0 + a_2x + a_4x^2 + \cdots + a_{n-2}x^{(n-2)/2}$$
$$A_{\text{odd}}(x) = a_1 + a_3x + a_5x^2 + \cdots + a_{n-1}x^{(n-2)/2}$$

则：
$$A(x) = A_{\text{even}}(x^2) + x \cdot A_{\text{odd}}(x^2)$$

- $x$ 是 1 的 $2n$ 次根时，$x^2$ 是 1 的 $n$ 次根

**算法步骤**：
1. 计算 1 的全体 $2n$ 次根（$O(n)$）
2. 分别计算 $A_{\text{even}}(x^2)$ 和 $A_{\text{odd}}(x^2)$（递归）
3. 用步骤 2 结果计算 $A(x)$（$O(n)$）

**复杂度**：
$$T(n) = 2T(n/2) + O(n) \to T(n) = O(n \log n)$$

**这是快速傅里叶变换（FFT）的核心。**

## 习题重点

### 逆序对计数（习题 2.28）—— PPT 例题

**问题**：计算排列 $i_1, i_2, \ldots, i_n$ 的逆序对个数（若 $i<j$ 但 $A[i] > A[j]$，则 $(A[i], A[j])$ 为一个逆序对）

**分治思路**（利用归并排序合并过程）：

```
归并排序 + 计数器

合并步骤：
  左半 L = [a_1, a_2, ...]  右半 R = [b_1, b_2, ...]
  两个指针 i, j 分别指向 L 和 R 的当前元素
  while 两边都不为空:
      if L[i] ≤ R[j]: 取 L[i]，i++（正常，不产生逆序）
      else:          取 R[j]，j++
           逆序计数 += |L| - i + 1
           （R[j] 跳过了 L 中剩余的所有元素，每个都构成逆序对）
```

**示例**：排列 3, 5, 2, 7, 8, 1, 4, 6 的逆序计数过程

- 基本和归并排序一样，只是多了累加逆序数
- 复杂度：**$\Theta(n \log n)$**

## 小结

分治法的**基本模式**：

```
问题规模大 → 划分 → 递归求解子问题 → 合并 → 得到原问题的解
```

**适用范围**：
- 原问题可划分为相同性质的子问题
- 子问题可以独立求解
- 子问题的解可以合并为原问题的解

**改进分治算法的两个技巧**：
1. 减少子问题个数 → 通过代数变换减少乘法次数
2. 减少合并时间 → 预处理 + 利用问题特性
