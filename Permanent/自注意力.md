# 什么是自注意力

**自注意力**（Self-Attention）是一种让同一序列中的各位置，根据彼此的相关程度加权汇总信息、更新自身表示的[[注意力机制]]。“自”表示查询、键和值都来自同一个序列；每个位置可以关注该序列中允许访问的其他位置以及自身。

# 核心计算公式

以单头缩放点积自注意力为例，令输入表示矩阵为 $X\in\mathbb{R}^{n\times d}$，每行对应一个位置。通过三个可学习的[[线性层|线性投影]]得到：

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
$$

- $n$：序列长度；$d$：输入表示的维度。
- $W_Q,W_K\in\mathbb{R}^{d\times d_k}$、$W_V\in\mathbb{R}^{d\times d_v}$：可学习的投影矩阵；这里省略可选偏置。
- $Q$（Query，查询）：用于匹配需要的信息。
- $K$（Key，键）：用于与查询计算匹配分数。
- $V$（Value，值）：被加权汇总的信息。
- $d_k$：查询和键的维度；$d_v$：值的维度。

无掩码时，注意力权重和输出为：

$$
A=\operatorname{softmax}\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}\right),
\qquad Y=AV
$$

$A\in\mathbb{R}^{n\times n}$ 中的 $A_{ij}$ 表示位置 $i$ 对位置 $j$ 的注意力权重。[[激活函数#Softmax|Softmax]] 沿每一行计算，使该行权重之和为 $1$；除以 $\sqrt{d_k}$ 用于控制点积分数的尺度。输出 $Y\in\mathbb{R}^{n\times d_v}$ 的每一行都是值向量的加权和。

若使用[[因果掩码]]，则在 Softmax 前将未来位置的分数设为负无穷，使其权重为 $0$，让当前位置只能关注自身和之前的位置。

[[FlashAttention]]是对上述注意力计算的内存访问与执行方式进行优化的算法，不是另一种近似的注意力定义。

公式参考：[Attention Is All You Need，§3.2](https://arxiv.org/html/1706.03762v7#S3.SS2)、[FlashAttention 原论文](https://arxiv.org/abs/2205.14135)。

# [[位置编码|Positional Encoding]]

Self-Attention 能够判断 Token 之间的关联程度，但仅凭注意力计算本身，并不能直接判断它们在序列中的位置和距离。

回顾 Self-Attention：
$$
 \operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V 
$$

其中：
- $Q$：当前 Token 想寻找什么信息
- $K$：其他 Token 能提供什么信息
- $V$：其他 Token 实际提供的信息
并没有直接使用Token的位置
对于不带位置编码和掩码的 Self-Attention，改变 Token 的排列顺序，只会让输出跟着重新排列，无法真正识别序列次序。
因此，需要一种机制将位置信息引入模型，也就是[[位置编码]]。

例如，[[正弦位置编码]]通常将位置向量加到输入表示上，[[旋转位置编码|RoPE]]则对查询和键施加位置相关的旋转，以不同方式影响注意力计算。
