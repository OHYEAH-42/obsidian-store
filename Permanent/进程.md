# 什么是进程
**进程**（Process）是[[操作系统]]进行**资源分配**的基本单位，是正在执行的程序实例。
进程是[[操作系统]]对一个正在运行的[[程序]]的一种抽象
可以理解为：[[程序]]+执行[[上下文]]=进程

# 进程的特性

| 特性      | 核心含义                               | 关键理解                                                                         |
| :------ | :--------------------------------- | :--------------------------------------------------------------------------- |
| **动态性** | 进程是程序的一次**执行过程**，有生命周期             | 进程有“创建→运行→消亡”的过程，而程序是静态的（仅占磁盘空间）。**动态性是进程最基本的特征**。                           |
| **并发性** | 多个进程可同时在内存中运行，**宏观上并行，微观上交替**      | 即使是单核CPU，操作系统也通过快速切换让多个进程共享CPU。并发是操作系统存在的核心价值。                               |
| **独立性** | 进程是系统进行**资源分配**和**独立调度**的基本单位      | 每个进程拥有独立的地址空间（通过[[虚拟内存]]实现），一个进程崩溃一般不影响其他进程（隔离性）。                            |
| **异步性** | 进程以**不可预知**的速度向前推进                 | 因CPU调度策略和I/O中断等因素，进程的执行是“走走停停”的。异步性导致程序行为的不确定性，是并发编程需要同步机制的根本原因（参考[[竞态条件]]）。 |
| **结构性** | 进程在内存中由**程序段、数据段、进程控制块（PCB）**三部分组成 | PCB是进程存在的唯一物理标识，内核通过PCB感知和管理进程。没有PCB，进程就不存在。                                 |

# 进程的状态

![[Pasted image 20260703204002.png]]

- 就绪到执行：处于就绪状态的进程，在调度程序为之分配了[[处理器]]之后，该进程就进入执行状态。
- 执行到就绪：正在执行的进程，如果分配给它的时间片用完，则暂停执行，该进程就由执行状态转变为就绪状态。
- 执行到阻塞：如果正在执行的进程因为发生某事件而使进程的执行受阻，则将停止执行，由执行状态转变为阻塞状态。
- 阻塞到就绪：处于阻塞状态的进程，如果引起其阻塞的事件发生了，则该进程将解除阻塞状态而进入就绪状态。
