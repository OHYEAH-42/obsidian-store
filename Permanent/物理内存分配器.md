# 什么是物理内存分配器

**物理内存分配器**（Physical Memory Allocator）是内核中管理可用物理内存、分配和回收[[物理页框]]的组件。xv6 的基本分配器以 4 KiB 页为单位，并用[[空闲页链表]]记录可用页面。分配物理页与建立虚拟映射是不同操作：获得页框后，通常还需建立相应[[页表项]]才能按目标虚拟地址使用它。
