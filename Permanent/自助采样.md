# 什么是自助采样

**自助采样**（Bootstrap Sampling）是在已有数据集中独立、有放回地抽取样本，形成重采样数据集的方法。典型做法是从 n 个样本中抽取 n 次，因此新数据中可以重复出现某些样本，也会遗漏另一些样本。它可用于估计统计量的不确定性，也常用于 [[Bagging]]；重采样不会创造新的独立观测信息。

参考：[定义与方法来源](https://scikit-learn.org/stable/modules/ensemble.html#bagging-meta-estimator)。
