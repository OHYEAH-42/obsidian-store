# 问题

$n$ 个集装箱，重量 $w_1, w_2, ..., w_n$，两艘船载重分别为 $c_1, c_2$。问能否将所有集装箱装上两艘船？

# 思路

**转化为[[0-1背包问题]]**

先判断必要条件吗，集装箱总重量小于等于两艘船的载重和：$\sum w_i \leq c_1 + c_2$（不满足直接不行）。

然后转化为：第一艘船装哪些箱子，能使装的重量尽量大（但不超过 $c_1$），且剩下的全都能装进第二艘船。

剩下的能装进第二艘船 ⇔ 总重量 - 第一艘船装的重量 ≤ $c_2$

所以问题变成：求一组集装箱放到第一艘船，重量之和不超过 $c_1$的前提下最大化重量，检查最大值是否 ≥ 总重 - $c_2$。这等价于 0-1背包：容量 = $c_1$，每个物品重量 = 价值 = $w_i$。


# 回溯算法求解

## 分析

- **解向量**：$X = \langle x_1, x_2, ..., x_n \rangle$，$x_i \in {0, 1}$，1 表示装箱 i上第一艘船
- 搜索空间：子集树（满二叉树），$2^n$ 个叶子，树的左右节点代表了是否将该节点放到第一艘船上
- 约束剪枝：当前装入第一艘船的重量之和 $\leq c_1$
- 最优性剪枝：设已知最优解（第一艘船最大载重）为 $bestW$，当前部分解已装入重量为
$cw$，剩余集装箱总重为 $r$

> 如果 $cw + r \leq bestW$，就算把剩下的全装进去也不会超过当前最优 → 剪枝

## 代码

```
void backtrack(int i) {
      if (i > n) {
          bestW = cw;   // 到达叶子，更新最优解
          return;
      }

      // 剩余重量上界估计
      r -= w[i];

      // 分支1：装集装箱i上第一艘船
      if (cw + w[i] <= c1) {           // 约束剪枝
          cw += w[i];
          backtrack(i + 1);
          cw -= w[i];                  // 回退
      }

      // 分支2：不装集装箱i上第一艘船
      if (cw + r > bestW) {            // 最优性剪枝
          backtrack(i + 1);
      }

      r += w[i];                       // 回退剩余重量
  }
```
