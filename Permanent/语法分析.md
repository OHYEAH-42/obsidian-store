语法分析器，将输入的单词流(Token stream)转化为[[抽象语法树]](AST)，语法分析（Syntax Analysis，又称 Parsing）是[[编译器]]的核心阶段之一，根据[[文法]]规则，将[[词法分析]]生成的 Token 序列组织成**语法结构**（通常是[[抽象语法树]]（AST）或解析树）。

解析器(Parser)

值得一提，有的解释器会把[[词法分析]]和语法分析统一，都有Parser完成。

# 什么是[[语法]]？

**语法**（Syntax）是指一种语言中组成合法句子的**结构规则**——即哪些符号序列在形式上是被允许的。它关注的是**形式**，而不是含义（语义）。


# 什么是[[文法]]？

**文法**（Grammar）是一组形式化规则，用于描述一种语言的**语法结构**。它通常由四个部分组成：终结符集合、非终结符集合、起始符号、产生式规则。

# 什么是[[语言]]？

**语言**（Language）是由[[文法]]生成的所有合法句子（由终结符组成的串）的集合。


# 核心作用
- **检查语法正确性**：Token 序列是否符合语言文法
- **构建语法树**：为后续[[语义分析]]和代码生成提供结构化表示
- **报告语法错误**：定位错误位置并尝试恢复

# 主要方法分类
| 类型                | 解析方向        | 典型算法                                       | 文法限制         |
| :---------------- | :---------- | :----------------------------------------- | :----------- |
| **[[自顶向下的语法分析]]** | 从起始符号展开到终结符 | [[LL(1)]]、[[Permanent/递归下降算法]]                       | 无左递归，需提取左公因子 |
| **[[自底向上的语法分析]]** | 从终结符归约到起始符号 | [[LR(0)]]、[[SLR(1)]]、[[LR(1)]]、[[LALR(1)]] | 能力更强，可处理左递归  |
