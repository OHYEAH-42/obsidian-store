# 临界区

## 定义

**临界区（Critical Section）** 是一段访问共享资源的代码片段，该共享资源同一时刻只能被一个[[线程]]（或[[进程]]）访问。当多个线程并发执行时，必须保证在任一时刻最多只有一个线程处于临界区中，以防止[[竞态条件]]（Race Condition）导致数据不一致。

### 关键特征

- **互斥（Mutual Exclusion）**：同一时刻只允许一个线程进入临界区。
- **有限等待（Bounded Waiting）**：某个线程在发出进入请求后，必须在有限时间内获准进入，避免无限等待（饥饿）。
- **前进（Progress）**：当临界区空闲且有多个线程请求进入时，必须由其中一个线程在有限时间内获准进入。

### 进入与退出

每个线程在进入临界区前需执行 **进入区（Entry Section）** 代码申请权限，退出后执行 **退出区（Exit Section）** 代码释放权限，其余部分为 **剩余区（Remainder Section）**。

```c
// 典型结构
do {
    // 进入区 —— 申请进入临界区
    entry_section();

    // 临界区 —— 访问共享资源
    critical_section();

    // 退出区 —— 释放临界区
    exit_section();

    // 剩余区 —— 其余代码
    remainder_section();
} while (TRUE);
```

### 实现方式

- **软件方法**：Peterson 算法、Dekker 算法
- **硬件方法**：关中断、Test-and-Set、Compare-and-Swap
- **操作系统抽象**：[[信号量]]（Semaphore）、互斥锁（Mutex）、管程（Monitor）
