# 方法一 手动—加括号

类似在[[后缀式]]中描述的办法

  1. 按优先级把每一步加括号：  (a * (b + c))
  2. 把操作符移到对应的右括号位置，删括号：
     (a (b c)+)*
     → a b c + *

只是把$E_1$这些换成了括号

# 方法二 [[Permanent/递归下降算法]]

## 核心原则

操作数先输出，操作符后输出，函数嵌套本身决定顺序。
	ab+  （操作数在前，操作符在后） 


## 伪代码

factor()里遇到操作数直接输出
exp()/term()里操作数在递归调用后输出

```
void exp()
      term()
      while (token == '+' || token == '-')
          op = token
          match(token)
          term()
          输出 op          ← 在所有操作数之后输出

void term()
    factor()
	while (token == '*' || token == '/')
	    op = token
        match(token)
	    factor()
        输出 op

void factor()
    if (token == 数字或变量)
        输出 token
        match(token)
    else if (token == '(')
        match('(')
        exp()
        match(')')
```

## 实例

a+b\*c

```
exp()
    → term()
        → factor() 输出 a                  // 左子树
        → while: token='+' 不是*/, 退出
    → while: token='+', match(+)
        → term()
            → factor() 输出 b              // 右子树的左子
            → while: token='*', match(*)
                → factor() 输出 c          // 右子树的右子
                → 输出 *                   // 根（内层）
        → 输出 +                           // 根（外层）
```

输出：abc\*+

```
  语法树:
         +
        / \
       a   *
          / \
         b   c
```

# 方法三 [[LR]] [[属性文法]]

以以下文法为例子：

E→E+T|T，T→T\*F|F，F→id

## 核心原则

后缀串是每个非终结符的综合属性，[[归约]]时拼接子节点的字符串。

## 属性设计

每个非终结符挂一个 post（string 类型）：


| 符号  | 属性                  |
| --- | ------------------- |
| E   | E.post — 该 E 对应的后缀串 |
| T   | T.post — 该 T 对应的后缀串 |
| F   | F.post — 该 F 对应的后缀串 |

## 语义规则

产生式                        语义规则
(1) E₁ → E₂ + T     E₁.post = E₂.post + T.post + "+"
(2) E₁ → E₂ - T      E₁.post = E₂.post + T.post + "-"
(3) E  → T             E.post = T.post
(4) T₁ → T₂ \* F     T₁.post = T₂.post + F.post + "\*"
(5) T₁ → T₂ / F     T₁.post = T₂.post + F.post + "/"
(6) T  → F             T.post = F.post
(7) F  → ( E )        F.post = E.post           ← 括号只去掉，不输出
(8) F  → id           F.post = id.lexeme

观察可以总结规律：

(1)(2)： E₁.post = 左操作数后缀 + 右操作数后缀 + 操作符
(4)(5)： T₁.post = 左操作数后缀 + 右操作数后缀 + 操作符
(3)(6)： T/F 单产生式，属性原样传递
(7)：   括号里的东西，后缀原样拿出来，括号就不要了
(8)：   叶子节点，后缀就是变量名本身

## 演算过程

a+b\*c
文法：E→E+T|T，T→T\*F|F，F→id

归约过程（只列关键归约步）：

| 栈                   | 输入    | 归约产生式 | 属性计算                               |
| ------------------- | ----- | ----- | ---------------------------------- |
| 0 a                 | +b\*c | F→id  | F.post = "a"                       |
| 0 F(a)              | +b\*c | T→F   | T.post = "a"                       |
| 0 T(a)              | +b\*c | E→T   | E.post = "a"                       |
| 0 E(a) +            | b\*c  | —     | —                                  |
| 0 E(a) + b          | \*c   | F→id  | F.post = "b"                       |
| 0 E(a) + F(b)       | \*c   | T→F   | T.post = "b"                       |
| 0 E(a) + T(b) \*    | c     | —     | —                                  |
| 0 E(a) + T(b)  \* c |       | F→id  | F.post = "c"                       |
| 0 E(a)+T(b)\*F(c)   |       | T→T*F | T.post = "b"+"c"+"\*" = "bc\*"     |
| 0 E(a)+T(bc\*)      |       | E→E+T | E.post = "a"+"bc\*"+"+" = "abc\*+" |
| 0 E(abc\*+)         |       | acc   |                                    |

核心改变就是关于属性的：

- 移进
	除了将符号，状态压入栈中，还要把属性值也压入新的一个栈中

- 归约

### 优化思路

可以看到代码中用switch来判断表达式从而获得属性值，但我们有别的方式，那就是把属性和产生式放在一起。比如：
```
Grammar[1] = {"E", {"E", "+", "T"}, [](auto& v) {
	return v[0] + v[2] + "+";    // E.post + T.post + "+"
}};
```
