属性文法是在[[上下文无关文法]]的基础上，为每个产生式附加一组[[语义]]规则，用来计算该产生式中各[[文法]]符号的属性值。是带[[属性]]的一种文法。

# 主要思想

- 对每个文法符号引进相关的属性符号
- 写出计算属性值的语义规则

# 属性文法的形式定义

一个属性文法是一个三元组，A=（G，V，F）
- G是一个上下文无关文法
- V是属性的有穷集
- F是关于属性的断言的有穷集（断言就是对属性的定义和约束）

一般地，将属性文法写成表格形式，每个文法规则用属性等式的集合或者相应规则的语义 规则列出，如下所示
![[Pasted image 20260604222257.png]]

例如对于文法：
G\[E]:
   E→n
   E→E+n
我们可以得到：

| 文法规则  | 语义规则              |
| ----- | ----------------- |
| E→n   | E.val=n.val       |
| E→E+n | E.val=E.val+n.val |
