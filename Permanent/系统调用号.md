# 什么是系统调用号

**系统调用号**（System Call Number）是在特定操作系统和体系结构的调用接口中，用于标识某项内核服务的整数编号。用户程序按[[应用二进制接口]]传递编号，内核再分派到对应[[系统调用]]处理函数；编号不是函数的内存地址，也不是跨系统通用的常量。xv6 RISC-V 使用 `a7` 传递调用号。
