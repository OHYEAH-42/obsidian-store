# 什么是归一化

**归一化**（Normalization）泛指按照某种规则调整数据、网络激活值或向量的尺度，使数值范围或分布更加稳定。在[[神经网络]]中，归一化可以改善数值条件和[[梯度]]传播，从而使训练更稳定，并常常允许使用更大的学习率。

# 常见类型

| 归一化方法 | 处理对象 | 主要目的 |
| :--- | :--- | :--- |
| [[最小-最大归一化]] | 输入特征 | 将数据缩放到固定区间 |
| [[标准化]] | 输入特征 | 使数据均值接近 $0$、标准差接近 $1$ |
| [[批归一化]] | 网络内部激活值 | 使用一个批次的统计量稳定训练 |
| [[层归一化]] | 网络内部激活值 | 使用单个样本内部的统计量稳定训练 |
| [[向量归一化]] | 表示向量 | 将向量缩放到单位长度 |

此外还有 Instance Normalization、Group Normalization 和 Weight Normalization 等方法，它们的统计范围或处理对象不同。

# 归一化与标准化

狭义的归一化通常指把数据缩放到固定范围，[[标准化]]则指减去均值后除以标准差；但在机器学习语境中，“归一化”也经常被用作这些尺度调整方法的统称，因此需要根据上下文判断具体含义。
