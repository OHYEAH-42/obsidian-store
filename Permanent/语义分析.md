# 什么是[[语义]]？



**语义**（Semantics）是指程序中**符号和结构的含义**，即“这段代码做了什么/意味着什么”。


# 语义分析

**语义分析**（Semantic Analysis）是编译器的后端阶段之一，在语法分析，对[[抽象语法树]]（AST）进行[[上下文]]相关**的检查，确保程序符合语言的语义规则。



# 核心作用

一般可以分为两类，一种是检查语法结构的静态语义，即类型检查和作用域解析。另一种是将合乎[[语义]]的句子进行翻译，并生成某种中间形式

- **类型检查**：操作数类型是否匹配（如 `int + string` 是否允许）
- **作用域解析**：标识符引用是否已声明、是否可见
- **符号绑定**：将标识符关联到对应的定义（如函数、变量）
- **一致性检查**：函数调用参数个数/类型是否正确、数组索引是否为整数、break是否在循环内等


# 主要任务一览
| 任务          | 说明                                     | 示例                      |
| :---------- | :------------------------------------- | :---------------------- |
| **类型检查**    | 验证表达式类型一致性                             | `3 + true` → 错误         |
| **类型推导**    | 自动推断表达式类型（如 `var x = 1` → `x` 为 `int`） | ML、Haskell 等语言          |
| **作用域校验**   | 识别引用是否在当前作用域内                          | 使用未声明变量 → 错误            |
| **符号表管理**   | 填充、查询[[符号表]]                           | 记录变量类型、存储位置             |
| **唯一性检查**   | 防止重复定义（如同一作用域同名变量）                     | `int x; double x;` → 错误 |
| **流检查**     | 控制流合法性（如非 void 函数是否返回值）                | 有 `if` 但无 `return`      |
| **标签/跳转目标** | 检查 goto、break、continue 的目标是否存在         | `goto unknown;` → 错误    |

## [[语义动作]]

**语义动作**（Semantic Actions）是附着在文法产生式上的代码片段，在语法分析过程中触发执行，完成翻译任务（如计算值、生成代码、登记符号表等）。

语义动作是实现语法制导翻译的具体手段。

# [[属性]]

属性(attribute)是编程语言结构的任意特性，是附着在文法符号（终结符或非终结符）上的“值”。每个符号可以有多个属性。

# [[属性文法]]

属性文法是在[[上下文无关文法]]的基础上，为每个产生式附加一组[[语义]]规则，用来计算该产生式中各[[文法]]符号的属性值。是带[[属性]]的一种文法
