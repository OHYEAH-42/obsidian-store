赋值语句翻译就两步：先算右边，再把结果赋给左边。
# 1. 分析编程语言赋值语句的书写格式

x=3     y=a+b\*c

基本格式由变量、赋值号和表达式组成，其形式为：
$id=E$

# 2. 按书写格式规律写出对应的编程语言的赋值语句文法

S->id=E
其中E可以是算术表达式

# 3. 分析算数表达式执行时的具体含义，以便观察是否需要进行文法规则的改造以及写出对应规则归约时需要执行的[[语义动作]]

- 将算术表达式E的值填入[[符号表]]中id的属性值中
- 要先查看符号表
- 还要进行数据类型的检查

//   attrs[0] = id 的词素（如 "x"）

//   attrs[2] = E 的结果（如 "t3"）

switch (prodIdx) {

        break;
}
