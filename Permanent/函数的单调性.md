# 函数的单调性

**单调性**描述自变量从小到大变化时，函数值在指定区间内是否始终保持同一变化方向。任取区间 $I$ 内两点 $x_1<x_2$，按下表比较函数值。

| 性质 | 对任意 $x_1<x_2$ 都成立的条件 |
| --- | --- |
| 严格递增 | $f(x_1)<f(x_2)$ |
| 严格递减 | $f(x_1)>f(x_2)$ |
| 单调不减 | $f(x_1)\le f(x_2)$ |
| 单调不增 | $f(x_1)\ge f(x_2)$ |

- $I$：所考察的区间，包含在函数的[[定义域]]内。
- $x_1,x_2$：区间中任意两个不同的输入，按从小到大排列。

例如 $f(x)=x^2$ 在 $(-\infty,0]$ 上严格递减，在 $[0,+\infty)$ 上严格递增。从左到右看整条抛物线，函数值先减后增，因此它在 $\mathbb R$ 上不单调。
