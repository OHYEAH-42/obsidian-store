# 四元组（Quadruples）

- **结构**：`(op, arg1, arg2, result)`，即**三地址码**的标准实现。
- **核心**：**显式临时变量**（如 `t1`, `t2`）存放结果，指令间通过变量名引用。
- **示例**：（+,a,b,t1）(\*,t1,t2,t3)
- **特点**：
  - **便于优化和移动**：指令间无硬依赖（通过变量名松耦合）
  - 现代编译器（GCC/LLVM）的标准基础IR


# 四元组的转化

## 算术表达式

eg：$((a+b)*(a-c)-d)*(x+y)$

四元组的计算与怕[[三元组]]类似由内到外，顺序相同一般都从左到右：
- (+,a,b,t1)
- (-,a,c,t2)
- (\*,t1,t2,t3)
- (-,t3,d,t4)
- (+,x,y,t5)
- (\*,t4,t5,t6)

## 赋值语句

a=b+c

（+，b，c，T1）
（=，T1，，a）

## 关系比较语句

**a rop b** 
- rop表示＞，＜，!=，>=，.<=，\==等关系比较运算符

由于关系运算通常都会作为条件语句或循环语句的条件，因此通常将关系运算转换为减法运算，后面跟着条件成立与否转移的四元组

eg：  a > b
可以表示为
（-，a，b，T）
（BMZ，？，，T）      //？表示跳转目标，T就是a-b的值，如果T小于等于0，就跳转到？
或者表示为
（J>，a，b，?1）       // a>b，则跳转到?1语句                         
（J，，，?2）             //else语句，无条件跳转的写法，跳转到?2语句

>BR——Branch——无条件跳转
>BZ——Branch if Zero——结果\==0就跳转
>BLZ——Branch if Less than Zero——结果<0就跳转
>BMZ——Branch if Minus or Zero——结果<=0就跳转

注意一下，BR类的写法和J类的写法对于跳转语句的位置不同
（BR，1，，）BR在操作数中
（J，，1）      J在最后

## 条件语句

if（u）S1 else S2

按照计算级执行顺序，将其翻译成四元组：
- 将u转换为四元组。
- 条件不成立转移，转化为四元组
- 语句S1转换为四元组
- 无条件转移转换为四元组
- 语句S2转换为四元组

### eg1：
```
if (m>n)
	k=0;S=1;
else
	m=0;
```
四元组表示：
1. （-，m，n，T1）                                              （J>，m，n，（3））
2. （BMZ，（6），，T1）                                    （J，，（6））
3. （=，0，，k）                                                  （=，0，，k）
4. （=，1，，S）                                                  （=，1，，S）
5. （BR，（7），，）                                           （J，，（7））
6. （=，0，，m）                                                （=，0，，m）
7. 接着后面的语句

### eg2：
```
if A<B && C>D
	x=1;
else
	x=0;
```
1. （j<，A，B，（3）)
2. （j，，，（7））
3. （j>，C，D，（5））
4. （j，，，（7））
5. （=，1，，x）
6. （j，，，（8））
7. （=，0，，x）
8. 接着后面的语句

### eg3：
```
if A<B || C>D
	x=1;
else
	x=0;
```
1. （j<，A，B，（5）)
2. （j，，，（3））
3. （j>，C，D，（5））
4. （j，，，（7））
5. （=，1，，x）
6. （j，，，（8））
7. （=，0，，x）
8. 接着后面的语句

## 循环语句

### while循环语句

while(u)
	s;
按照计算机执行顺序，翻译成四元组，步骤如下
- 将u转换为四元组
- 条件不成立转移，转换为四元组
- 语句S转换为四元组
- 无条件转移转换为四元组

eg：
```
while(m>n)
	k=1;S=0;
```
四元组表示：

| 序号  |               |              |
| --- | ------------- | ------------ |
| （1） | （-，m，n，T1）    | （J>，m，n，（2）） |
| （2） | （BMZ，（6），，T1） | （J，，，（6））    |
| （3） | （=，1，，k）      | （=，1，，k）     |
| （4） | （=，0，，S）      | （=，0，，S）     |
| （5） | （BR，（1），，）    | （J，，，（1））    |
| （6） |               |              |
