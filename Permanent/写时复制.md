# 什么是写时复制

**写时复制**（Copy-On-Write，COW）是让多个使用者暂时共享同一数据副本，仅在某一方需要修改时才为其创建私有副本的延迟复制机制。

用于 [[fork]] 时，系统可让父子进程暂时共享原有物理页，把原本可写的共享映射设为只读并记录 COW 状态；写入触发[[缺页异常]]后，再按共享情况分配、复制并修改映射。原本就只读的页面不能因此获得写权限。
