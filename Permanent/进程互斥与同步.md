# 与时间有关的错误 

由于[[并发进程]]执行的随机性，有关进程对另一个进程的影响是不可预测的。 由于他们共享了资源（变量），在不同时刻交替访问资源时就可能造成结果的不正确。造成结果不正确的因素是与进程占用处理器时间、执行速度以及外界影响有关，这些因素都与时间有关，故统称为“与时间有关的错误”。
例：飞机售票问题、主存管理问题、自动计算问题

# [[临界区]] 

有交往的并发进程执行时出现与时间有关的错误，根本原因是对共享资源 （变量）的使用不加限制，当进程交叉使用了共享资源时就可能造成错误。 
临界区：并发进程中与共享变量有关的程序段 
临界资源：共享变量所代表的资源 
相关临界区：多个并发进程中涉及相同共享变量的那些程序段 
临界区设计要求：一次一个，有空让进，无空等待，多中择一，有限等待

# 进程的互斥

当有若干进程要使用某一资源时最多只允许一个进程使用， 其他等待直到占用者释放该资源。
