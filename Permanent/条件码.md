**条件码（Condition Codes）**，在大多数[[处理器]]（如x86、ARM）中也叫**标志位（Flags）**，是一组只有0或1的**状态位**，用于记录最近一次算术或逻辑运算的“附加结果”。

# 常见条件码

| 标志     | 全称      | 含义（何时为1）            |
| ------ | ------- | ------------------- |
| **ZF** | 零标志     | 运算结果为 **0**         |
| **SF** | 符号标志    | 运算结果为 **负数**（最高位=1） |
| **OF** | 溢出标志    | **有符号数**运算结果超出可表示范围 |
| **CF** | 进位/借位标志 | **无符号数**运算发生进位或借位   |
这些条件码可以由处理器的[[算数逻辑单元]]ALU产生，存储在条件寄存器
