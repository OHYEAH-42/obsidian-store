# 什么是神经元

**神经元**（Neuron）是[[神经网络]]的基本计算单元，模拟生物神经元的“加权求和 + 非线性激活”过程。

# 核心计算

$$
z=\sum_{i=1}^{n}w_i x_i+b,\qquad y=f(z)
$$

| 符号    | 含义              |
| :---- | :-------------- |
| $x_i$ | 输入信号            |
| $w_i$ | 权重（可学习参数）       |
| $b$   | 偏置（可学习参数）       |
| $f$   | [[激活函数]]（引入非线性） |
| $y$   | 神经元输出           |

写成向量形式为：

$$
y=f(\boldsymbol{w}^{\mathsf T}\boldsymbol{x}+b)
$$

神经元先通过[[权重]]决定各输入对结果的影响程度，再用[[偏置]]整体平移加权和，最后通过[[激活函数]]得到输出。单个神经元只能完成一次较简单的变换；大量神经元组成[[层]]并逐层组合后，才能表示复杂函数。
