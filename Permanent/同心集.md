# [[同心集]]

**核心** = LR(1) 项目去掉前瞻符后的部分。

两个 LR(1) 状态是**同心**的，当它们包含的项目**核心完全相同**（仅前瞻符不同）。

简单地说，就是在两个项集中，去掉前瞻符后，所有[[项目]]都相同，两者可以合并成一个同心集。
合并后的同心集的前瞻项也合并。


```
I₂  = { [A → (·A), $],   [A → ·(A), )],  [A → ·a, )]  }
I₇  = { [A → (·A), )],   [A → ·(A), )],  [A → ·a, )]  }

两者核心完全相同 → 同心集 → 可以合并！

I₂₇  = { [A → (·A), $ | )],   [A → ·(A), )],  [A → ·a, )]  }

```
