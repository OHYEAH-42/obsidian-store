# 什么是位置编码

**位置编码**（Positional Encoding）是向模型提供序列位置或顺序信息的方法。仅根据内容进行、没有位置信息或顺序约束的[[自注意力]]本身不能区分输入排列的先后关系，因此 [[Transformer]] 需要某种方式表示位置。

常见形式包括将固定正弦／余弦向量或可学习的位置向量加到输入表示上；也有通过相对位置调整注意力计算的方法。因此位置编码不只有一种固定公式，也不一定是“额外加一个向量”。

[[嵌入表|词元嵌入]]主要表示“是什么”，位置信息表示“在哪里或相距多远”，两者承担不同角色。

参考：[定义与结构来源](https://d2l.ai/chapter_attention-mechanisms-and-transformers/self-attention-and-positional-encoding.html)。

# 工作原理

最直观的方案是：给每个 Token 分配一个表示位置的向量。
![[Pasted image 20261024142559.png]]
公式为：
$$
 X_{\text{input}}=X_{\text{token}}+PE 
 $$

其中：
- $X_{\text{token}}$：Token 本身的语义向量。
- $PE$：Token 的位置向量。
- $X_{\text{input}}$：最终输入 Transformer 的向量。
这样，模型就可以同时利用 Token 的语义信息和位置信息。
但需要注意：不是所有位置编码都通过相加实现。

# 常见的编码方法

| 方法                        | 核心思想            | 特点           |
| ------------------------- | --------------- | ------------ |
| [[正弦位置编码\|Sinusoidal PE]] | 使用正弦、余弦函数生成位置向量 | 无须学习位置参数     |
| Learned PE                | 为每个位置训练独立向量     | 可以从训练中学习     |
| [[旋转位置编码\|RoPE]]          | 根据位置旋转 Q、K 向量   | 使注意力分数体现相对位置 |
| ALiBi                     | 为注意力分数添加距离偏置    | 直接影响远近位置的注意力 |
