**操作数**（Operand）是[[指令]]中**[[操作码]]作用的对象**，指定了“对什么数据做操作”。
# 核心定义

- 操作数指定了数据的**来源、去向**或**立即值**
- 一条指令可以有 0~3 个操作数（取决于指令集）
# 操作数的来源
| 类型           | 说明            | 示例（x86）          |
| :----------- | :------------ | :--------------- |
| **[[立即数]]**  | 指令中直接给出的常数    | `MOV EAX, 42`    |
| **[[寄存器]]**  | 数据存放在[[寄存器]]中 | `ADD EAX, EBX`   |
| **[[内存引用]]** | 数据存放在内存中      | `MOV EAX, [EBX]` |
| **I/O端口**    | 与外设通信         | `IN AL, 60h`     |
