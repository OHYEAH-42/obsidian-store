**早期批处理系统**（Early Batch Processing System）是操作系统最早的形式，也称为**单道批处理系统**（Single-Stream Batch Processing System）。用户将作业（程序、数据和作业说明书）一起提交给计算机中心，由操作员将一批作业集中输入计算机，监督程序（Monitor）按顺序依次处理。

核心特点：
- **顺序执行**：内存中始终只有一道程序，CPU 严格串行执行
- **CPU 与 I/O 串行**：CPU 等待 I/O 完成，资源利用率极低
- **自动化程度低**：作业切换需人工干预

在早期的批处理系统中，[[程序]]的执行完全串行，不存在[[并发]]能力。
