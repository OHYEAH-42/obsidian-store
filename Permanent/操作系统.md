# 什么是操作系统

Operating System: A body of software, in fact, that is responsible for _making it easy to run programs_ (even allowing you to seemingly run many at the same time), allowing programs to share memory, enabling programs to interact with devices, and other fun stuff like that. (OSTEP)
操作系统：实际上，它是一个软件体系，负责让程序能够轻松运行（甚至让你看似可以同时运行多个程序），允许程序共享内存，使[[程序]]能够与设备交互，以及实现诸如此类的其他有趣功能。（选自《操作系统导论》）

# [[程序]]、[[进程]]、[[线程]]的关系
线程必须隶属于某个进程；进程则必须依附于某个程序，但同一程序可对应多个进程实例。

- **程序**：存储在非易失性存储介质（如硬盘）上的静态指令序列与数据集合，是计算机执行任务的目标代码形态，不具备运行时的动态属性。
- **进程**：程序在特定数据集上的一次动态执行实例。它是操作系统进行资源分配（包括内存地址空间、文件描述符、I/O设备等）的最小独立单位，具有生命周期（创建、就绪、运行、阻塞、终止）。
- **线程**：进程内部可独立调度的最小执行单元。一个进程可包含一个或多个线程，所有线程共享所属进程的堆内存、全局变量等资源，但各自拥有独立的栈空间、程序计数器和寄存器上下文。
