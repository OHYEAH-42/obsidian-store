# 第七章：代码优化 — 深入讲解

## 1. 优化的位置与分类

```
源程序
  → 词法分析
  → 语法分析
  → 语义分析
  → 中间代码生成
  → ★ 中间代码优化（机器无关优化，本章重点）
  → 目标代码生成
  → ★ 目标代码优化（机器相关优化）
  → 目标程序
```

### 优化原则
1. **等价性**：不改变程序语义
2. **有效性**：确实提高速度或减少空间
3. **收益大于代价**：优化本身的开销值得

## 2. 基本块与流图

### 2.1 基本块（Basic Block）的定义

一个**最大**的、**连续**的、只有**一个入口一个出口**的语句序列。

### 2.2 划分基本块的算法

**入口语句**（基本块的第一条）的判断标准：
1. 程序的**第一条**语句
2. 任何**跳转目标**（label 处）
3. 紧跟在**跳转指令后面**的语句

**算法**：
1. 标记所有入口语句
2. 每个入口语句开始一个基本块，直到下一个入口前或程序结尾

### 2.3 示例：do-while 嵌套 → 基本块

**源程序（goto 形式）**：
```
a = 6;
b = 7;
L1: a = x - a;
    if (a < 5) goto L1;
y = 10;
```

**四元组**：
```
<1> (=, 6, 0, a)
<2> (=, 7, 0, b)
<3> (-, x, a, T1)
<4> (=, T1, 0, a)
<5> (j<, a, 5, <3>)
<6> (=, 10, 0, y)
```

**划分结果**：
```
B1 = {<1>, <2>}     ← 第一条语句开始
B2 = {<3>, <4>, <5>}  ← <3> 是跳转目标(入口)
B3 = {<6>}           ← 紧跟跳转后(入口)
```

**流图**：
```
B1 → B2 ⇄ B3
      ↺ (循环!回到B2)
```

### 2.4 嵌套循环示例

```
a = 0; b = 0;
L_b: b = x + 1;
L_a: a = y - a;
     if (a < 5) goto L_a;
     if (b > 7) goto L_b;
```

等价于：
```
a = 0; b = 0;
do
    b = x + 1;
    do
        a = y - a;
    while (a < 5);
while (b > 7);
```

**四元组**：
```
<1> (=, 0, 0, a)
<2> (=, 0, 0, b)
<3> (+, x, 1, T1)         ← L_b 目标
<4> (=, T1, 0, b)
<5> (-, y, a, T2)         ← L_a 目标
<6> (=, T2, 0, a)
<7> (j<, a, 5, <5>)       ← 内循环回边
<8> (j>, b, 7, <3>)       ← 外循环回边
```

**基本块划分**：
```
B1 = {<1>, <2>}           ← 初始化
B2 = {<3>, <4>}           ← b = x+1
B3 = {<5>, <6>, <7>}      ← 内循环体 + 条件判断
B4 = {<8>}                ← 外循环条件判断
```

**流图**：
```
B1 → B2 → B3 ⇄ B4
              ↙
        B2 ←────  (b > 7 时回到 B2)
        B3 ←──    (a < 5 时回到 B3)
```

## 3. 局部优化技术详解

### 3.1 值编号（Value Numbering）—— 核心算法

**目标**：识别并消除相同的计算。

**数据结构**：维护一个哈希表，记录 `(op, VN1, VN2) → VN_result`

**算法**：
```
对每条指令 result = data1 op data2：
  1. 查找 data1 的值编号 VN₁ 和 data2 的值编号 VN₂
     （若 data1 是变量，找它当前的值编号；若是常量，直接取值）
  2. 查找 (op, VN₁, VN₂) 是否已有值编号
     → 若有 VN_result：替换为 result = 已有结果变量
     → 若无：分配新编号 VN_result，记录此计算
  3. 更新 result 变量当前的值编号为 VN_result
```

**示例1**：
```
原始代码                  值编号
a = b + c      →  a₃ = b₁ + c₂           // 新编号 3
b = a - d      →  b₅ = a₃ - d₄           // 新编号 5（b被重定义了）
c = b + c      →  c₆ = b₅ + c₂           // b现在是5号，不是1号 → 新编号6
d = a - d      →  d₅ = a₃ - d₄           // 已有!(a₃-d₄)=5号! → d₅=b₅ → d=b
```
优化后：
```
a = b + c
b = a - d
c = b + c
d = b         ← 替换！
```

**示例2**：
```
a = x + y      →  a₃ = x₁ + y₂
b = x - y      →  b₄ = x₁ - y₂
a = 17         →  a₅ = 17            // a 的值编号变了
c = x + y      →  c₃ = x₁ + y₂      // (+,1,2) 还是编号3
```
优化后：
```
a = x + y
b = x - y
a = 17
c = x + y     ← 算新的（因为此时 x,y 的值编号没变，但需要检查是否被改变；有的话用已有的）
// 这里其实可以优化为 c=a? 不对，a已经被重新赋值了
// 但如果 a 的值没变过，就可以 c=a
```

### 3.2 常量折叠（Constant Folding）

**编译时直接计算常量表达式**。

```
原始 IR                          优化后
T1 = 3 * 5        →           T1 = 15         (3*5=15)
x = T1 + 4        →           x = 19          (15+4=19)
b = 19 - y                     b = 19 - y     (y不是常量，保留)
a = 17                         a = 17
c = 19 + y                     c = 19 + y     (19是常量，y不是)
```

### 3.3 常量传播（Constant Propagation）

将已知的常量值替换变量的使用。

```
原始 IR                      常量传播后
T1 = 15         →           T1 = 15
x = T1 + 4      →           x = 19          (T1 → 15)
b = x - y       →           b = 19 - y      (x → 19)
a = 17          →           a = 17
c = x + y       →           c = 19 + y      (x → 19)
```

两者结合效果更好：
```
T1 = 3 * 5  →  T1 = 15  →  (删除T1，直接传播15)
x = T1 + 4  →  x = 19   →  (T1→15，15+4→19)
```

### 3.4 公共子表达式消除（Common Subexpression Elimination, CSE）

**在更大范围内识别相同计算**（值编号是局部实现方法之一）。

```
a = b + c        ← 第一次 b+c
b = a - d
c = b + c        ← 第二次 b+c，但中间 b 被改变了！不能消除
d = a - d        ← 第二次 a-d，中间 a,d 都没变 → 可消除！
```

### 3.5 复写传播（Copy Propagation）

```
优化后产生了 d = b 这种拷贝，后续使用 d 的地方可以直接用 b。
```

```
d = b           ← 复写语句
e = d + c       →  e = b + c   (直接把 d 替换成 b)
```

### 3.6 死代码消除（Dead Code Elimination）

**两种情况**：
1. **不可达代码**：永远不会执行的代码
2. **无用赋值**：结果不再被使用的赋值

```
x = u * v;      ← 若后面不使用 x → 删除！
t = 9 + d;
x = 3 + t;      ← 上一行对 x 的赋值被覆盖 → 第一行可删除
y = x + 15;
```

```
if (true) x = 5; else x = 10;
→ else 分支永远不会执行 → 删除
→ x = 5;
```

## 4. 全局优化概念

### 4.1 循环相关优化

**循环不变量外提（Loop Invariant Code Motion）**：
将循环内部不随迭代改变的计算移到循环外。

```
变换前：                       变换后：
for (i=0; i<n; i++)           t = a * b;
    x = a * b + c[i];         for (i=0; i<n; i++)
                                  x = t + c[i];
```
`a*b` 在循环中不变，提到外面只算一次。

**强度削弱（Strength Reduction）**：
用代价更低的操作替代昂贵操作。

```
乘法变加法：i*4 → 每次循环加4
乘方变乘法：x² → x*x
乘法变移位：x*8 → x<<3
```

**归纳变量消除（Induction Variable Elimination）**：
```
for (i=0; i<100; i++)          →  j = 400;
    a[i] = 4*i;                for (i=0; i<100; i++)
                                   a[i] = j;  j += 4;
```

## 5. 完整优化示例

**输入代码**：
```
a = b + c
b = a - d
c = b + c
d = a - d
```

**值编号过程**：
```
指令              VN分配              判断
a = b + c    →   a₃ = b₁ + c₂       新编号3
b = a - d    →   b₅ = a₃ - d₄       新编号5
c = b + c    →   c₆ = b₅ + c₂       新编号6（b₅≠b₁）
d = a - d    →   d₅ = a₃ - d₄       已有!(a₃-d₄)=5号!
```

**优化后代码**：
```
a = b + c
b = a - d
c = b + c
d = b        ← 替换
```

→ 接着复制传播：`c = b + c` 若 b 值之后被使用...
→ 检查后若 c 之后不活 → 可能进一步删除

## 6. 重要概念辨析

| 概念 | 含义 | 例子 |
|------|------|------|
| 常量折叠 | 编译时算出常量表达式 | `3*5` → `15` |
| 常量传播 | 用常量值替换变量引用 | `T1=15; x=T1+4` → `x=15+4` → `x=19` |
| 公共子表达式 | 相同表达式重复出现 | `a-d` 出现两次 |
| CSE | 消除重复的公共子表达式 | 第二次 `a-d` → 直接用 `b` |
| 复写传播 | 将 f=g 替换为使用 g | `d=b; e=d+c` → `e=b+c` |
| 死代码消除 | 删除无用代码 | `x=u*v`（后续不引用x） |
| 循环不变量外提 | 把循环内不变计算提到外面 | `for` 内 `a*b` → 提到 `for` 外 |
| 强度削弱 | 用便宜运算替代贵运算 | `i*8` → `i<<3` |

## 7. 流图中的循环结构

**回边（Back Edge）**：在流图中，若存在一条边 `B → H` 且 `H` 支配 `B`（从入口出发到 B 必经 H），则这条边称为回边。

**支配关系**：节点 D 支配节点 N，如果从入口出发到达 N 的每条路径都经过 D。

**自然循环**：由回边 `B → H` 确定的循环，包含 H 和所有能到达 B 而无需经过 H 的节点。
