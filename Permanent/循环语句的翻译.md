# 代码实现

While 循环无需插入标记非终结符，因为 BE 的 TC（条件真出口的首条指令编号）天然就是循环开始地址。

依赖工具函数（与[[逻辑表达式的翻译#版本 B：控制上下文（if/while 中，短路 + 回填）]] 相同）：

```cpp
string encodePair(int a, int b);            // "a,b"
pair<int,int> decodePair(const string& s);  // 解码
int Merge(int c1, int c2);                  // 链合并
void Backpatch(int c, int addr);            // 回填
```

文法 `W → while ( BE ) S1`（无 else）：

```cpp
// ═══ W → while ( BE ) S1  ═══
// 产生式编号：1（假设，实际取决于文法定义顺序）
// rhsLen = 5: [while, (, BE, ), S1]
// attrs[4] = S1."start,chain"
// attrs[2] = BE."TC,FC"

// attrs[0..rhsLen-1] 已在主框架第 1 步中弹出

switch (prodIdx) {
    case 1:  // W → while ( BE ) S1
    {
        auto [s1_start, s1_chain] = decodePair(attrs[4]);
        int c = attrs[2].find(',');
        int TC = stoi(attrs[2].substr(0, c));
        int FC = stoi(attrs[2].substr(c + 1));

        // BE 真出口 → S1 体
        BackPatch(TC, stoi(s1_start));

        // S1 末尾生成无条件跳转 ← 回到条件判断（即 BE 的第一条指令）
        Gen("J", "", "", TC);

        // W 的出口链 = BE 假出口 + S1 出口链
        int chain = Merge(FC, stoi(s1_chain));

        // 起始地址 = TC（循环开始），出口链 = chain
        result = encodePair(TC, chain);
        break;
    }
}
```
