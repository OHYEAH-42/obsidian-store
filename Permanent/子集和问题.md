# 问题

**给定**：一个包含 n 个正整数的集合（或数组）S，以及一个目标整数 T。  
**问**：是否存在一个非空子集，使得该子集中所有元素的和**恰好等于** T？


# 动态规划

## 问题分析

### 思考每一轮的决策，定义状态，得到dp表

对于集合S，假设所有元素求和的值为A，则元素求和得到的整数区间为\[0,A]
设bool dp\[i]=true，表示存在一个子集和为 i 的子集。

### 最优子结构

对于每一个元素$S_i$，从A向下遍历，可以得到：
$$dp[n]=dp[n]||dp[n-S_i]$$
只要dp\[T]=1，则解出题目

### 边界条件和状态转移顺序

显然，dp\[0]为1。

关于状态转移顺序，需要两次循环，外层循环为每一个元素$S_n$
内层循环为$dp[A]$到$dp[S_n]$，这样才能保证$dp[i]$的正确性。


### 伪代码核心：
```
for(auto n : S)
	for(int i=A;i>=n;i--)
		if(dp[i-n])
			dp[i]=1;
```
