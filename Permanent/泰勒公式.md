# 泰勒公式

泰勒公式利用函数在一点的函数值和各阶导数，把附近的函数值写成多项式与余项之和。求极限时常用**带佩亚诺余项的泰勒公式**。设 $f$ 在 $a$ 处具有直到 $n$ 阶的导数，则当 $x\to a$ 时，

$$
f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k
+o\bigl((x-a)^n\bigr).
$$

- $a$：展开点，取 $a=0$ 时称为麦克劳林公式。
- $n$：展开阶数。$f^{(k)}(a)$ 是 $k$ 阶导数在 $a$ 处的值，约定 $f^{(0)}(a)=f(a)$、$0!=1$。
- $o((x-a)^n)$：余项，它与 $(x-a)^n$ 的比值趋于零。

若 $f$ 在包含 $a,x$ 的区间上有连续的 $n+1$ 阶导数，还可将余项写为 $\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$，其中 $\xi$ 介于 $a$ 与 $x$ 之间。这是便于估计误差的拉格朗日余项形式。

## 常用泰勒公式（麦克劳林展开）

下表均在 $x\to0$ 时成立，三角函数的角用弧度。做题时按需要截断；若只保留到 $x^m$，相应的佩亚诺余项可写成 $o(x^m)$。

| 函数 | 在 $0$ 处的常用展开 |
| --- | --- |
| $e^x$ | $1+x+\dfrac{x^2}{2!}+\dfrac{x^3}{3!}+\cdots+\dfrac{x^n}{n!}+o(x^n)$ |
| $\sin x$ | $x-\dfrac{x^3}{3!}+\dfrac{x^5}{5!}+o(x^5)$ |
| $\cos x$ | $1-\dfrac{x^2}{2!}+\dfrac{x^4}{4!}-\dfrac{x^6}{6!}+o(x^6)$ |
| $\ln(1+x)$ | $x-\dfrac{x^2}{2}+\dfrac{x^3}{3}-\cdots+(-1)^{n-1}\dfrac{x^n}{n}+o(x^n)$ |
| $(1+x)^\alpha$ | $1+\alpha x+\dfrac{\alpha(\alpha-1)}{2!}x^2+\dfrac{\alpha(\alpha-1)(\alpha-2)}{3!}x^3+o(x^3)$ |
| $\dfrac{1}{1-x}$ | $1+x+x^2+\cdots+x^n+o(x^n)$ |
| $\tan x$ | $x+\dfrac{x^3}{3}+\dfrac{2x^5}{15}+o(x^5)$ |
| $\arctan x$ | $x-\dfrac{x^3}{3}+\dfrac{x^5}{5}+o(x^5)$ |
| $\arcsin x$ | $x+\dfrac{x^3}{6}+\dfrac{3x^5}{40}+o(x^5)$ |

- $n$：展开阶数，为正整数。
- $\alpha$：固定实数。取 $\alpha=\tfrac12$，可得常用的根式展开 $\sqrt{1+x}=1+\tfrac{x}{2}-\tfrac{x^2}{8}+\tfrac{x^3}{16}+o(x^3)$。

记系数时，可以对照 $\sin x$ 和 $\arctan x$：两者都只含奇次幂、正负交替，但 $\sin x$ 的分母是阶乘 $3!,5!,\ldots$，$\arctan x$ 的分母是奇数 $3,5,\ldots$。

## 求极限时展开到几阶

当低次项相消时，保留到能判定分子与分母相对阶数为止。例如分母是 $x^3$，而分子 $x-\sin x$ 的一次项抵消。由 $\sin x=x-x^3/6+o(x^3)$ 得

$$
\lim_{x\to0}\frac{x-\sin x}{x^3}
=\lim_{x\to0}\frac{x^3/6+o(x^3)}{x^3}=\frac16.
$$

这里只用[[等价无穷小]] $\sin x\sim x$ 会丢掉决定极限的三次项。
