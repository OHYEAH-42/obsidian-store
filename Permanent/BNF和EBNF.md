# BNF（巴科斯范式）

**BNF**（Backus-Naur Form）是描述[[上下文无关文法]]的**元语言**，广泛用于定义程序设计语言的语法规则。
## 基本形式
一条BNF规则写作：

<非终结符> ::= 表达式
- `::=` 表示“定义为”
- `<>` 通常用来括起非终结符（也有不用尖括号的变体）
- 表达式由**终结符**（实际符号）和**非终结符**组成
## 组合方式
| 符号 | 含义 | 示例 |
|:---|:---|:---|
| 并列 | 连接 | `<A> ::= x y` 表示A由x后跟y组成 |
| `|` | 选择（或） | `<A> ::= x \| y` 表示A可以是x或y |
## BNF 示例（算术表达式）

\<expr\> ::= \<expr\> + \<term\> | \<term\>
\<term\> ::= \<term\> * \<factor\> | \<factor\>
\<factor\> ::= ( \<expr\> ) | id

# EBNF（扩展巴科斯范式）

**EBNF**（Extended Backus-Naur Form）是BNF的扩展，增加了描述重复、可选和分组的专用符号，使语法定义更紧凑易读。
## 扩展符号
| 符号        | 含义        | 示例                         |
| :-------- | :-------- | :------------------------- |
| `{ ... }` | 重复零次或多次   | `digit { digit }` 表示至少一位数字 |
| `[ ... ]` | 可选（零次或一次） | `[ + ] number` 表示带可选正号     |
| `( ... )` | 分组        | `(a \| b) c` 表示a c或b c     |
## EBNF 示例（与BNF相同语义，更简洁）

expr = term { ("+" | "-") term }  
term = factor { ("*" | "/") factor }  
factor = id | "(" expr ")" | number

其中：
- `{ ("+" | "-") term }` 表示零个或多个 `+ term` 或 `- term`
- 已包含可选的运算符，无需左递归定义
## BNF vs EBNF 对比
| 特点  | BNF                  | EBNF           |
| :-- | :------------------- | :------------- |
| 重复  | 只能用递归                | `{ ... }` 直接表达 |
| 可选  | 用 `ε` 或特殊产生式         | `[ ... ]`      |
| 分组  | 无（需引入额外非终结符）         | `( ... )`      |
| 可读性 | 规则较多                 | 更简洁            |
| 标准  | ISO 14977（EBNF有国际标准） | 有多种方言          |
## 应用
- **编程语言语法规范**：很多语言标准（如Python、JavaScript）使用类EBNF表示法
- **解析器生成器**：ANTLR、Yacc/Bison 的输入语法接近EBNF风格
