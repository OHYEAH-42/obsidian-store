# 诱导公式

**诱导公式**把形如 $\dfrac{k\pi}{2}\pm\alpha$ 的角的[[三角函数]]值，改写成角 $\alpha$ 的三角函数值。记忆口诀是「奇变偶不变，符号看象限」。

- $k$：整数，表示 $\pi/2$ 的倍数。$k$ 为奇数时，正弦与余弦互换，正切与余切互换。$k$ 为偶数时，保留原函数名。
- $\alpha$：用于化简的角。判号时暂把它看作锐角，判断原角 $\dfrac{k\pi}{2}\pm\alpha$ 落在哪个象限，再看**原函数**在该象限的正负。恒等式在两边都有定义时成立。

| 象限 | 取正值的函数 |
| --- | --- |
| 第一象限 | 正弦、余弦、正切、余切 |
| 第二象限 | 正弦 |
| 第三象限 | 正切、余切 |
| 第四象限 | 余弦 |

例如 $\cos(\pi/2+\alpha)$ 的角里 $k=1$，余弦变正弦。把 $\alpha$ 看成锐角时，原角在第二象限，原函数余弦为负，所以 $\cos(\pi/2+\alpha)=-\sin\alpha$。

## 常用形式

| 角 | 正弦 | 余弦 | 正切 |
| --- | --- | --- | --- |
| $-\alpha$ | $-\sin\alpha$ | $\cos\alpha$ | $-\tan\alpha$ |
| $\frac{\pi}{2}-\alpha$ | $\cos\alpha$ | $\sin\alpha$ | $\cot\alpha$ |
| $\frac{\pi}{2}+\alpha$ | $\cos\alpha$ | $-\sin\alpha$ | $-\cot\alpha$ |
| $\pi-\alpha$ | $\sin\alpha$ | $-\cos\alpha$ | $-\tan\alpha$ |
| $\pi+\alpha$ | $-\sin\alpha$ | $-\cos\alpha$ | $\tan\alpha$ |
| $\frac{3\pi}{2}-\alpha$ | $-\cos\alpha$ | $-\sin\alpha$ | $\cot\alpha$ |
| $\frac{3\pi}{2}+\alpha$ | $-\cos\alpha$ | $\sin\alpha$ | $-\cot\alpha$ |
| $2\pi-\alpha$ | $-\sin\alpha$ | $\cos\alpha$ | $-\tan\alpha$ |

角里含有整圈的平移时，可以先用周期性化简。

$$
\begin{aligned}
\sin(\alpha+2k\pi)&=\sin\alpha, &
\cos(\alpha+2k\pi)&=\cos\alpha,\\
\tan(\alpha+k\pi)&=\tan\alpha, &
\cot(\alpha+k\pi)&=\cot\alpha.
\end{aligned}
$$

- $k$：任意整数。正弦和余弦的最小正周期是 $2\pi$，正切和余切的最小正周期是 $\pi$。
- $\alpha$：实数角。使用正切公式时要求 $\cos\alpha\ne 0$，使用余切公式时要求 $\sin\alpha\ne 0$。

使用表中含 $\tan$ 或 $\cot$ 的等式时，检查原角和化简后的角是否都在各自的定义域内。第一行也可直接由[[奇函数]]和[[偶函数]]的定义记忆。[OpenStax《Trigonometric Identities》](https://openstax.org/books/algebra-and-trigonometry-2e/pages/9-key-equations)

把 $\dfrac{k\pi}{2}$ 当作一个已知角，也可用[[两角和差公式]]推导相应的诱导公式。
