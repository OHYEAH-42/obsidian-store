# LR(1) 前瞻符

**[[LR(1)]] 前瞻符**（Lookahead）是 LR(1) 分析中附加在**[[项目]]**（Item）上的一个终结符，用于决定在哪些输入符号下可以进行归约，从而消除移进/归约冲突。


# 核心概念

- **LR(0) 项目**：`[A → α·β]`，只记录已识别的[[句柄]]部分
- **LR(1) 项目**：`[A → α·β, a]`，其中 `a` 是前瞻符（终结符或 `$` 结束符）
前瞻符 `a` 表示：当使用该产生式 `A → αβ` 进行归约时，**下一个输入符必须是 `a`** 才允许归约。



# 前瞻符的传播规则（闭包与转移）

1. **初始项目**：`[S' → ·S, $]`

2. **闭包**：若 `[A → α·Bβ, a]` 在闭包中，则对每条 `B → γ` 添加 `[B → ·γ, b]`，其中 `b ∈ FIRST(βa)`。
	 **说白了**：已知项目 \[A → α·Bβ, a]       B 的前瞻符 = FIRST(βa)。     ([[FIRST 集]]的复合规则)
	 （*注意α，B，β代表产生式里面的符号，a代表A产生式的前瞻符，B代表B产生式的前瞻符*）

3. **转移**（Goto）：若项目 `[A → α·Xβ, a]`，则转移后得到 `[A → αX·β, a]`，前瞻符不变。
