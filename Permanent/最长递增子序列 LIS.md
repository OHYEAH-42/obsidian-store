# 问题描述

最长递增子序列：例如序列2387145，它的最长递增子序列为2345
对于一个数组A序列：173249658，求它的最长递增子序列。

# 算法设计

## 思考每一轮的决策，定义状态，得到 dp 表

对于每一个数字A\[i]为结尾的最长递增子序列，获取它的该子序列的长度，写入dp\[i]

dp\[i]：数字 i 为结尾的最长递增子序列的长度

## 找出最优子结构

每次比对A\[i]，查看 i 前面的的 dp\[n] ，有以下决策：
- 求出最大值的max(dp\[n])，dp\[i]=dp\[n]+1

得到状态转移方程：
$$
dp[i]=max(dp[n])+1
$$

## 确定边界条件和状态转移顺序

### 边界条件

最开始没放入时，可以将dp所有位都设置为1

状态转移顺序：
每次先读取A\[i]，再遍历dp\[n]


# 算法代码

```
int LIS(vector <int> A)
{
	//初始化dp
	vector<int>dp(A.size(),1)
	//遍历序列A
	for (int i=0; i<A.size(); i++)
	{
		//遍历已经填入数据的dp[]，找出最大值
		for(int j=0; j<i;j++)
		{
			//要求递增
			if (A[j]<A[i])
				//状态转移方程
				dp[i]=max(dp[i],dp[j]+1);
		}
	}
	return max(dp);
}
```
