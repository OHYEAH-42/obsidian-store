# 问题

在[[图]]中找到包含顶点**数量最多**的那个[[团]]


# 分支界限

## 分析

### 解向量

  $$X = \langle x_1, x_2, ..., x_n \rangle, \quad x_i \in {0, 1}$$

  $x_i = 1$ 表示顶点 $i$ 选入团中，$x_i = 0$ 表示不选。

### 搜索空间

子集树（满二叉树），共 $2^n$ 个叶子结点。

### 约束条件

选入团的顶点必须两两相邻（构成完全子图）：

  $$\forall i, j \in {p \mid x_p = 1}, \ (i, j) \in E$$

  检查时只需验证新加入的顶点 $k$ 与团中已有顶点都相邻。


### 剪枝策略

  - 约束剪枝：新顶点与团中已有某个顶点无边 → 不能加入，停止扩展
  - 最优性剪枝：结点上界估计 $F \leq$ 当前界值 $best$ → 停止扩展

### 活结点表

  采用 LC（优先队列），按上界 $F$ 从大到小优先扩展。$F$ 越大的结点越可能通往更大的团。

### 代价函数

$$F = cn + (n - k)$$

  - $cn$：当前已选入团的顶点数
  - $n - k$：剩余待决策的顶点数
  - $F$ 的含义：沿这条分支走到底，团最多能有多大

  初始化：$best = 0$（已知最大团大小初值）。


## 伪代码

```
1. best = 0
  2. 根结点入优先队列（cn=0, k=1）
  3. while 队列非空:
       取 F 最大的结点
       if k > n:                          // 到达叶子
          if cn > best: best = cn
          continue

       分支1（选顶点k入团）:
         if 顶点k与团中已有顶点都相邻:       // 约束剪枝
           F = (cn+1) + (n-k)
           if F > best:                     // 最优性剪枝
             结点(k+1, cn+1)入队

       分支2（不选顶点k入团）:
         F = cn + (n-k)
         if F > best:                       // 最优性剪枝
           结点(k+1, cn)入队

  4. 输出 best
```
