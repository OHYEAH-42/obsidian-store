# 介绍

**子类型（Subtyping）** 是类型系统中的一个核心关系，记为 **`S <: T`**，读作 **“S 是 T 的子类型”** 或 **“S 服从于 T”**。

它的直观含义是：**凡是需要类型 `T` 的值的地方，都可以安全地使用类型 `S` 的值**。这就是著名的 **里氏替换原则（Liskov Substitution Principle）**。


# 基本定义

**子类型**：`S <: T`(或者≤) 表示 `S` 是 `T` 的子类型。
**超类型**：`T` 是 `S` 的超类型。
**关键性质**：任何对 `T` 类型值的操作，也能同样作用于 `S` 类型的值（且行为符合预期）。

# 性质

- X ≤ X
- 如果X继承自Y，那么X ≤ Y
- 如果X ≤ Y，Y ≤ Z，那么 X ≤ Z
