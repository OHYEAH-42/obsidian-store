# 一元二次方程求根公式

**一元二次方程求根公式**根据实系数方程 $ax^2+bx+c=0$（$a\ne 0$）的三个系数直接计算根。

$$
\Delta=b^2-4ac,\qquad
x_{1,2}=\frac{-b\pm\sqrt{\Delta}}{2a}\quad(\Delta\ge 0).
$$

- $x$：未知数。
- $a,b,c$：二次项、一次项和常数项的系数，代入时保留正负号。
- $\Delta$：判别式，决定实根的个数。
- $x_1,x_2$：公式中分别取 $+$ 和 $-$ 得到的根。若两者相等，则为二重根。

| 判别式 | 实根情况 |
| --- | --- |
| $\Delta>0$ | 两个不同的实根 |
| $\Delta=0$ | 一个实根 $-b/(2a)$，重数为 $2$ |
| $\Delta<0$ | 没有实根 |

例如 $2x^2-5x+2=0$，代入 $a=2$、$b=-5$、$c=2$，得 $\Delta=9$，所以两根是 $(5+3)/4=2$ 和 $(5-3)/4=\tfrac12$。可用[[韦达定理]]核对根的和为 $\tfrac52$，积为 $1$。[OpenStax《Solve Quadratic Equations Using the Quadratic Formula》](https://openstax.org/books/intermediate-algebra-2e/pages/9-3-solve-quadratic-equations-using-the-quadratic-formula)
