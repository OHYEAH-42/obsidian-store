# 什么是机器学习

**机器学习**（Machine Learning，ML）是研究如何让计算机利用数据或交互经验，自动改进其在某类任务上表现的方法。学习算法根据经验调整模型或决策规则，使其能够完成预测、识别、生成或行动选择等任务。

许多机器学习方法通过[[拟合]]训练数据、优化[[损失函数]]来学习规律，其重要目标是获得对未见数据同样有效的[[泛化能力]]。[[神经网络]]是机器学习中使用的一类模型。

# 在整个领域中的位置

[[人工智能]]是更大的研究领域，机器学习是其中利用数据或经验学习的方法，[[深度学习]]则是机器学习中利用多层神经网络学习表示的一类方法。因此，学习机器学习既包括神经网络，也包括线性模型、树模型等其他方法。参考：[《动手学深度学习》导论](https://d2l.ai/chapter_introduction/index.html)。

理解一个机器学习方法时，可以分别问：它用什么反馈学习？要完成什么任务？采用什么模型？目前处于哪个训练阶段？这些维度可以组合，不是一份互斥的分类清单。

# 按学习信号区分

| 学习方式 | 学习信号从哪里来 | 主要在做什么 | 例子 |
| :--- | :--- | :--- | :--- |
| [[监督学习]] | 输入对应的目标标签 | 学习输入到目标输出的映射 | 用已知房价预测新房价格 |
| [[无监督学习]] | 数据自身的结构、分布 | 发现分组或学习表示 | 按用户行为自动分组 |
| [[自监督学习]] | 从数据自身构造的目标或关系 | 通过预测、重建等目标学习表示 | 根据前文预测下一个词元 |
| [[半监督学习]] | 有标签与无标签数据共同提供信息 | 利用未标注样本辅助目标任务 | 结合少量标注图片和大量未标注图片训练分类器 |
| [[强化学习]] | 采取行动后获得的奖励反馈 | 学习使长期回报更高的行动策略 | 游戏决策、机器人控制 |

自监督学习与无监督学习的边界存在术语上的不同划分：从“不依赖外部人工标签”的角度，自监督常归入广义无监督学习；从训练方式看，它又有从数据构造的监督目标。两者不能简单理解为完全无关的分支。参考：[自监督学习综述](https://arxiv.org/abs/2006.08218)。

同一个系统可以先自监督预训练，再进行监督微调，随后结合强化学习；这些方法并不要求只能选一种。

# 常见任务

| 任务 | 输出或目标 | 例子 |
| :--- | :--- | :--- |
| [[分类]] | 离散类别或类别概率 | 判断邮件是否为垃圾邮件 |
| [[回归]] | 数值目标 | 预测价格或温度 |
| [[聚类]] | 根据数据结构形成的分组 | 在没有类别标签时划分用户群体 |
| [[降维]] | 较低维的数据表示 | 压缩特征或可视化高维数据 |
| 生成 | 符合所学分布的新内容 | 生成文本或图像 |
| 序贯决策 | 随环境变化选择行动 | 控制游戏角色或机器人 |

“监督学习”描述反馈形式，“分类”描述任务。分类常采用监督学习，聚类常采用无监督学习；生成任务可以使用自监督训练，决策任务可以使用强化学习。

# 常见模型和方法

[[传统机器学习]]整理了线性模型、树与集成、核方法、概率模型、聚类、降维及配套评估方法。

- [[线性模型]]：用特征的加权组合形成预测值或分数，结构较简单。
- [[决策树模型]]：按特征条件逐步分支，形成预测规则，可用于分类和回归。
- [[最近邻方法]]：根据训练样本中邻近对象的信息完成预测。
- [[神经网络]]：组合多层可学习变换，学习复杂表示；多层感知器、卷积网络等是相关结构。

学习方式与模型结构是不同维度。例如，神经网络可以用于监督分类、自监督表示学习，也可以用于强化学习中的策略表示。

# 一个典型的开发流程

以监督学习任务为例：

1. **明确任务和数据**：确定输入[[特征]]、目标[[标签（机器学习）|标签]]以及评价方式。
2. **划分数据**：使用[[训练集]]学习，用[[验证集]]选择方案，保留[[测试集]]做最终评估。
3. **选择模型和配置**：选择模型结构、损失函数及学习率等[[超参数]]。
4. **训练**：使用训练数据拟合模型；神经网络通常通过[[反向传播]]计算梯度，再由[[优化器]]更新参数。
5. **验证与调整**：检查未见数据表现，判断是否存在[[欠拟合]]或[[过拟合]]，再调整模型或训练设置。
6. **最终评估与使用**：方案确定后评估测试集表现，并通过[[推理（机器学习）|推理]]对新输入产生输出。

具体数据划分应符合任务场景，例如时间序列通常需要按时间顺序划分。测试数据不能反复用于选择方案，否则无法独立评估泛化能力。参考：[数据集划分](https://developers.google.com/machine-learning/crash-course/overfitting/dividing-datasets)。

训练损失只是优化目标，评价指标还应反映实际任务需求。模型在训练集上的误差小，并不意味着在新数据上一定有效。

# 与已有神经网络笔记的联系

[[层]]、[[线性层]]、[[卷积层]]和[[自注意力]]描述网络的结构或计算机制；它们不决定训练信号来自哪里。[[预训练]]与[[微调]]描述训练阶段，也不等同于某一种学习方式。

以语言模型为例，一条常见路线是：用预测文本内容的自监督目标预训练，再用带目标回答的数据进行监督微调，之后可使用[[基于人类反馈的强化学习|RLHF]]等方法优化行为。具体模型不一定采用全部阶段。

# 建议阅读顺序

先了解[[监督学习]]、[[无监督学习]]、[[自监督学习]]、[[半监督学习]]与[[强化学习]]的区别，再读[[分类]]、[[回归]]、[[聚类]]和[[降维]]。随后理解训练、验证、测试的分工，以及[[泛化能力]]、过拟合与欠拟合。最后结合已有的神经网络笔记，理解深度学习中的模型计算和训练过程。
