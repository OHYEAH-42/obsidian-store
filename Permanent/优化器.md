# 什么是优化器

**优化器**（Optimizer）是根据[[梯度]]更新模型参数、使[[损失函数]]尽可能减小的算法。

# 核心更新公式

以最基本的梯度下降为例，在目标函数可微的位置，参数沿负梯度方向更新：

$$
\theta_{t+1}=\theta_t-\eta\nabla_{\theta}J(\theta_t)
$$

- $t$：当前更新步的编号。
- $\theta_t$：更新前的模型参数，包括[[权重]]、[[偏置]]等可学习参数。
- $\theta_{t+1}$：更新后的模型参数。
- $J(\theta_t)$：当前参数下的损失目标值，通常是训练集或当前小批量上的平均损失。
- $\nabla_{\theta}J(\theta_t)$：损失目标对参数的[[梯度]]，通常由[[反向传播]]计算。
- $\eta>0$：[[学习率]]，控制每次更新的步长。

减去梯度是为了沿损失局部下降的方向调整参数，但有限步长的更新不保证每次都使损失减小。学习率过大可能导致训练震荡或发散，过小则会使收敛速度很慢。不同优化器会在这一基础上引入动量、自适应步长等更新机制。

# 常见优化器

Batch GD、单样本 SGD、Mini-batch SGD 区分每次用多少数据计算梯度；AdaGrad、RMSProp、Adam、AdamW、Muon 则主要区分如何利用梯度和历史状态构造更新。两种划分可以结合，例如 Adam 通常也使用小批量梯度。

- **[[批量梯度下降|Batch GD]]**：每次使用整个训练集的平均梯度更新参数。
- **[[SGD]]**：严格意义上每次随机选一个样本更新；实践中也常作为小批量版本的统称。
- **[[小批量随机梯度下降|Mini-batch SGD]]**：每次使用随机选取的一小批样本的平均梯度更新。
- **[[动量（优化）|Momentum]]**：累积历史梯度形成动量，减少震荡并加速沿一致方向的更新。
- **[[AdaGrad]]**：累计各参数的历史梯度平方，逐参数调整更新尺度。
- **[[RMSProp]]**：维护梯度平方的指数移动平均，逐参数调整更新尺度。
- **[[Adam]]**：同时维护梯度的一阶矩和二阶矩估计，为不同参数自适应调整更新尺度。
- **[[AdamW]]**：在 Adam 的自适应更新之外，单独施加解耦的权重衰减。
- **[[Muon]]**：对矩阵参数的动量更新方向作近似正交化，再用于更新参数。

# 理解优化器的演进

可以按“希望改善什么问题”理解这些方法，它们存在不同分支，也常组合使用：

| 方法 | 希望改善的问题 | 核心变化 |
| --- | --- | --- |
| [[SGD]] → [[动量（优化）\|Momentum]] | 更新只看当前梯度，可能在某些方向反复震荡 | 保留历史方向信息，形成动量 |
| SGD → [[AdaGrad]] | 不同参数方向适合不同的更新尺度 | 用各参数的历史梯度平方和调整尺度 |
| AdaGrad → [[RMSProp]] | 平方和持续积累，可能使后期步长过小 | 改用梯度平方的指数移动平均，逐渐淡忘旧信息 |
| Momentum 与 RMSProp 的思路 → [[Adam]] | 同时平滑方向并自适应调整尺度 | 维护梯度及梯度平方的移动平均，并作零初始化偏差修正 |
| Adam → [[AdamW]] | 把 L2 惩罚加入 Adam 梯度时，衰减也会受自适应缩放影响 | 将权重衰减与自适应梯度更新解耦 |
| 矩阵更新方向的分支：[[Muon]] | 希望利用权重矩阵的整体结构组织更新 | 对矩阵的动量方向作近似正交化，通常与 AdamW 分工使用 |

表中的箭头表示理解思路上的联系。AdaGrad 的“历史累加”和 Momentum 的“方向累积”作用不同；Adam 也不能直接等同于任意一种 Momentum 与 RMSProp 实现的简单拼接。选择方法仍需结合具体模型和训练设置。

参考：[《动手学深度学习》：AdaGrad 与 RMSProp 的关系](https://d2l.ai/chapter_optimization/rmsprop.html)、[Adam 原论文](https://arxiv.org/abs/1412.6980)、[AdamW 原论文](https://arxiv.org/abs/1711.05101)、[Muon 作者实现](https://github.com/KellerJordan/Muon)。

# 与反向传播的关系

一次典型训练迭代包含：

1. [[前向传播]]得到预测。
2. [[损失函数]]计算误差。
3. [[反向传播]]计算各参数的梯度。
4. 优化器使用这些梯度更新参数。

因此，反向传播解决“梯度是多少”，优化器解决“如何利用梯度更新参数”。优化器不能保证找到全局最优解，其效果还受到学习率、初始化、数据分布和损失曲面等因素影响。
