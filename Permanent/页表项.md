# 什么是页表项

**页表项**（Page Table Entry，PTE）是[[页表]]中的一个记录。在[[Sv39]]中，有效的非叶子项指向下一级页表，叶子项描述实际映射的物理页及权限；一个项的物理页号并不总是数据页的地址。

页表项=物理页号+标志位

Sv39 的一个 PTE 占 8 字节。基本格式包含物理页号、有效位 V、读写执行位 R/W/X、用户访问位 U、全局位 G、访问位 A、脏位 D 和软件保留字段。有效位及权限编码必须同时符合规则，不能仅凭某一个权限位判断整个条目合法。

| ---- | ------- | ---- |
