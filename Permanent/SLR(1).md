# SLR(1) 文法

SLR(1) = **Simple LR(1)**。**S** 表示"简单"，它是对 [[LR(0)]] 的改进——用 [[FOLLOW 集]]限制归约的适用范围，减少冲突。一种[[语法分析]]中[[自底向上的语法分析]]的方法

---

# 为什么需要 SLR(1)？

LR(0) 的问题是：**归约项目在任何输入符号下都执行归约**，这太"粗暴"了。

### 经典冲突

```
I₁ = {E' → E·,  E → E· + n}
      ↑归约项目    ↑移进项目（输入为 +）
```

LR(0) 的做法：`E' → E·` 对所有输入符号（包括 `+`）都归约，和 `E → E· + n` 的移进 `+` 冲突 → **不是 LR(0)**。

SLR(1) 的想法：`E' → E·` 只在 FOLLOW(E') = { $ } 时归约。输入 `+` 不在 FOLLOW(E') 中，所以只移进不归约 → **冲突消除**。


## SLR(1) 的核心改进

**只在 FOLLOW(A) 包含的输入符号上执行归约 A → α**。

|      | LR(0)                          | SLR(1)                                    |
| ---- | ------------------------------ | ----------------------------------------- |
| 归约条件 | `A → α· ∈ Iᵢ` → 对**所有** a 填 rⱼ | `A → α· ∈ Iᵢ` → 仅对 a ∈ **FOLLOW(A)** 填 rⱼ |

# SLR(1)分析表构造

与[[LR(0)]]依旧类似，唯一区别是仅归约在文法符号对应的[[FOLLOW 集]]的元素。
以[[LR(0)]]中的例子为例

(0)E‘ -> E
(1)E -> E +T
(2)E -> T
(3)T -> ( E )
(4)T -> a
