将数据从一个位置复制到另一个位置的[[指令]]即是**数据传送指令**

MOV指令包含两个[[操作数]]：
- 源操作数(Source operand): [[立即数]]、[[内存引用]]、[[寄存器]]
- 目的操作数(Destination operand): [[内存引用]]、[[寄存器]]
此外，x86-64处理器有一条限制，两个操作数不能都是内存，所以，当我们需要将一个内存地址上的数据复制到另一个内存地址上的时候，就需要两条指令：
	mov memory register
	mov register memory

## 特殊情况

当movq的源操作数是立即数时，立即数只能是32位的补码表示
 然后将该立即数进行符号位扩展，再将立即数传送到目的位置。

 **当立即数是32位的时候怎么办？**
	movabsq，这条指令的源操作数可以是任意的64位立即数，但目的操作数只能是寄存器

当movl的目的操作数是寄存器时，会把该寄存器的高四字节设置为0.

当源操作数的数位小于目标操作数时，需要进行零扩展或者符号位扩展
