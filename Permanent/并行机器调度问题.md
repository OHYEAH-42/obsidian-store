# 问题

现有n个完全不同的任务，以及k台一模一样的机器，这些机器可以同时工作。每个任务耗时不同。
求：如何分配让所有的机器都尽早完成任务（就是看最后一台机器停工时间）。

# 回溯算法


## 分析

只讲比较重要的了。

最开始先将任务完成时间由大到小排列，根节点为完成时间大的任务

### 解空间：k叉树，层数为n，表示第n个任务分配给了第k个机器

比如3台机器，则最开始可以用数组来存储机器处理任务的时间为\[0，0，0]
假设任务1的时间为7，分配给第一个机器，则数组变化为\[7,0,0]
利用这个数据结构配合树形结构就能遍历所有可能。

### 剪枝

利用BEST来表示到达叶子节点后，每个不同叶子节点的完成时间。

## 例子：


**任务耗时**：t=\[5,3,4,2,6]t=\[5,3,4,2,6]（共 n=5n=5 个任务）  
**机器数量**：k=3k=3 台  
**总耗时**：sum=20sum=20，理论最优下界是 ⌈20/3⌉=7⌈20/3⌉=7。

**核心思路**：按顺序把每个任务依次分配给 3 台机器，用 DFS 一直探到底。一旦发现某台机器的当前负载已经 **大于等于** 当前找到的最佳值（Best），立刻停止这条支路。

**关键预处理（提升剪枝效率）**：将任务按耗时 **从大到小排序**，变成 `[6, 5, 4, 3, 2]`。让大任务先分配，能更快地接近最优解，从而让 Best 尽早变小，剪掉更多分支。

**手推搜索过程**（带剪枝）：

1. **初始状态**：Best = 无穷大（∞），三台机器负载为 \[0, 0, 0]。
    
2. **分配任务 6**（第一个）：
    
    - 分给 M1 → \[6, 0, 0]
        
    - 分给 M2 → \[0, 6, 0]（与分给 M1 本质对称，通常加上“机器编号不重复”剪枝，简化只走 M1）。
        
3. **分配任务 5**（第二个）：
    
    - 放 M1：\[11, 0, 0]；放 M2：\[6, 5, 0]；放 M3：\[6, 0, 5]（M2和M3对称，留一个）。
        
    - 优先探索负载均衡的，比如走 \[6, 5, 0]。
        
4. **分配任务 4**（第三个）：
    
    - 放 M1：\[10, 5, 0]；放 M2：\[6, 9, 0]；放 M3：\[6, 5, 4]。
        
    - 继续探索，假设走 \[6, 5, 4]。
        
5. **分配任务 3**（第四个）：
    
    - 放 M1：\[9, 5, 4]；放 M2：\[6, 8, 4]；放 M3：\[6, 5, 7]。
        
    - 继续探到底，假设走\[6, 5, 7]。
        
6. **分配任务 2**（最后一个）：
    
    - 放 M1：\[11, 5, 7] → 最大负载 **11** → Best = 11。
        
    - 放 M2：\[6, 7, 7] → 最大负载 **7** → Best = 7。
        
    - 放 M3：\[6, 5, 9] → 最大负载 9（不如7，但已经得到一个完整解）。
        
7. **此时 Best = 7**（触及理论下界！）。
    
8. **触发强力剪枝**：回溯到上层，当任何节点的某台机器负载 ≥ 7 时，直接剪枝（因为后续任务耗时都 >0，负载只会更大，不可能小于7）。
    
    - 比如在分配任务 4 时，如果出现负载 \[10, 5, 0]，因为 10 ≥ 7，这一整支全部砍掉，不再往下递归。
        

**结论**：回溯法找到了最优解 **7**，且因为触及下界，后续大量分支被“大于等于Best”的规则砍掉。

# 分支界限

**核心思路**：回溯是纵向（深度优先）硬闯，分支限界是横向扩展，并给每个节点算一个 **下界（LB）**。如果节点的 LB ≥ 当前 Best，直接淘汰（不入队）。

**下界计算公式（非常重要，考试常考）**：  
对于某个节点（当前已分配了一些任务），其下界 =  
LB=max⁡(当前所有机器的最大负载,⌈所有任务总耗时/k⌉)LB=max(当前所有机器的最大负载,⌈所有任务总耗时/k⌉)  
（注：因为总耗时固定20，三台机器再怎么平均，最大负载也不可能低于 ⌈20/3⌉=7⌈20/3⌉=7，同时也不可能低于当前的最高负载）。

**搜索过程（使用优先队列，LB 小的优先扩展）**：

1. **根节点**：负载 \[0, 0, 0]，LB = max(0, 7) = **7**。入队。
    
2. **扩展根节点（分配任务 6）**：
    
    - 子节点 A：分配给 M1 → \[6, 0, 0]，LB = max(6, 7) = **7**。入队。
        
    - 子节点 B：分配给 M2 → \[0, 6, 0]，LB = **7**。入队（对称，但保留）。
        
    - （此时队里有多个 LB=7 的节点）。
        
3. **扩展 LB=7 的节点（假设扩展\[6, 0, 0]，分配任务 5）**：
    
    - 分配给 M1 → \[11, 0, 0]，LB = max(11, 7) = **11**。入队。
        
    - 分配给 M2 → \[6, 5, 0]，LB = max(6, 7) = **7**。入队（这个很有潜力）。
        
    - 分配给 M3 → \[6, 0, 5]，LB = **7**。入队。
        
4. **继续优先扩展 LB=7 的节点（扩展 \[6, 5, 0]，分配任务 4）**：
    
    - 分配给 M1 → \[10, 5, 0]，LB = max(10, 7) = **10**。
        
    - 分配给 M2 → \[6, 9, 0]，LB = **9**。
        
    - 分配给 M3 → \[6, 5, 4]，LB = max(6, 7) = **7**。入队（这条路最均衡）。
        
5. **扩展 \[6, 5, 4]（分配任务 3）**：
    
    - 分配给 M1 → \[9, 5, 4]，LB = **9**。
        
    - 分配给 M2 → \[6, 8, 4]，LB = **8**。
        
    - 分配给 M3 → \[6, 5, 7]，LB = max(7, 7) = **7**。入队。
        
6. **扩展 \[6, 5, 7]（分配任务 2）**：
    
    - 分配给 M1 → \[8, 5, 7]，最大负载 8 → 得到完整解，Best = **8**。
        
    - 分配给 M2 → \[6, 7, 7]，最大负载 7 → 得到完整解，Best = **7**（触及最优）。
        
    - 分配给 M3 → \[6, 5, 9]，最大负载 9（忽略）。
        
7. **终止与剪枝**：此时 Best = 7。队列中还存着之前那些 LB=8, 9, 10, 11 的节点。因为它们的 LB（8,9...）都 **≥ Best（7）**，所以全部被抛弃，不再扩展。
    

**结论**：分支限界法利用下界 7，一路引导算法走向最均衡的分支，在找到最优解 7 后，直接杀死了队列里所有 LB≥7 的节点，省去了回溯法中大量无谓的深度探索。
