# 极限的运算方法

求[[函数极限]]，先看自变量趋向哪里，再看各部分趋向什么。直接代入得到 $0/0$ 只说明商的四则运算法则暂时用不上，下一步要根据式子的结构选方法。

| 看到的结构 | 可以先试的方法 | 判断依据 |
| --- | --- | --- |
| 和、差、积、商的各部分都有有限极限 | [[极限的四则运算]] | 商还要求分母极限非零 |
| 乘积或商中出现趋于零的标准因子 | [[等价无穷小]] | 可替换整个因子，如 $\sin u\sim u$ 要求 $u\to0$ |
| $0/0$ 或 $\infty/\infty$ 型，分别求导后更简单 | [[洛必达法则]] | 检查可导条件以及导数之商的极限 |
| 分子或分母有多个低次项抵消 | [[泰勒公式]] | 展开到能看出抵消后剩余项的阶数 |
| 有振荡项，或能找到同极限的上下界 | [[夹逼定理]] | 上下界须在同一趋近过程中趋于同一值 |

例如 $(x-\sin x)/x^3$ 与 $x\sin(1/x)$ 都含有正弦函数。前者的一次项抵消，适合展开到三阶；后者的正弦因子保持有界，用夹逼更直接。
