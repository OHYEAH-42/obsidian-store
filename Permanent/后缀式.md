# 后缀式（逆波兰表示法）

- **结构**：操作数在前，运算符在后。无括号，无优先级。
- **计算方式**：依赖**操作数栈**，遇数压栈，遇运算符弹栈计算，结果压回栈顶。
- **示例**：`a = b * c + d` → `b c * d + a =`
- **特点**：
  - 结构极简，解释执行快
  - 只能表示表达式，难以处理控制流
  - 难以优化（中间结果在栈中不可见）

# 后缀式的表示
## 算数表达式

eg： $((a+b)*(a-c)-d)*(x+y)$

**处理思路**：从外到内，一层一层转化为后缀式。

- 最外层可以看到两个部分：$((a+b)*(a-c)-d)$、$(x+y)$，分别设为E<sub>1</sub>和E<sub>2</sub>。原式转化为E<sub>1</sub>E<sub>2</sub>*
- 先处理E<sub>1</sub>=$((a+b)*(a-c)-d)$，可以化为两部分$(a+b)*(a-c)$和$d$，设E<sub>3</sub>=$(a+b)*(a-c)$，则原式转化为E<sub>3</sub>d-E<sub>2</sub>*
- 再处理E<sub>3</sub>=$(a+b)*(a-c)$，可以看作两个部分$a+b$和$a-c$，分别设为E<sub>4</sub>和E<sub>5</sub>，原式化为
E<sub>4</sub>E<sub>5</sub>$*d-$E<sub>2</sub>*
- E<sub>2</sub>、E<sub>4</sub>、E<sub>5</sub>的后缀式结果显然，分别为$xy+$、$ab+$、$ab-$。
- 最后代入式子中，$ab+ab-*d-xy+*$

## 条件语句

if（u）S1 else S2
对应的后缀表示为
u L1 BZ S1 L2 BR S2

>- BZ为双目运算符，表示当u不成立（为0）时，转向标号L1部分继续执行
>- L1表示语句S2开始执行的位置
>- BR为一个单目运算符，表示无条件转向L2部分继续执行
>- L2表示该条件语句下一个语句开始执行的位置

eg：
if（m>n）k=1；else m=0；
后缀表示：
m n >10 BZ k1= 20 BR
10:m0=
20:下一个语句
