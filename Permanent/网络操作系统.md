**网络操作系统**（Network Operating System, NOS）是在通用操作系统的基础上增加网络通信和资源共享功能的操作系统，主要用于管理网络中的计算机资源和通信。

核心功能：
- **网络通信**：支持 TCP/IP 等网络协议栈
- **资源共享**：文件共享、打印服务、数据库共享
- **安全管理**：用户认证、访问控制、数据加密
- **C/S 架构**：提供客户端/服务器模式的服务管理

典型系统：
- Windows Server 系列
- Linux（各种服务器发行版）
- UNIX（如 Solaris、AIX）
- Novell NetWare（历史）

与[[分布式操作系统]]的区别：网络操作系统中的各台计算机有明确的本地/远程之分，用户能感知到网络的存在；而分布式操作系统则追求对资源的透明访问。
