# 什么是深度学习

**深度学习**（Deep Learning）是[[机器学习]]中利用多层可学习计算来形成层次化数据表示的方法，通常以深层[[神经网络]]实现。它可以结合[[监督学习]]、[[自监督学习]]、[[无监督学习]]或[[强化学习]]，因此描述的是模型和表示学习方式，而不是与这些学习范式互斥的另一类监督信号。

学习[[神经元]]、[[线性层]]、[[激活函数]]、[[反向传播]]和[[优化器]]，是在学习深度学习的共同基础。不过，“神经网络”的范围更广，并非每个浅层神经网络都必须称为深度学习；“深”通常强调多层变换形成的层次化表示，而非一个统一的层数门槛。

# 主要结构与计算机制

| 名称 | 核心特点 | 需要区分的关系 |
| :--- | :--- | :--- |
| [[多层感知器\|MLP]] | 组合全连接变换和非线性激活，学习输入到输出的映射 | 是[[前馈神经网络]]的典型形式，也可作为其他架构的内部模块 |
| [[卷积神经网络\|CNN]] | 使用局部连接和共享卷积核提取结构化特征 | 常用于图像，也可处理音频或时间序列 |
| [[循环神经网络\|RNN]] | 沿序列递归更新隐藏状态，使过去影响当前计算 | [[长短期记忆网络\|LSTM]]和[[门控循环单元\|GRU]]属于门控循环变体 |
| [[注意力机制\|Attention]] | 根据查询与键的匹配程度，动态加权汇总值 | 是计算机制，可以与 RNN、CNN 等结构组合，不与它们构成互斥分类 |
| [[Transformer]] | 以注意力和逐位置前馈网络为主要模块，结合残差连接、归一化与位置信息 | 是完整架构，不等于单个 Attention 层，也不意味着一定是自回归模型 |

这些名称不是一条“后者完全替代前者”的升级链。例如，Transformer 内部通常仍有 MLP；CNN、RNN 也可以加入注意力。结构选择、训练信号与任务类型是不同维度。

# 卷积与序列表示

[[卷积层]]使用可学习的[[卷积核]]在局部窗口内计算，[[池化层]]则按固定规则汇总区域信息；叠加这些模块会改变输出对应的[[感受野]]。

[[隐藏状态]]在 RNN 中沿时间步传递；其训练通常使用[[时间反向传播]]。LSTM 与 GRU 通过门控控制历史信息的保留和更新，但不等于可以无限、无损地记住全部历史。

# 注意力与 Transformer 的组成关系

- [[自注意力]]与[[交叉注意力]]区分查询、键和值来自哪里；[[多头注意力]]区分是否使用多组投影并行计算，它们可以组合。
- [[位置编码]]向表示或注意力计算提供位置信息；[[嵌入表]]则将离散编号转换为可学习向量。
- [[因果掩码]]限制读取未来位置，常服务于[[自回归模型]]；它不等于位置编码。
- [[残差连接]]跨过模块传递输入，[[层归一化]]调整特征尺度，前馈子层变换各位置的特征；三者与注意力承担不同职责。
- [[编码器-解码器架构]]是一种输入与输出的组织方式。原始 Transformer 采用该架构，后续也有只保留编码器或解码器式模块的形式。

[[语言模型]]描述学习语言概率规律的任务，可以由 RNN 或 Transformer 实现。架构本身不是[[预训练]]或[[微调]]，也不直接决定采用监督、自监督还是强化学习。

# 共同的计算与训练基础

数据、参数和中间表示通常用[[张量]]组织。训练时，[[前向传播]]得到输出，[[损失函数]]形成优化目标，[[自动微分]]与反向传播计算[[梯度]]，再由优化器更新参数。

[[梯度消失]]和[[梯度爆炸]]描述梯度传递中的两类困难；[[梯度裁剪]]用于限制过大的梯度，并非解决所有不稳定问题的通用办法。[[归一化]]、[[批归一化]]和层归一化关注数值尺度，[[正则化]]与[[Dropout]]则可用于改善泛化、减轻[[过拟合]]。

[[混合精度训练]]组合使用 FP32、FP16 或 BF16 等精度，[[TF32]]改变部分 FP32 运算的内部计算精度，[[FlashAttention]]优化注意力的显存访问。它们描述不同层面的计算效率优化，不是新的学习范式或模型架构。
