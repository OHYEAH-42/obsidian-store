# 什么是大语言模型

**大语言模型**（Large Language Model，LLM）是通过大规模数据和计算进行训练、具有较大参数规模的神经[[语言模型]]。它学习语言的统计规律和可用于多种任务的表示，现代常见架构是 [[Transformer]]；“大”是相对性的描述，没有适用于所有模型和时期的固定参数数量门槛。

常见的生成式 LLM 采用[[自回归模型|自回归]]方式，根据已有上下文预测下一个词元，再逐步生成文本。它通常先通过[[自监督学习]]进行[[预训练]]，获得可复用的语言能力，再通过[[后训练]]改善指令遵循、对话行为或特定任务表现。

LLM 既可以指预训练后的基座模型，也可以指经过[[监督微调|SFT]]等后训练的模型。模型本身与聊天界面是不同层次：聊天助手是使用 LLM 构建的一类应用，不能把 LLM 仅理解为聊天软件。

参考：[A Survey of Large Language Models](https://arxiv.org/abs/2303.18223)、[The Llama 3 Herd of Models，§2](https://arxiv.org/html/2407.21783v3#S2)。
