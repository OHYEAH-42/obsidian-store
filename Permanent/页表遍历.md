# 什么是页表遍历

**页表遍历**（Page Table Walk）是从根页表开始，依据[[虚拟地址]]各级索引逐步读取[[页表项]]，直到找到合法叶子映射或检测到错误的过程。[[Sv39]]通常由硬件在 TLB 未命中时完成；内核也可用软件遍历页表以查询或修改映射。遇到较高层级的[[超级页]]叶子项时，不再继续访问下级表。
