**多道批处理系统**（Multi-programmed Batch Processing System）是早期批处理系统的升级，内存中同时驻留多道[[程序]]，当一道程序等待 I/O 时，CPU 自动切换到另一道程序运行。

核心特点：
- **多道并行**（宏观）：多道程序同时在内存中
- **交替执行**（微观）：单核 CPU 在程序间交替切换
- **CPU 与 I/O 并行**：一道程序做 I/O 时，另一道程序用 CPU，大幅提高资源利用率

技术支持：
- **[[中断]]技术**：设备完成后通过中断通知 CPU
- **通道技术**：专用的 I/O 处理器，使 I/O 与 CPU 并行工作

多道批处理系统真正引入了[[并发]]的概念，但由于是批处理方式，用户无法与程序交互（缺乏交互性）。
