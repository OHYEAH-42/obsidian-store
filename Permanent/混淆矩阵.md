# 什么是混淆矩阵

**混淆矩阵**（Confusion Matrix）是按真实类别与预测类别统计数量的表。以下二分类约定中，行为真实类别，列为预测类别：

| | 预测为正 | 预测为负 |
| :--- | :--- | :--- |
| 实际为正 | TP：真正例 | FN：假负例 |
| 实际为负 | FP：假正例 | TN：真负例 |

TP、TN 表示正确判断，FP、FN 表示两类错误。由这些计数可计算[[分类评价指标]]；多分类时可扩展为真实类别数与预测类别数对应的矩阵。

参考：[定义与指标来源](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.confusion_matrix.html)。
