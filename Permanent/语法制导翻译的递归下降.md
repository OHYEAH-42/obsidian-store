# 与 LR 方式的区别

| 维度 | LR 语法制导翻译 | 递归下降语法制导翻译 |
|------|---------------|-------------------|
| 驱动方式 | 分析表驱动（状态栈 + 符号栈） | 函数调用驱动（系统调用栈） |
| 属性传递 | `valStack`（属性栈）统一传递 | 函数返回值（综合属性）、函数参数（继承属性） |
| 语义动作时机 | 归约时统一触发 | 与语法分析代码**交织**在一起 |
| 非终结符 | 归约时由 `prodIdx` 区分 | 每个非终结符对应一个独立的函数 |
| TC/FC 传递 | 编码为 `"TC,FC"` 字符串入 `valStack` | 函数直接返回 `pair<int,int>` |

# 数据结构

与 LR 方式相同，见[[语法制导翻译的LR方式#数据结构]]。

常用工具（与 LR 共享）：

```cpp
// ═══ 链操作（四元组 result 字段存下一跳编号，0 = 链尾）═══

int Merge(int p1, int p2) {
    if (p2 == 0) return p1;
    if (p1 == 0) return p2;
    int tail = p1;
    while (quads[tail].result != 0)
        tail = quads[tail].result;
    quads[tail].result = p2;
    return p1;
}

void BackPatch(int chain, int targetLabel) {
    for (int p = chain; p != 0; ) {
        int next = quads[p].result;
        quads[p].result = targetLabel;
        p = next;
    }
}

int Gen(string op, string a1, string a2, int res) {
    quads.push_back({op, a1, a2, res});
    return NextStat++;
}
```

# 算术表达式的递归下降翻译

每个非终结符对应一个函数，函数返回值就是该表达式的**属性**。

## 文法

```
E → E + T | E - T | T
T → T * F | T / F | F
F → ( E ) | i
```

## LL(1) 改造（消除左递归）

```
E  → T E'
E' → + T E' | - T E' | ε
T  → F T'
T' → * F T' | / F T' | ε
F  → ( E ) | i
```

## 四元组版本

```cpp
// ═══ 全局变量 ═══
Token lookahead;          // 当前输入的 Token
TokenStream& input;       // 输入流
SymbolTable& symbolTable; // 符号表

void match(const string& expected) {
    if (lookahead.type == expected)
        lookahead = input.advance();
    else
        error("期望 " + expected + "，遇到 " + lookahead.type);
}

// ═══ E → T E'  ═══
string E() {
    string t_val = T();         // T 返回综合属性（临时变量名或词素）
    string e_val = E_prime(t_val);
    return e_val;
}

// ═══ E' → + T E' | - T E' | ε  ═══
string E_prime(string inherited) {
    if (lookahead.type == "+" || lookahead.type == "-") {
        string op = lookahead.type;
        match(op);
        string t_val = T();
        int q = Gen(op, inherited, t_val, 0);    // (+, inherited, t_val, ?)
        string temp = "t" + to_string(q);
        return E_prime(temp);
    }
    // ε 产生式：传递继承属性
    return inherited;
}

// ═══ T → F T'  ═══
string T() {
    string f_val = F();
    return T_prime(f_val);
}

// ═══ T' → * F T' | / F T' | ε  ═══
string T_prime(string inherited) {
    if (lookahead.type == "*" || lookahead.type == "/") {
        string op = lookahead.type;
        match(op);
        string f_val = F();
        int q = Gen(op, inherited, f_val, 0);
        string temp = "t" + to_string(q);
        return T_prime(temp);
    }
    return inherited;
}

// ═══ F → ( E ) | i  ═══
string F() {
    if (lookahead.type == "(") {
        match("(");
        string e_val = E();
        match(")");
        return e_val;
    }
    // F → i
    string val = lookahead.value;   // 词素，如 "x", "123"
    match("id");                    // 或 match("num")
    return val;
}
```

### 说明

- **综合属性**用函数**返回值**传递（如 `T()` 返回临时变量名）
- **继承属性**用函数**参数**传递（如 `E'` 需要知道左边的值）
- **不需要 valStack**——函数调用栈天然起到了传递属性的作用

# 说明语句的递归下降翻译

## 文法

```
S → T V ;
V → id | V , id
T → int | char | float | double
```

## LL(1) 改造（消除左递归）

```
S → T V ;
V → id V'
V' → , id V' | ε
T → int | char | float | double
```

## 代码

```cpp
int currentType;                     // 全局变量，充当继承属性

void S() {
    T();                             // 归约 T 时设置 currentType
    V();                             // 归约 V 时用 currentType 填符号表
    match(";");
}

void T() {
    if (lookahead.type == "int")   { currentType = INT;   match("int");   }
    else if (lookahead.type == "char")   { currentType = CHAR;  match("char");  }
    else if (lookahead.type == "float")  { currentType = FLOAT; match("float"); }
    else if (lookahead.type == "double") { currentType = DOUBLE;match("double");}
    else error("期望类型名");
}

void V() {
    if (lookahead.type == "id") {
        symbolTable.enter(lookahead.value, currentType);
        match("id");
        V_prime();
    }
}

void V_prime() {
    if (lookahead.type == ",") {
        match(",");
        if (lookahead.type == "id") {
            symbolTable.enter(lookahead.value, currentType);
            match("id");
        }
        V_prime();
    }
    // ε：do nothing
}


```

# 赋值语句的递归下降翻译

## 文法

```
S → id = E
```

## 代码

```cpp
void S() {
    string id_name = lookahead.value;   // 记录左边的变量名
    match("id");
    match("=");
    string e_val = E();                 // 计算右边表达式
    Gen("=", e_val, id_name, 0);        // (=, t3, x, 0)  →  x = t3
    match(";");
}
```

# 逻辑表达式（控制上下文）的递归下降翻译

每个非终结符函数返回 `pair<int,int>`（TC, FC），**无需字符串编码**。

## 文法

```
BE → BE || BT | BT
BT → BT && BF | BF
BF → !BF | ( BE ) | E rop E | i rop i | i
```

## LL(1) 改造

消除左递归后，用循环处理 `||` 和 `&&`：

```
BE  → BT BE'
BE' → || BT BE' | ε
BT  → BF BT'
BT' → && BF BT' | ε
BF  → !BF | ( BE ) | E rop E | i rop i | i
```

## 代码

```cpp
// ═══ BE → BT BE'  ═══
pair<int,int> BE() {
    auto bt = BT();          // BT 返回 {TC, FC}
    return BE_prime(bt);     // 处理后续的 || BT
}

// ═══ BE' → || BT BE' | ε  ═══
pair<int,int> BE_prime(pair<int,int> inherited) {
    auto [TC, FC] = inherited;

    while (lookahead.type == "||") {
        match("||");
        auto bt = BT();                          // 右边 BT 的 {TC, FC}
        BackPatch(TC, NextStat);                 // 左边真出口 → 跳过右边
        TC = bt.first;                           // 新 TC = 右边的 TC
        FC = Merge(FC, bt.second);               // 新 FC = 左右 FC 合并
    }
    // ε
    return {TC, FC};
}

// ═══ BT → BF BT'  ═══
pair<int,int> BT() {
    auto bf = BF();
    return BT_prime(bf);
}

// ═══ BT' → && BF BT' | ε  ═══
pair<int,int> BT_prime(pair<int,int> inherited) {
    auto [TC, FC] = inherited;

    while (lookahead.type == "&&") {
        match("&&");
        auto bf = BF();                          // 右边 BF 的 {TC, FC}
        BackPatch(FC, NextStat);                 // 左边假出口 → 算右边
        FC = bf.second;                          // 新 FC = 右边的 FC
        TC = Merge(TC, bf.first);                // 新 TC = 左右 TC 合并
    }
    // ε
    return {TC, FC};
}

// ═══ BF 的各产生式  ═══
pair<int,int> BF() {
    if (lookahead.type == "!") {                 // BF → !BF
        match("!");
        auto [TC, FC] = BF();
        return {FC, TC};                         // 交换 TC/FC
    }

    if (lookahead.type == "(") {                 // BF → ( BE )
        match("(");
        auto result = BE();
        match(")");
        return result;
    }

    // 下面处理关系比较和布尔变量，需要前瞻判断
    string save = lookahead.value;
    string save_type = lookahead.type;

    if (lookahead.type == "id" || lookahead.type == "num") {
        match(lookahead.type);
        string left = save;

        if (lookahead.type == ">=" || lookahead.type == "<=" ||   // BF → i rop i
            lookahead.type == ">"  || lookahead.type == "<"  ||
            lookahead.type == "==" || lookahead.type == "!=") {
            string rop = lookahead.type;
            match(rop);
            string right = lookahead.value;
            match(lookahead.type);   // 第二个操作数

            int TC = Gen("j" + rop, left, right, 0);
            int FC = Gen("j", "", "", 0);
            return {TC, FC};
        }

        // BF → i（布尔变量）
        int TC = Gen("JNE", left, "0", 0);
        int FC = Gen("j", "", "", 0);
        return {TC, FC};
    }

    error("期望布尔表达式");
    return {0, 0};
}
```

### 说明

- 递归下降中 TC/FC 直接用函数返回值 `pair<int,int>` 传递，**不需要** `encodeChains/decodeChains`
- 消除左递归后，`||` 和 `&&` 用 `while` 循环处理，每次迭代处理一个运算符
- `BackPatch`/`Merge` 函数与 LR 版**完全相同**

# 条件判断语句的递归下降翻译

## 文法

```
S → if ( BE ) S1
S → if ( BE ) S1 else S2
```

## 代码

```cpp
void S() {
    if (lookahead.type == "if") {
        match("if");  match("(");
        auto [TC, FC] = BE();            // 生成条件跳转指令，得到 TC/FC 链
        match(")");

        int s1_start = NextStat;         // S1 体开始的指令编号
        S();                             // 翻译 S1（递归调用自身）

        if (lookahead.type == "else") {  // if-else
            int jump = Gen("J", "", "", 0);   // S1 末尾跳过 else
            int s2_start = NextStat;          // S2 体开始的指令编号

            BackPatch(TC, s1_start);          // BE 真 → S1
            BackPatch(FC, s2_start);          // BE 假 → S2
            BackPatch(jump, NextStat);        // S1 末尾 → 跳过 S2

            match("else");
            S();                             // 翻译 S2
        } else {                             // if 无 else
            BackPatch(TC, s1_start);          // BE 真 → S1
            BackPatch(FC, NextStat);          // BE 假 → 整个 if 之后
        }
    }
    // 其他语句类型...
}
```

# 循环语句的递归下降翻译

## 文法

```
W → while ( BE ) S1
```

## 代码

```cpp
void W() {
    match("while");  match("(");

    int loop_start = NextStat;             // 循环开始（条件判断的第一条指令）
    auto [TC, FC] = BE();                  // 生成条件跳转指令

    match(")");

    int s1_start = NextStat;               // S1 体开始的指令编号
    S();                                   // 翻译 S1

    Gen("J", "", "", loop_start);          // S1 末尾无条件跳回循环开始

    BackPatch(TC, s1_start);               // BE 真 → 执行 S1 体
    BackPatch(FC, NextStat);               // BE 假 → 退出循环
}
```

# 小结：LR vs 递归下降

| 方面 | LR | 递归下降 |
|------|-----|---------|
| 方法 | 写归约动作，通过 `switch(prodIdx)` 触发 | 为每个非终结符写一个递归函数 |
| 属性传递 | `valStack` 是唯一的通道，TC/FC 被迫编码为字符串 | 函数参数和返回值天然传递属性，无需编码 |
| 左递归 | LR 天然支持左递归文法 | 必须先消除左递归（否则死循环） |
| 可读性 | 归约动作集中，但属性流向较隐蔽 | 代码与文法结构一一对应，更直观 |
| 适合场景 | 自动生成的分析器（Yacc/Bison） | 手写分析器 |
