# 方法一 手动—分配临时变量

1. 按优先级把每一步加括号：`(a * (b + c))`
2. 从最内层括号开始，每对操作分配一个临时变量：
   - `b + c` → `(+, b, c, t1)`
   - `a * t1` → `(*, a, t1, t2)`

整体得到：

```
(+, b, c, t1)
(*, a, t1, t2)
```

只是把 $E_1$ 这些换成了临时变量名。

# 方法二 [[Permanent/递归下降算法]]

## 核心原则

每个函数返回"这个子表达式的结果放在哪个变量里"（`String place`），遇二元操作符时申请新临时变量并 `emit` 一条四元组。

## 伪代码

```
String exp()
    place1 = term()
    while (token == '+' || token == '-')
        op = token
        match(token)
        place2 = term()
        t = newtemp()                    // 申请新临时变量
        emit(op, place1, place2, t)      // 生成四元组
        place1 = t
    return place1

String term()
    place1 = factor()
    while (token == '*' || token == '/')
        op = token
        match(token)
        place2 = factor()
        t = newtemp()
        emit(op, place1, place2, t)
        place1 = t
    return place1

String factor()
    if (token == 数字或变量)
        place = token
        match(token)
        return place                     // 操作数本身的名字就是"地址"
    else if (token == '(')
        match('(')
        place = exp()
        match(')')
        return place
```

## 实例

`a + b * c`

```
exp()
    └─ term()
        └─ factor() return "a"
        └─ while: token 不是 */, 退出
        └─ return "a"
    └─ while: token='+', match(+)
        └─ term()
            └─ factor() return "b"
            └─ while: token='*', match(*)
                └─ factor() return "c"
                └─ t1 = newtemp()
                └─ emit(*, b, c, t1)
                └─ return t1
        └─ t2 = newtemp()
        └─ emit(+, a, t1, t2)
        └─ return t2
```

生成的四元组：

| 序号 | op | arg1 | arg2 | result |
|----|----|------|------|--------|
| (1) | * | b | c | t1 |
| (2) | + | a | t1 | t2 |

```
  语法树:
         +
        / \
       a   *
          / \
         b   c

四元组顺序 = 后序遍历中遇到操作符时 emit
```

## 控制流语句的翻译

递归下降方法可以自然扩展到控制流语句。关键新增：

- `newlabel()` — 生成新标签（跳转目标 `L1, L2, ...`）
- `emit(label: )` — 标记跳转目标位置
- `emit(jf, cond, _, L)` — cond 为假时跳转
- `emit(jnz, cond, _, L)` — cond 为真时跳转
- `emit(jmp, _, _, L)` — 无条件跳转

### 扩充后的语法函数

原有 `exp()` 不变（处理算术加减），新增关系运算层和语句层：

```
// ── 工具 ──
int lc = 0;
String newlabel() {
    return "L" + (++lc);
}

// ── 关系表达式（在算术表达式外套一层）──
String rel_exp() {
    place1 = exp();                          // 沿用原有的算术表达式
    if (token是关系运算符 ==, !=, <, >, <=, >=) {
        op = token; match(token);
        place2 = exp();
        t = newtemp();
        emit(op, place1, place2, t);
        place1 = t;
    }
    return place1;
}

// ── 语句 ──
void stmt() {
    if      (token == "if")    if_stmt();
    else if (token == "while") while_stmt();
    else if (token == "do")    do_while_stmt();
    else                       assign_stmt();
}

void assign_stmt() {
    id_name = token; match(ID);
    match('=');
    e_place = rel_exp();                    // 右侧可以是关系表达式
    emit(=, e_place, _, id_name);
    match(';');
}

void if_stmt() {
    match("if"); match('(');
    e_place = rel_exp();
    match(')');

    L_true  = newlabel();
    L_false = newlabel();
    L_exit  = newlabel();

    emit(jnz, e_place, _, L_true);         // 真 → L_true
    emit(jmp, _, _, L_false);               // 假 → L_false

    emit(L_true:);
    stmt();                                  // then 分支

    if (token == "else") {
        emit(jmp, _, _, L_exit);            // 跳过 else
        emit(L_false:);
        match("else");
        stmt();                              // else 分支
        emit(L_exit:);
    } else {
        emit(L_false:);                     // 无 else，L_false 即出口
    }
}

void while_stmt() {
    match("while"); match('(');

    L_cond = newlabel();
    L_body = newlabel();
    L_exit = newlabel();

    emit(L_cond:);
    e_place = rel_exp();
    match(')');
    emit(jf, e_place, _, L_exit);           // 假 → 跳出
    emit(jmp, _, _, L_body);                // 真 → 进入循环体

    emit(L_body:);
    stmt();
    emit(jmp, _, _, L_cond);                // 跳回条件判断

    emit(L_exit:);
}

void do_while_stmt() {
    match("do");

    L_start = newlabel();
    emit(L_start:);
    stmt();

    match("while"); match('(');
    e_place = rel_exp();
    match(')'); match(';');
    emit(jnz, e_place, _, L_start);         // 真 → 继续循环
}
```

### 实例：if-else

源码：
```
if (x < 0)
    y = 0 - x;
else
    y = x;
```

逐步翻译：

```
rel_exp() 处理 x < 0
  → t1 = newtemp()
  → emit(<, x, 0, t1)

if_stmt() 控制流
  → L_true  = "L1", L_false = "L2", L_exit = "L3"
  → emit(jnz, t1, _, L1)
  → emit(jmp, _, _, L2)

then 分支 y = 0 - x
  → t2 = newtemp(); emit(-, 0, x, t2)
  → emit(=, t2, _, y)
  → emit(jmp, _, _, L3)          // 跳过 else

else 分支 y = x
  → emit(=, x, _, y)
```

最终四元组：

| 序号 | op   | arg1 | arg2 | result |
|-----|------|------|------|--------|
| (1) | <    | x    | 0    | t1     |
| (2) | jnz  | t1   | _    | L1     |
| (3) | jmp  | _    | _    | L2     |
| (4) | L1:  |      |      |        |
| (5) | -    | 0    | x    | t2     |
| (6) | =    | t2   | _    | y      |
| (7) | jmp  | _    | _    | L3     |
| (8) | L2:  |      |      |        |
| (9) | =    | x    | _    | y      |
| (10) | L3:  |      |      |        |

源码：
```
sum = 0;
i = 1;

    sum = sum + i;

```

逐步翻译：

```

  L_body = newlabel()  → "L5"
```

| (9) | =    | t4   | _    | sum    |
| (10) | +   | i    | 1    | t5     |
| (11) | =   | t5   | _    | i      |

# 方法三 [[LR]] [[属性文法]]

以以下文法为例子：

E → E + T | T，T → T \* F | F，F → id

## 核心原则

每个非终结符引入一个 `.place` 属性（存放结果的变量名），归约时申请新临时变量并 emit 四元组。

## 属性设计

| 符号 | 属性 |
|----|------|
| E | `E.place` — 该 E 结果所在的变量名 |
| T | `T.place` — 该 T 结果所在的变量名 |
| F | `F.place` — 该 F 结果所在的变量名 |

## 语义规则

| 产生式 | 语义规则 |
|-------|--------|
| (1) E₁ → E₂ + T | `t = newtemp(); emit(+, E₂.place, T.place, t); E₁.place = t` |
| (2) E₁ → E₂ - T | `t = newtemp(); emit(-, E₂.place, T.place, t); E₁.place = t` |
| (3) E → T | `E.place = T.place` |
| (4) T₁ → T₂ \* F | `t = newtemp(); emit(\*, T₂.place, F.place, t); T₁.place = t` |
| (5) T₁ → T₂ / F | `t = newtemp(); emit(/, T₂.place, F.place, t); T₁.place = t` |
| (6) T → F | `T.place = F.place` |
| (7) F → ( E ) | `F.place = E.place` |
| (8) F → id | `F.place = id.lexeme` |

规律总结：

- (1)(2)(4)(5)：双操作数产生式 → 申请新临时变量存放运算结果
- (3)(6)：单产生式 → place 原样传递
- (7)：括号内的结果直接作为括号表达式的结果
- (8)：叶子节点，place 就是变量名本身

## 演算过程

`a + b * c`

| 栈（符号） | 栈（值） | 输入 | 动作 | 说明 |
|---------|--------|-----|------|------|
| F | "a" | +b\*c | T→F | T.place = "a" |
| T | "a" | +b\*c | E→T | E.place = "a" |
| E | "a" | +b\*c | s5 | |
| E + | "a","+" | b\*c | s4 | |
| E + F | "a","+","b" | \*c | T→F | T.place = "b" |
| E + T | "a","+","b" | \*c | s6 | |
| E + T \* | "a","+","b","\*" | c | s4 | |
| E + T \* F | "a","+","b","\*","c" | | F→id | F.place = "c" |
| E + T | "a","+","t1" | | T→T\*F | t1=newtemp(); emit(\*,b,c,t1); T.place=t1 |
| E | "t2" | | E→E+T | t2=newtemp(); emit(+,a,t1,t2); E.place=t2 |

最终生成的四元组：

```
(*, b, c, t1)
(+, a, t1, t2)
```

## 伪代码

在 [[LR#算法实现#LR系列分析器伪代码与实现]] 的三栈模型基础上，值栈中存放每个符号的 `.place`。

```
stateStack      初始状态 0
symbolStack     符号栈
valStack        属性栈（存每个符号的 place / 值）

while (true)
    s = stateStack.top()
    a = input[ip]

    if (Action[s][a] 为空) 报错

    str = Action[s][a]

    if (str[0] == 's')                  // 移进
        symbolStack.push(a)
        valStack.push(a.lexeme)         // 操作数的 place 就是它自身
        stateStack.push(新状态)
        ip++

    elif (str[0] == 'r')                // 归约
        ruleNo = str.substr(1)
        A = Grammar[ruleNo].left
        len = Grammar[ruleNo].right.size()

        // ──── 语义动作 ────
        switch (ruleNo)
            case 1:  // E → E + T
                v3 = valStack.top(); valStack.pop()  // T.place
                v2 = valStack.top(); valStack.pop()  // +（跳过）
                v1 = valStack.top(); valStack.pop()  // E.place
                t = newtemp()
                emit(+, v1, v3, t)
                val = t                              // 新临时变量名
                break
            case 3:  // E → T
                val = valStack.top(); valStack.pop()
                break
            case 8:  // F → id
                val = valStack.top(); valStack.pop()
                break
            // ... 其余产生式类似
        // ─────────────────

        // 弹出状态栈
        for (i = 0; i < len; i++)
            symbolStack.pop()
            stateStack.pop()

        // 压入左部符号 + 属性 + 新状态
        symbolStack.push(A)
        valStack.push(val)
        stateStack.push(Goto[stateStack.top()][A])
```

## 优化思路

将语义动作与产生式绑定在一起：

```
Grammar[1] = {"E", {"E", "+", "T"}, [](auto& v) {
    t = newtemp();
    emit("+", v[0], v[2], t);
    return t;           // 返回 E₁.place
}};
```

在 [[LR#算法实现#文法规则（结构体）Grammer]] 的基础上添加属性计算函数即可。

## 控制流语句的属性文法

### 扩展文法

在算术表达式文法基础上，增加语句层产生式：

```
P    → S
S    → id = E ;
     | if ( E ) S
     | if ( E ) S else S
     | while ( E ) S
     | do S while ( E ) ;
     | { S }
```

### 新增属性与工具

| 符号 | 属性 | 说明 |
|----|------|------|
| S | `S.code` | 该语句生成的四元组列表 |
| — | `newlabel()` | 生成新标签名 `L1, L2, ...` |

跳转四元组约定：

| 四元组 | 含义 |
|-------|------|
| `(label, _, _, L)` | 定义标签位置 |
| `(jmp, _, _, L)` | 无条件跳转到 L |
| `(jf, E.place, _, L)` | 若 E.place 为假（0），跳转到 L |
| `(jnz, E.place, _, L)` | 若 E.place 为真（非 0），跳转到 L |

### 语义规则

| 产生式 | 语义规则 |
|-------|--------|
| (9) S → id = E ; | `emit(=, E.place, _, id.lexeme)` |
| (10) S → if ( E ) S₁ | `L_true = newlabel(); L_exit = newlabel()` <br> `emit(jnz, E.place, _, L_true)` <br> `emit(jmp, _, _, L_exit)` <br> `emit(L_true:)` <br> *S₁.code* <br> `emit(L_exit:)` |
| (11) S → if ( E ) S₁ else S₂ | `L_true = newlabel(); L_false = newlabel(); L_exit = newlabel()` <br> `emit(jnz, E.place, _, L_true)` <br> `emit(jmp, _, _, L_false)` <br> `emit(L_true:)` <br> *S₁.code* <br> `emit(jmp, _, _, L_exit)` <br> `emit(L_false:)` <br> *S₂.code* <br> `emit(L_exit:)` |
| (12) S → while ( E ) S₁ | `L_cond = newlabel(); L_body = newlabel(); L_exit = newlabel()` <br> `emit(L_cond:)` <br> `emit(jf, E.place, _, L_exit)` <br> `emit(jmp, _, _, L_body)` <br> `emit(L_body:)` <br> *S₁.code* <br> `emit(jmp, _, _, L_cond)` <br> `emit(L_exit:)` |
| (13) S → do S₁ while ( E ) ; | `L_start = newlabel()` <br> `emit(L_start:)` <br> *S₁.code* <br> `emit(jnz, E.place, _, L_start)` |

### 规律总结

- 赋值语句是最简情况：把右侧表达式的 place 赋给左值
- 控制流语句的核心模式是 **"条件 + 跳转 + 标签"**
- 每个 `if / while` 都会引入一组新标签，标签名由 `newlabel()` 保证唯一
- `jnz` 和 `jf` 互为反义，配合使用构成完整分支
