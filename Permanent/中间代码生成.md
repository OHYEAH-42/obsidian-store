**中间代码生成**（Intermediate Code Generation）是编译器的关键阶段，在[[语义分析]]**之后、**[[代码优化]]**之前进行。它将经过语义检查的[[抽象语法树]]（AST）或[[语法树]]，转换为一种介于[[高级语言]]和机器语言之间的*****[[中间表示]]**（Intermediate Representation, IR）。


# 核心作用

- **解耦前后端**：前端（语言相关）生成统一的IR，后端（机器相关）将IR翻译为目标代码。增加新语言或新CPU时，只需更换一端。
- **便于优化**：IR结构规整，保留了程序的控制流和数据流信息，非常适合进行与机器无关的优化（如常量折叠、死代码删除）。
- **降低编译复杂度**：将复杂的源语言特性（如循环、函数调用）逐步拆解为简单的、接近机器指令的IR操作。
