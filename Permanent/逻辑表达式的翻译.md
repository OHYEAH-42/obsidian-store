逻辑表达式的翻译核心是短路求值 + 回填
# 在c语言中，逻辑表达式可能出现在赋值语句和条件语句中：

## X=(a>b)&&(c<d)

在赋值语句中出现时，需要先计算出整个逻辑表达式的值，这与算术表达式的处理方式相同。

## if(((a>b)&&(c<d)))  x=0; else x=1;

在条件判断（如if语句）或循环语句中，逻辑表达式作为条件时，主要功能是根据条件成立与否进行跳转控制。

[[短路优化]]：
- 对于逻辑与运算&&：若前一个条件不成立，则直接跳转到条件不成立的分支，无需计算后续条件
- 对于逻辑或运算||：若前一个条件成立，则直接跳转到条件成立的分支，同样无需计算后续条件

# 1. 分析编程语言逻辑表达式的书写格式

（a>b）&& ( c<d ) || ! (a\==d)

运算符号有
- 逻辑运算符：&&（与）、||（或）、!（非）
- 关系运算符：>、<、>=、<=、\==、!=

## 逻辑与关系运算的优先级

- 关系运算符优先级高于逻辑运算符
- 在逻辑运算符内部：! > && > ||

## 括号改变运算优先级

- 括号可以强制改变默认优先级，如使||优先于&&运算

## 关系运算符的种类与表示

- 标准形式：E1 rop E2﻿，其中rop代表关系运算符
- 运算符集合：包括<、<=、\==、>=、>等，常用rop作为抽象表示

## 算术、关系与逻辑运算的优先级关

括号 > 算术运算 > 关系运算 > 逻辑非 > 逻辑与 > 逻辑或

# 2. 按书写格式规律写出对应的编程语言的逻辑表达式文法

改写方法：基于[[算数表达式的翻译]]文法规则进行适配改造：
- 将加减法改为逻辑或运算
- 将乘除法改为逻辑与运算
-  增加非运算和关系运算支持

BE->BE || BT                                         
BE->BT                                                                    $E' \to E$ 
BT->BT && BF                                                        $E_1 \to E_2 + T$       $E_1 \to E_2 + T$ 
BT->BF                                                                    $E \to T$
BF->!BF                                                                   $E \to -T$ 
BF->(BE)                                                                  $F \to (E)$ 
BF->E rop E                                                             $T_1 \to T_2 * F$
BF->i rop i                                                               $T_1 \to T_2 \; / \; F$ 
BF->i                                                                       $F \to i$

大概理解怎么来的就行

eg：（1>2)&&(3<4)||(5>3)
1. 扫描到1>2时，用BF->(BE)，归约为BF，计算1>2的逻辑值为0，存入BF.value
2. BF用BT->BF归约为BT，将BF.value传递给BT.value
3. BT用BE->BT归约为BE，将BT.value传递给BE.value
4. 扫描到3<4时，用BF->(BE)，归约为BF，计算3<4的逻辑值为1，存入BF.value
5. BF用BT->BF归约为BT，将BF.value传递给BT.value
6. BT和&&及BF用BT->BT&&BF归约，计算0&&1=0，结果存入BT.value
7. 扫描到5>3时，用BF->(BE)，归约为BF，计算5>3的逻辑值为1，存入BF.value
8. BF用BT->BF归约为BT，将BF.value传递给BT.value
9. BE和||及BT用BE->BE||BT归约，计算0||1=1，最终结果存入BE.value

# 代码实现

逻辑表达式有两种使用上下文，归约写法不同：

### 版本 A：值上下文（赋值语句中，如 `X = (a>b) && (c<d)`）

按布尔值计算，valStack 传 `"0"` / `"1"`。

```cpp
// ═══ 逻辑表达式归约 —— 值上下文 ═══

// attrs[0..rhsLen-1] 已在主框架第 1 步中弹出

// 产生式编号约定：
//   1: BE → BE || BT    2: BE → BT
//   3: BT → BT && BF    4: BT → BF
//   5: BF → !BF         6: BF → ( BE )
//   7: BF → E rop E     8: BF → i rop i
//   9: BF → i

switch (prodIdx) {
    case 1:  // BE → BE || BT
        result = to_string(stoi(attrs[0]) || stoi(attrs[2])); break;
    case 2:  // BE → BT
    case 4:  // BT → BF
    case 9:  // BF → i
        result = attrs[0]; break;
    case 3:  // BT → BT && BF
        result = to_string(stoi(attrs[0]) && stoi(attrs[2])); break;
    case 5:  // BF → !BF
        result = to_string(!stoi(attrs[1])); break;
    case 6:  // BF → ( BE )
        result = attrs[1]; break;
    case 7:  // BF → E rop E
    case 8:  // BF → i rop i
        result = to_string(eval_rop(attrs[1], attrs[0], attrs[2])); break;
}
// result 由主框架第 3 步 push 回 valStack
```

### 版本 B：控制上下文（if/while 中，短路 + 回填）

每个非终结符（BF / BT / BE）在 valStack 中压入一个编码串 `"TC,FC"`：

- TC = 真出口链头（条件成立时跳转的目标指令编号）
- FC = 假出口链头（条件不成立时跳转的目标指令编号）
- `-1` 表示空链
- 链中每条四元组的 result 字段存下一跳编号

需要前置工具函数：

```cpp
// ═══ 链操作（四元组 result 字段存下一跳编号，0 = 链尾）═══

// 合并两条链（p2 接到 p1 末尾），返回新链头
int Merge(int p1, int p2) {
    if (p2 == 0) return p1;
    if (p1 == 0) return p2;
    int tail = p1;
    while (quads[tail].result != 0)
        tail = quads[tail].result;
    quads[tail].result = p2;
    return p1;
}

// 回填：链上所有四元组的 result 改为目标编号
void BackPatch(int chain, int targetLabel) {
    for (int p = chain; p != 0; ) {
        int next = quads[p].result;
        quads[p].result = targetLabel;
        p = next;
    }
}
```

归约动作代码：

```cpp
// ═══ 逻辑表达式归约 —— 控制上下文 ═══
// valStack 每层压入一个编码串 "TC,FC"

// attrs[0..rhsLen-1] 已在主框架第 1 步中弹出

// 产生式编号约定：
//   1: BE → BE || BT    2: BE → BT
//   3: BT → BT && BF    4: BT → BF
//   5: BF → !BF         6: BF → ( BE )
//   7: BF → E rop E     8: BF → i rop i
//   9: BF → i

switch (prodIdx) {
    case 1:  // BE → BE || BT
    {
        // 解码左 BE 的 TC,FC
        int c1 = attrs[0].find(',');
        int TC1 = stoi(attrs[0].substr(0, c1));
        int FC1 = stoi(attrs[0].substr(c1 + 1));
        // 解码右 BT 的 TC,FC
        int c2 = attrs[2].find(',');
        int TC2 = stoi(attrs[2].substr(0, c2));
        int FC2 = stoi(attrs[2].substr(c2 + 1));

        BackPatch(TC1, NextStat);                   // 回填左 BE 的真出口 → 右 BT
        result = to_string(TC2) + "," +
                 to_string(Merge(FC1, FC2));         // 新 TC=右 BT 的 TC；新 FC=合并
        break;
    }
    case 2:  // BE → BT
    case 4:  // BT → BF
        result = attrs[0];                          // 传递
        break;
    case 3:  // BT → BT && BF
    {
        // 解码左 BT 的 TC,FC
        int c1 = attrs[0].find(',');
        int TC1 = stoi(attrs[0].substr(0, c1));
        int FC1 = stoi(attrs[0].substr(c1 + 1));
        // 解码右 BF 的 TC,FC
        int c2 = attrs[2].find(',');
        int TC2 = stoi(attrs[2].substr(0, c2));
        int FC2 = stoi(attrs[2].substr(c2 + 1));

        BackPatch(FC1, NextStat);                   // 回填左 BT 的假出口 → 右 BF
        result = to_string(Merge(TC1, TC2)) + "," +
                 to_string(FC2);                    // 新 TC=合并；新 FC=右 BF 的 FC
        break;
    }
    case 5:  // BF → !BF
    {
        // 交换 TC 和 FC（非运算反转跳转方向）
        int c = attrs[1].find(',');
        int TC = stoi(attrs[1].substr(0, c));
        int FC = stoi(attrs[1].substr(c + 1));
        result = to_string(FC) + "," + to_string(TC);
        break;
    }
    case 6:  // BF → ( BE )
        result = attrs[1];                          // 传递内层 BE 的链
        break;
    case 7:  // BF → E rop E（E 是算术表达式）
    {
        int TC = Gen("j" + attrs[1], attrs[0], attrs[2], 0);  // (jrop, E1.val, E2.val, 0)
        int FC = Gen("j", "", "", 0);                          // (j, _, _, 0)
        result = to_string(TC) + "," + to_string(FC);
        break;
    }
    case 8:  // BF → i rop i（i 是简单变量/常量）
    {
        int TC = Gen("j" + attrs[1], attrs[0], attrs[2], 0);  // (jrop, i1, i2, 0)
        int FC = Gen("j", "", "", 0);                          // (j, _, _, 0)
        result = to_string(TC) + "," + to_string(FC);
        break;
    }
    case 9:  // BF → i（布尔变量）
    {
        int TC = Gen("JNE", attrs[0], "0", 0);          // (JNE, i, 0, 0) 假设 0=false
        int FC = Gen("j", "", "", 0);                   // (j, _, _, 0)
        result = to_string(TC) + "," + to_string(FC);
        break;
    }
}
        Gen("J", "", "", "-1");
        result = encodeChains(TC, FC);
        break;
    }
}
// result 由主框架第 3 步 push 回 valStack
```
