算数表达式的翻译就是把 $a+b*c$等拆成一步只做一件事的形式
# 1. 分析编程语言算数表达式语句的书写格式

比如：`a + b * c`，`(3 + 4) / 2`

书写格式规律：
- 运算符有优先级：`*`、`/` 高于 `+`、`-`
- 括号 `()` 可以改变优先级
- 相同的优先级从左到右结合（左结合）

# 2. 按书写格式规律写出对应的编程语言算术表达式文法

$E$'->$E$
$E_1$->$E_2$ | $T$ | $E_2$ - $T$ | - $T$
$T_1$-> $T_2$ | $T_2$ $F$ | $F$
$F$->( $E$ ) | $i$

# 3. 分析算数表达式执行时的具体含义，以便观察是否需要进行文法规则的改造以及写出对应规则归约时需要执行的[[语义动作]]

## 语法制导定义（[[属性文法]]）

每个产生式附加一条语义规则，用综合[[属性]] `.val` 传递值：

**开始符号：**

$E' \to E$ —— { $E'.val = E.val$ }

**表达式层（加减与一元负）：**

$E_1 \to E_2 + T$ —— { $E_1.val = E_2.val + T.val$ }

$E_1 \to E_2 - T$ —— { $E_1.val = E_2.val - T.val$ }

$E \to T$ —— { $E.val = T.val$ }

$E \to -T$ —— { $E.val = -T.val$ }

**项层（乘除）：**

$T_1 \to T_2 * F$ —— { $T_1.val = T_2.val * F.val$ }

$T_1 \to T_2 \; / \; F$ —— { $T_1.val = T_2.val \; / \; F.val$ }

$T \to F$ —— { $T.val = F.val$ }

**因子层（括号与基本操作数）：**

$F \to (E)$ —— { $F.val = E.val$ }

$F \to i$ —— { $F.val = i.lexval$ }


## 根据需要，写出表达式对应的语义动作

比如翻译为后缀式：
```
E1 → E2 + T  ——  { E1.post = E2.post || T.post || '+' }
```

翻译为四元组：
```
E1 → E2 + T  ——  { t = newtemp(); 
                   gen(+, E2.val, T.val, t); 
                   E1.val = t }
```

翻译为三元组：
```
E1 → E2 + T  ——  { p = newtriple();
                   setTriple(p, +, E2.val, T.val);
                   E1.val = p }
```

>gen()表示生成三元组\四元组的函数

# 代码实现

以下为 LR 语法制导翻译框架中算术表达式的归约动作（已在[[语法制导翻译的LR方式]]中有完整代码，此处为附录速查）。

```cpp
// ═══════════════════════════════════════════
// 算术表达式（四元组版本，选中其一即可）
// ═══════════════════════════════════════════

// attrs[0..rhsLen-1] 已在主框架第 1 步中弹出

// 产生式编号约定：
//   1: E → E + T    2: E → E - T    3: E → T
//   4: E → -T
//   5: T → T * F    6: T → T / F    7: T → F
//   8: F → ( E )    9: F → i

switch (prodIdx) {
    case 1:  // E → E + T
    case 2:  // E → E - T
    {
        int q = Gen(attrs[1], attrs[0], attrs[2], 0);
        result = "t" + to_string(q);
        break;
    }
    case 3:  // E → T
        result = attrs[0];
        break;
    case 4:  // E → -T
    {
        int q = Gen("neg", attrs[1], "", 0);
        result = "t" + to_string(q);
        break;
    }
    case 5:  // T → T * F
    case 6:  // T → T / F
    {
        int q = Gen(attrs[1], attrs[0], attrs[2], 0);
        result = "t" + to_string(q);
        break;
    }
    case 7:  // T → F
        result = attrs[0];
        break;
    case 8:  // F → ( E )
        result = attrs[1];
        break;
    case 9:  // F → i
        result = attrs[0];
        break;
}
// result 由主框架第 3 步 push 回 valStack
```
