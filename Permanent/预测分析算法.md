预测分析是一种**表驱动的[[自顶向下的语法分析]]**方法。它**不需要**回溯**，通过查看**当前输入符号**（lookahead）和**栈顶符号**，在预先构建的**预测分析表**中决定下一步动作。

预测分析算法中需要使用到[[LL(1)]]文法以及LL1文法表的构建

# 理解

以该产生式为例
E->T|T+E
T->int|int\*T|(E)

![[Pasted image 20260521132134.png]]

左侧一列为非终结符号(当前指针指向的符号)，上面一行为下一个符号($假定为输入流的末尾)，对应到表格上则是相应的产生式。也就是可以通过读取下一个字符，来判断我们应该使用哪个产生式。

以前文的递归下降回溯算法为例子，当输入为int的时候，在T()处，会读取下一字符，如果下一字符为*，则采用Y->\*T，在表格中可以找到对应。如果下一字符为$，则表示接下来没有字符了，int本身为终结符，翻译为int。(预测分析算法不需要递归回溯)

## 伪代码

```
// 初始化，初始化栈，初始化输入串
stack 初始栈[$，文法开始符号]
输入：[输入串,$]             //vector，string啥的都可以

// LL1的预测分析算法

void LL1analyze()
	while（栈非空）
		X = 栈顶元素，出栈
		a = 当前输入符号
		
		if X == a == “$”
			ACCEPT;        //两个都走完了
		elif X == a        //终结符匹配到了
			输入指针移动一位
		elif X 是非终结符号  //查表
			if [X , a] 有产生式 X ->Y1，Y2
			倒序入栈，依次把Y2，Y1压入栈中
		else
			ERROR          //语法错误



```
