  ▎ 查询"计算机系"所有学生的姓名

  π<sub>姓名</sub>( σ<sub>系别='计算机'</sub>( Student ) )

  2. 多表自然连接

  ▎ 查询选了"数据库"课程的学生姓名

  π<sub>姓名</sub>( σ<sub>课程名='数据库'</sub>( Student ⋈ SC ⋈ Course ) )

  3. "至少…全部" → 用除法 ÷

  ▎ 查询选修了"学号 S1 所选全部课程"的学生学号

  π<sub>Sno, Cno</sub>(SC) ÷ π<sub>Cno</sub>( σ<sub>Sno='S1'</sub>(SC) )

  ▎ 除法口诀：分子 ÷ 分母 = "满足分母所有条件的分子元素"

  π<sub>Sno</sub>(Student) − π<sub>Sno</sub>(SC)

  5. "同时满足多个条件" → 用交 ∩（或用连接+选择代替）

  π<sub>Sno</sub>(σ<sub>Cno='C1'</sub>SC) ∩ π<sub>Sno</sub>(σ<sub>Cno='C2'</sub>SC)
