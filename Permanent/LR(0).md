# LR(0) 文法

LR(0) 中的 **L** 表示从左向右扫描输入，**R** 表示产生最右推导的逆过程（即归约），**0** 表示每一步**不需要向前看任何符号**就能决定动作。一种[[语法分析]]中[[自底向上的语法分析]]的方法

---

# 基本概念

### 活前缀 (Viable Prefix)(又叫[[可行前缀]])

规范句型中不含[[句柄]]右边任何符号的前缀。LR 分析器在栈中始终维护一个活前缀。

### LR(0) 项([[项目]])

在产生式右部加一个点 `.` 表示"已经读到了哪里"。

```
产生式 E → E + n 的四个项目：
E → ·E + n      即将识别 E
E → E· + n      刚识别了 E，期望 +
E → E +· n      刚识别了 +，期望 n
E → E + n·      全部识别完成 → 可以归约！
```

### 项目的分类

| 类型   | 形式                | 含义              |
| ---- | ----------------- | --------------- |
| 移进项目 | `A → α·aβ`（a∈V_T） | 点后是终结符，等待移进     |
| 待约项目 | `A → α·Bβ`（B∈V_N） | 点后是非终结符，等待归约出 B |
| 归约项目 | `A → α·`          | 点在末尾，可以执行归约     |
| 接受项目 | `S' → S·`         | 拓广文法的开始符号归约完成   |

#  LR(0) DFA

## 理解

E -> E +T | T
T -> ( E ) | a

1. 扩展文法
	对于这个文法，我们先扩展文法：
	E‘ -> E
	其实就是加一个E'而已

2. 列出文法
	然后列出所有文法
	(0)E‘ -> E
	(1)E -> E +T
	(2)E -> T
	(3)T -> ( E )
	(4)T -> a

3. 状态读取
	- 开始状态为扩展文法例如E‘ -> · E
	- 每次读取状态读取一个符号a，从左到右读取，写下该状态中可以读取符号a的所有产生式，且 · 向右移动一位 写下的新产生式为一个新状态。以此类推一直读
	- 如果读取后点号右边不为空且是非终结符，则要将该非终结符的产生式也写入该状态，· 在非终结符的产生式右边的最左边

## 算法实现

### 第一步：拓广文法

添加 `S' → S`（S' 不在原文法中），使接受状态唯一。

```
原文法：   E → E + n | n
拓广后：   (0) E' → E
          (1) E → E + n
          (2) E → n
```

### 第二步：闭包算法 Closure(I)

```
Closure(I)：
    将 I 的所有项目加入 J
    while (J 有变化)
        for (J 中每个项目 A → α·Bβ)      // 点后面是非终结符 B
            for (B 的每个产生式 B → γ)
                若 B → ·γ 不在 J 中 → 加入 J
    return J
```

**直觉**：`A → α·Bβ` 说明接下来要识别 B，而识别 B 意味着可能要按 B 的某个产生式展开，所以把 `B → ·γ` 也加进去。

### 第三步：转移函数 Goto(I, X)

```
Goto(I, X)：
    J = ∅
    for (I 中每个项目 A → α·Xβ)
        将 A → αX·β 加入 J       // 点跨过 X，右移一位
    return Closure(J)
```

**直觉**：识别了 X 之后，把点跨过 X，然后再求闭包。

### 第四步：构造完整 DFA

```
1. I₀ = Closure({S' → ·S})
2. 对于每个已生成的状态 I 和每个文法符号 X：
      若 Goto(I, X) 非空且是新状态 → 加入 DFA
3. 重复步骤2直到无新状态
```

## 规则

对于每一个项集：
- 如果该项集有指出箭头：
	- 当前项集I<sub>n</sub>中的n为横坐标
	- 指出箭头上的符号α为纵坐标
	- 填入箭头指向的项集I<sub>n’</sub> 
		如果α为非终结符号，则填入n’
		如果α为终结符号，则填入S<sub>n‘</sub>，表示移进
- 如果该项集无指出箭头：
	- 当前项集I<sub>n</sub>中的n为横坐标
	- 查看当前项集的项可以归约成文法中的第几个产生式，假设为a，则在横坐标所有ACTION列中填写S<sub>a</sub>表示归约
- 如果该项集还有 · 在扩广文法最后面的产生式
	- 当前项集I<sub>n</sub>中的n为横坐标
	- 符号#的#为纵坐标
	- 在该坐标填入acc，表示接受

# LR(0) 的局限

LR(0) **不看任何输入符号就决定归约**，导致两类冲突：

**移进-归约冲突**：同一状态中同时有归约项目和移进项目。
```
I₁ = {E' → E·,  E → E· + n}
      ↑归约      ↑移进（输入为 + 时）
→ 输入为 + 时，不知道该归约 E'→E 还是移进 +
```

**归约-归约冲突**：同一状态中有两个不同的归约项目。
```
I = {A → a·,  B → a·}
→ 不知道按 A→a 还是 B→a 归约
```

LR(0) 文法要求 DFA 中**完全不存在这两类冲突**，条件非常苛刻，实际中几乎没有语言是 LR(0) 的。**[[SLR(1)]] 通过引入 FOLLOW 集来缓解归约冲突**，这就是下一步的内容。
