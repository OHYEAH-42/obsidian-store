# 决策树模型

**决策树模型**（Decision Tree Model）是一种基于**树状结构**进行决策的[[监督学习]]算法。它通过递归地将数据集按照特征值进行划分，生成一棵由**决策节点**和**叶节点**组成的树，用于解决分类([[分类决策树]])或回归([[回归决策树]])问题。

每一个节点代表一个决策，每一条路径代表一个决策序列
## 核心组成部分

| 组件       | 英文            | 作用                      | 示例（判断是否出门打球）   |
| :------- | :------------ | :---------------------- | :------------- |
| **根节点**  | Root Node     | 包含数据集的全部样本，是第一个分裂点      | “天气状况”         |
| **内部节点** | Internal Node | 对应一个特征（属性），根据该特征的取值向下分支 | “湿度”、“风速”      |
| **分支**   | Branch        | 特征取值的不同走向（或阈值划分）        | “晴天”、“阴天”、“雨天” |
| **叶节点**  | Leaf Node     | 决策结果，不再继续分裂             | “去打球”、“不去打球”   |

# 如何选择划分条件？

## [[分类决策树]]

假设有 10 个训练样本，其中：
- 5 个样本对应「去打球」
- 5 个样本对应「不去打球」
目前两类样本混杂在一起。
模型究竟应该按照湿度划分，还是按照温度划分？
这里引入一个概念：[[不纯度]]（Impurity）。

我们利用[[基尼不纯度]]，尝试不同特征以及划分方式，选出让不纯度下降最多的方案
这就是划分的方法，是一种[[贪心算法|贪心]]的方法：每次划分只考虑当前节点的最佳选择。

## [[回归决策树]]

回归树需要衡量的是：预测值与真实值之间的误差。
对于常见的 CART 回归树，可以使用平方误差（Squared Error）。
$$
SSE=\sum_{i=1}^{n}(y_i-\hat y)^2
$$
其中：

- $y_i$：第 i 个样本的真实值。
- $\hat y$：该样本所在叶节点的预测值。
- $n$：样本数量。
