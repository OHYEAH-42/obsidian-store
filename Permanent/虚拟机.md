# 什么是虚拟机

**虚拟机**（Virtual Machine）在系统虚拟化语境中，是由软件模拟或借助硬件辅助构建的计算机执行环境，可向来宾操作系统提供处理器、内存、磁盘等虚拟硬件。它使多个系统环境在同一主机上运行；与依靠同一内核提供的[[进程隔离]]不同，系统虚拟机可以运行自己的内核。QEMU 在文档场景中模拟 RISC-V 机器供 xv6 运行。
