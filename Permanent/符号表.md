**符号表**（Symbol Table）是编译器用于管理**标识符**（变量、函数、类型等）及其**属性**的数据结构。
# 核心作用

- **记录绑定**：标识符 → 类型、存储位置、作用域等
- **[[作用域]]管理**：支持嵌套作用域的进入/退出
- **语义检查**：变量是否已声明、类型是否匹配、是否重复定义
# 在[[编译系统]]中的位置

词法分析 → 语法分析 → **[[语义分析]]**（符号表活跃）→ 中间代码生成
- 语法分析器识别标识符时，查符号表判断是否已声明
- 语义分析时填入类型、作用域层级等信息
- 代码生成阶段，从符号表读取变量的内存地址/寄存器分配

# 符号表常用函数

## 数据结构定义

在实现具体函数前，先定义符号表的基本数据结构（C++ 版本）：

```cpp
#include <string>
#include <vector>
#include <iostream>
#include <stdexcept>

enum DataType { T_UNDEFINED = 0, T_INT = 1, T_FLOAT = 2, T_CHAR = 3 };

struct SymbolEntry {
    std::string name;           // 标识符名称
    DataType type;              // 数据类型
    int scope_level;            // 作用域层级
};

class SymbolTable {
private:
    std::vector<SymbolEntry> table;  // 符号表容器（自动扩容）
    int current_scope = 0;

public:
    // 四个核心函数在此声明，下文逐一实现
    int lookup(const std::string &name);
    int enter(const std::string &name);
    int n_fetch(const std::string &name);
    void fill(int pos, DataType type);
};
```

---

## LOOKUP 函数

> 以符号名 `name` 查询符号表，若存在则返回位置序号，否则返回 `NULL`（`-1`）。用于检查变量是否已在符号表中声明。

### 伪代码

```
FUNCTION LOOKUP(name)
    FOR i FROM 0 TO table.size() - 1 DO
        IF table[i].name == name THEN
            RETURN i           // 找到，返回位置序号
        END IF
    END FOR
    RETURN -1                  // 未找到
END FUNCTION
```

### 详细代码（C++）

```cpp
int SymbolTable::lookup(const std::string &name) {
    for (size_t i = 0; i < table.size(); ++i) {
        if (table[i].name == name) {   // std::string 直接支持 == 比较
            return static_cast<int>(i); // 找到：返回符号在表中的位置
        }
    }
    return -1;                          // 未找到
}
```

> **要点**：C++ 中 `std::string` 重载了 `==`，无需 `strcmp`。线性扫描整个符号表，对于嵌套作用域可改为从末尾向前扫描。

## ENTER 函数

> 将当前名称登记到符号表中并返回其位置。用于变量首次声明时的登记操作。

### 伪代码

```
FUNCTION ENTER(name)
    entry = new SymbolEntry(name, UNDEFINED, current_scope)
    table.push_back(entry)
    RETURN table.size() - 1            // 返回新登记的位置
END FUNCTION
```

### 详细代码（C++）

```cpp
int SymbolTable::enter(const std::string &name) {
    table.push_back({name, T_UNDEFINED, current_scope});
    return static_cast<int>(table.size()) - 1;  // 返回新符号的位置
}
```

> **要点**：C++ `std::vector` 自动管理内存，无需担心固定容量溢出。登记时类型设为 `T_UNDEFINED`，后续由 `FILL` 填入。

---

## N取 函数

> 组合操作函数，先执行 `LOOKUP` 查找，若未找到则执行 `ENTER` 登记。确保变量无论是否已声明都能获得有效位置。

### 伪代码

```
FUNCTION N取(name)
    pos = LOOKUP(name)
    IF pos == -1 THEN
        pos = ENTER(name)     // 未声明则登记为新变量
    END IF
    RETURN pos
END FUNCTION
```

### 详细代码（C++）

```cpp
int SymbolTable::n_fetch(const std::string &name) {
    int pos = lookup(name);
    if (pos == -1) {            // 未在符号表中找到
        pos = enter(name);      // 登记为新变量
    }
    return pos;                 // 返回有效位置
}
```

> **要点**：先查后插的典型模式。语法分析时遇到标识符可直接调用 `N取`，无需区分是首次声明还是后续引用。

## FILL 函数

> 将数据类型填入符号表指定位置的 `type` 字段。需注意该操作通常在变量声明后数据类型确定时执行。

### 伪代码

```
FUNCTION FILL(pos, data_type)
    IF pos < 0 OR pos >= table.size() THEN
        ERROR: 位置不合法
    END IF
    table[pos].type = data_type
END FUNCTION
```

### 详细代码（C++）

```cpp
void SymbolTable::fill(int pos, DataType data_type) {
    if (pos < 0 || pos >= static_cast<int>(table.size())) {
        throw std::out_of_range("Invalid symbol table position: " +
                                std::to_string(pos));
    }
    table[pos].type = data_type;
}
```

> **要点**：`FILL` 与 `ENTER` 分离是因为声明语句中变量名先出现、类型后出现（如 `int x;`），必须先登记名字再填入类型。C++ 中使用异常替代 C 的 `exit(1)`，更安全可控。

## 函数调用流程示例

以 `int x;` 和后续 `x = 10;` 为例，展示四个函数的配合关系：

```
// 1. 处理声明 int x;
pos = ENTER("x");          // 登记变量名 x，返回位置
// ... 中间可能有其他语义动作 ...
FILL(pos, T_INT);          // 填入类型 int

// 2. 处理赋值 x = 10;
pos = N取("x");            // LOOKUP 找到 x，直接返回位置
// 等价于显式调用 LOOKUP，但 N取 在 x 未声明时也会自动登记
```

> 典型应用场景对照：
>
> | 函数 | 调用时机 | 作用 |
> |------|----------|------|
> | `LOOKUP` | 引用变量时 | 检查变量是否已声明 |
> | `ENTER` | 声明变量时 | 将新变量登记入表 |
> | `N取` | 不确定是否已声明时 | 安全获取位置 |
> | `FILL` | 确定变量类型后 | 补填类型信息 |

## 完整整合代码

```cpp
#include <string>
#include <vector>
#include <iostream>
#include <stdexcept>

enum DataType { T_UNDEFINED = 0, T_INT = 1, T_FLOAT = 2, T_CHAR = 3 };

struct SymbolEntry {
    std::string name;
    DataType type;
    int scope_level;
};

class SymbolTable {
private:
    std::vector<SymbolEntry> table;
    int current_scope = 0;

public:
    // LOOKUP：查询符号表
    int lookup(const std::string &name) {
        for (size_t i = 0; i < table.size(); ++i) {
            if (table[i].name == name) {
                return static_cast<int>(i);
            }
        }
        return -1;
    }

    // ENTER：登记新符号
    int enter(const std::string &name) {
        table.push_back({name, T_UNDEFINED, current_scope});
        return static_cast<int>(table.size()) - 1;
    }

    // N取：先查后插
    int n_fetch(const std::string &name) {
        int pos = lookup(name);
        return (pos == -1) ? enter(name) : pos;
    }

    // FILL：填入类型
    void fill(int pos, DataType data_type) {
        if (pos < 0 || pos >= static_cast<int>(table.size())) {
            throw std::out_of_range("Invalid position: " +
                                    std::to_string(pos));
        }
        table[pos].type = data_type;
    }

    void print() const {
        for (const auto &entry : table) {
            std::cout << "name=" << entry.name
                      << " type=" << entry.type
                      << " scope=" << entry.scope_level << "\n";
        }
    }
};

int main() {
    SymbolTable st;

    // 模拟 int x; x = 10;
    int pos = st.enter("x");
    st.fill(pos, T_INT);

    pos = st.n_fetch("x");          // lookup 命中，返回已有位置
    std::cout << "x found at: " << pos << "\n";

    pos = st.n_fetch("y");          // lookup 未命中，自动 enter
    std::cout << "y entered at: " << pos << "\n";

    st.print();
    return 0;
}
```
