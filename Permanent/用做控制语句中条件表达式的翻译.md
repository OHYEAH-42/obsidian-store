其作用是用来选择下一个节点

eg1：if ((a>b) && (c<d)) x=0; else x=1;
如果 a>b 的条件成立，
	继续执行 c<d，
		如果 c<d 成立才执行 x=0，否则执行 x=1
如果 a>b 的条件不成立，则转到执行 x=1

# 翻译方法及过程

每一个关系比较表达式都有条件成立和条件不成立的转向
**翻译方法**：每个关系比较表达式都翻译出两个转向指令
- 一个成立时转向——真出口（TC）
- 一个不成立时传向——假出口（FC）

对于文法：
- BF->E rop E 
- BF->i rop i
- BF->i
产生两条指令

实际上就是对应[[四元组]]的转化，比如 if a>b:
(1)（J>，a，b，？）对应真出口
(2)（J，，，？）对应假出口
这个时候我们是不知道真假出口的

我们需要一个全局变量NextStat来记录下一四元组（指令）的序号

```
static int NextStat = 1;//初始化为1
```

TC和FC属于[[属性]]，在[[LR]]分析中我们使用属性栈valStack来存储

```
stack <string> valStacl
```
