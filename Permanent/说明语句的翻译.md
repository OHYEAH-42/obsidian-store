说明语句的翻译就是把变量登记到[[符号表]]，不生成可执行代码

# 1.分析编程语言的说明语句的书写格式：

int j；
int k，m，n；
float x；

可以看见一共有三个部分：数据类型，数据列表，分号组成

# 2.按书写格式规律写出对应的说明语句文法（假设数据类型只有int、char、float、double）

显然，我们可以得到文法规则：
S->T V ;
V-> i | V , i
T->int | char | float | double

S代表语句，V表示数据列表，T表示数据类型

需要利用[[符号表]]来处理说明语句的结果，这个符号表的构成：

| name(变量名) | kind(种类)  | type(数据类型) | value(值) | scope(作用域) |
| --------- | --------- | ---------- | -------- | ---------- |
|           | 变量/常量/函数名 |            |          |            |

# 3.分析说明语句执行时的具体含义，以便观察是否需要进行文法规则的改造以及写出对应规则归约时需要执行的[[语义动作]]

实现方法：
- 为每条规则编写对应的语义动作
- 通过归约过程生成符号表
- 用[[语法制导翻译]]来完成

需要注意的是，在翻译说明语句时，由于归约时没法将数据类型和变量列表一起读到，比如归约int a，所以需要一个全局变量来传递当前读到的变量的数据类型：
```
struct Symbol {
    int type;          // 数据类型
    char* kind;        // 种类：VAR, FUNC, ARRAY
};

Symbol IDAttr;         // 全局变量，充当继承属性
```

# 代码实现

说明语句的归约**不生成中间代码**，而是将变量登记到[[符号表]]。数据类型需要靠全局变量 `IDAttr` 作为**继承属性**向下传递。

以下代码适用于 LR 框架主循环的 `// [在此插入归约语义动作]` 处：

```cpp
// ═══════════════════════════════════════════
// 说明语句（不生成中间代码，只填符号表）
// ═══════════════════════════════════════════

// attrs[0..rhsLen-1] 已在主框架第 1 步中弹出
// 以下按产生式编号处理

// 产生式编号约定：
//   1: S → T V ;
//   2: V → id
//   3: V → V , id
//   4: T → int
//   5: T → char
//   6: T → float
//   7: T → double

switch (prodIdx) {
    case 1:  // S → T V ;
        // 填表工作在 V 归约时已完成，此处无需额外操作
        result = "";
        break;
    case 2:  // V → id
    case 3:  // V → V , id
        // 将变量名写入符号表，类型用之前 T 归约时保存的 IDAttr.type
        // attrs.back() 是最右的 id 词素
        symbolTable.enter(attrs.back(), IDAttr.type);
        result = attrs.back();
        break;
    case 4:  // T → int
    case 5:  // T → char
    case 6:  // T → float
    case 7:  // T → double
        // 将类型名存入全局变量，供后面的 V 使用（继承属性）
        IDAttr.type = attrs[0];   // 如 "int"
        result = attrs[0];        // 类型名向上传
        break;
}
```
```
