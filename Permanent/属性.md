属性(attribute)是编程语言结构的任意特性，是附着在[[文法]]符号（终结符或非终结符）上的“值”。每个符号可以有多个属性。

# 常见属性

- 类型（`type`）：表达式的类型（`int`, `bool`）
- 值（`val`）：常量的数值
- 地址（`addr`）：变量的内存位置
- 代码（`code`）：生成的中间代码序列

**示例**：表达式 `E → E₁ + T`

- `E.type` 是综合属性，由 `E₁.type` 和 `T.type` 计算得到。


# 数据结构

在代码实现中，[[Permanent/递归下降算法]]使用函数返回值和全局变量来当作属性的存储

在[[LR]]中，使用属性栈valStack来存储

比如E.type，E.val等等的值都用此存储

## 表达式存储的属性数量不同的问题解决

对于不同表达式，需要存储的属性是不同的，比如：
E → E + T        右部 3 个符号，属性: {place, 无, place}
E → T              右部 1 个符号，属性: {place}
BF→!BF              右部 1 个符号，属性: {TC, FC}

你可能会想，状态栈和符号栈每次写入弹出的数量固定而且相等，但是属性栈因为属性的数量不同，而做不到

但在归约的时候，我们可以根据switch(ruleNo)来写死弹出操作
```
switch (ruleNo) {
      case 1:  // E → E + T
          // 我早就知道要弹 3 个：T.place, +, E.place
          v2 = valStack.top(); valStack.pop();   // T.place  (string)
                 valStack.top(); valStack.pop();   // +        (跳过不用)
          v0 = valStack.top(); valStack.pop();   // E.place  (string)
          newVal = v0 + v2 + "+";
          valStack.push(newVal);                 // 压回 string
          break;

      case 4:  // BF → i
          // 我早就知道要弹 1 个：i.name
          v0 = valStack.top(); valStack.pop();   // 变量名  (string)
          BoolAttr attr;
          attr.TC = NextStat;
          attr.FC = NextStat + 1;
          Gen(J!=, v0, _, 0); NextStat++;
          Gen(J, _, _, 0);   NextStat++;
          valStack.push(attr);                   // 压回 BoolAttr（不是 string!）
          break;

      case 5:  // BF->!BF
          // 我早就知道要弹 1 个：BF 的 BoolAttr
          v0 = valStack.top(); valStack.pop();   // BoolAttr {TC, FC}
          BoolAttr attr;
          attr.TC = v0.FC;    // 交换
          attr.FC = v0.TC;
          valStack.push(attr);                   // 压回 BoolAttr
          break;
  }
```
这样就成功获得属性了，而且case里面就是[[属性文法]]。
