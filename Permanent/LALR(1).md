# LALR(1) 文法

**LALR(1)**（Lookahead LR(1)）是介于 [[SLR(1)]] 和 [[LR(1)]] 之间的[[语法分析]]方法，通过**合并 LR(1) 项目集中的同心项**来减小分析表规模，同时保持对大多数实际程序设计语言的覆盖能力。一种[[语法分析]]中[[自底向上的语法分析]]的方法
## 核心思想
- 先构造完整的 LR(1) 项目集族
- 找出**同心项集**：两个 LR(1) 项目集如果忽略前瞻符后完全相同，则合并
- 合并后可能产生新的归约/归约冲突（但不会引入移进/归约冲突）
- 合并后的分析表状态数与 SLR(1) 相当，但文法识别能力接近 LR(1)

# 核心概念

## [[同心集]]

**核心** = LR(1) 项目去掉前瞻符后的部分。

两个 LR(1) 状态是**同心**的，当它们包含的项目**核心完全相同**（仅前瞻符不同）。

```
I₂  = { [A → (·A), $],   [A → ·(A), )],  [A → ·a, )]  }
I₇  = { [A → (·A), )],   [A → ·(A), )],  [A → ·a, )]  }

去掉前瞻符：
I₂ 的核心 = {A → (·A), A → ·(A), A → ·a}
I₇ 的核心 = {A → (·A), A → ·(A), A → ·a}

两者核心完全相同 → 同心集 → 可以合并！
```
