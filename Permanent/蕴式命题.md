# 蕴式命题

**蕴式命题**是形如「若 $P$，则 $Q$」的命题，记作 $P\Rightarrow Q$。它只在 $P$ 为真且 $Q$ 为假时为假，其余情况为真。

- $P$：前件，即假设。
- $Q$：后件，即结论。
- $\Rightarrow$：蕴含。
- $\neg$：否定。

| 与原命题的关系 | 形式 |
| --- | --- |
| 原命题 | $P\Rightarrow Q$ |
| 逆命题 | $Q\Rightarrow P$ |
| 否命题 | $\neg P\Rightarrow\neg Q$ |
| 逆否命题 | $\neg Q\Rightarrow\neg P$ |
| 原命题的否定 | $P\land\neg Q$ |

逆否命题与原命题等价。原命题的否定要求前件成立、后件不成立，其中 $\land$ 表示「且」。

当 $P\Rightarrow Q$ 成立时，前件是后件的[[充分条件]]，后件是前件的[[必要条件]]。如果写的是[[全称命题]] $\forall x\in D,\ (P(x)\Rightarrow Q(x))$，反例必须是 $D$ 中满足 $P(x)$ 且不满足 $Q(x)$ 的对象。
