# 问题

假设有两个字符串
- A B C B D A B
- B D C A B A
寻找在两个字符串中都出现的，最长的字符序列
如：
- B C B A
- B D A B

# 问题思路构建

## 思考决策，子问题构建

对于两个字符序列A\[ i ]和B\[ j ]
dp\[ i ]\[ j ]则表示序列A前 i 个字符和序列B前 j 个字符的最长公共子序列

## 找出最优子结构

对于每一次的比较A\[ i ]和B\[ j ]时，我们可以根据是否相等，分为两种情况：
- 不相等，此时的最大值为dp\[ i - 1 ]\[ j ]或者dp\[ i ]\[ j-1 ]
- 相等，此时的最大值为dp\[ i - 1 ]\[ j - 1 ]+1（看左上是因为要消耗掉i和j）

得到的状态转移方程为：
$$
dp[i]!=dp[j],dp[ i ][ j ]=max(dp[ i - 1 ][ j ],dp[ i ][ j-1 ])
$$
$$
dp[i]=dp[j],dp[ i ][ j ]=dp[ i - 1 ][ j - 1 ]+1
$$


## 确定边界条件和状态转移顺序

### 边界条件

显然，dp\[0]\[j]=0, dp\[i]\[0]=0


### 状态转移顺序

正常双层遍历


### 子序列获取

从答案回溯即可
对于每一次的比较A\[ i ]和B\[ j ]时，我们可以根据是否相等，分为两种情况：
- 不相等，比较dp\[ i - 1 ]\[ j ]和dp\[ i ]\[ j-1 ]，谁大就移动到谁那，如果两者相等，说明有多个答案子序列
- 相等，将字符放入子序列末位，移动到dp\[ i - 1 ]\[ j - 1 ]

# 算法实现

```
vector LCS(string A,string B){
	//初始化dp表
	vector<vector<int>> dp(A.size()+1, vector<int>(B.size()+1, 0));
	//遍历A字符串
	for(int i=1;i<A.size();i++)
	{
		//遍历B字符串
		for(int j=1;j<B.size();j++)
		{
			//字符不等，找上下的最大值
			if(A[i-1]!=B[j-1])
			{
				dp[i][j]=max(dp[i-1][j],dp[i][j-1]);
			}
			//字符相等，找左上角
			else if(A[i]==B[j])
			{
				dp[i][j]=dp[i-1][j-1]+1;
			}
		}
	}
	return dp;
}
```
