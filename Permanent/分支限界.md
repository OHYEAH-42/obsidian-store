# 核心

**分支限界**（Branch and Bound）是一种用于求解**组合优化问题**（通常是离散最优化）的算法范式。它通过系统地枚举状态空间树（分支），并利用**代价下界/上界**剪掉不可能产生最优解的分支（限界），从而找到全局最优解。

分支限界 = **[[广度优先搜索]]（BFS/优先搜索）** + **[[剪枝]]函数**

# 三种搜索策略

| 策略                           | 活结点表结构 | 特点           |
| ---------------------------- | ------ | ------------ |
| **FIFO**先进先出分支限界法            | 队列     | 按层扩展，先广后深    |
| **FILO (D-Search)**先进后出分支限界法 | 栈      | 类似回溯，但用显式栈   |
| **LC (Least Cost)**最小成本分支限界法 | 优先队列   | 按代价函数最小的优先扩展 |

# 基本框架

分支限界算法围绕三种基本要素：**解空间的树形表示、剪枝操作、成本函数（定义节点的优先级，即分支优先策略）**

基本步骤按照以上三种基本要素构造：
- 解向量及搜索空间（解空间树T）
	求解问题转化为在树T中搜索解对应的树节点
- 定义剪枝操作
	考虑约束条件和目标价至优化两方面
- 定义结点成本函数
	决定分支节点的优先级

```
/* 分支限界框架 */
  void branchAndBound() {
      // 活结点表（优先队列/队列/栈，取决于搜索策略）
      priority_queue<Node> liveNodes;

      // 初始化根结点
      liveNodes.push(根结点);

      while (!liveNodes.empty()) {
          // 取出最有希望的活结点（LC策略取最小代价）
          Node node = liveNodes.top();
          liveNodes.pop();

          // 判断是否为解（到达叶子结点）
          if (isSolution(node)) {
              recordSolution(node);
              // 更新当前最优解的界值
              updateBestValue(node);
              continue;
          }

          // 分支：扩展当前结点的所有子结点
          for (auto child : node.expand()) {
              // 约束剪枝：判断子结点是否可行
              if (!isFeasible(child)) {
                  continue;  // 丢弃
              }

              // 最优性剪枝：计算子结点的代价/上界
              if (bound(child) <= bestValue) {
                  continue;  // 不可能更优，丢弃
              }

              // 将可行的子结点加入活结点表
              liveNodes.push(child);
          }
      }
  }
```
