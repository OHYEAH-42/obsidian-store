有界缓冲区，生产者放数据，消费者取数据。

```
semaphore mutex = 1;      // 互斥信号量，保护缓冲区
semaphore empty = n;      // 空闲缓冲区数量
semaphore full = 0;       // 已满缓冲区数量

// 生产者
Producer() {
  while (true) {
    produce_item();       // 生产一个数据项
    P(empty);             // 申请一个空闲缓冲区
    P(mutex);             // 进入临界区
      put_item();        // 将数据放入缓冲区
    V(mutex);             // 退出临界区
    V(full);              // 增加满缓冲区数量
  }
}

// 消费者
Consumer() {
  while (true) {
    P(full);              // 申请一个满缓冲区
    P(mutex);             // 进入临界区
      get_item();        // 从缓冲区取出数据
    V(mutex);             // 退出临界区
    V(empty);             // 增加空闲缓冲区数量
    consume_item();       // 消费数据
  }
}
```

> [!warning] 注意
> P 操作的顺序**不能交换**。若 `P(mutex)` 在前 `P(empty)` 在后，当缓冲区满时生产者会持有 mutex 并阻塞在 empty 上，消费者无法进入临界区消费，导致**死锁**。在多生产者-多消费者场景下，这个问题更加复杂，还可能引发**饥饿**问题。
