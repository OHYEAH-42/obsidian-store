# 函数的概念与特性

[[函数]]用确定的对应关系，把[[定义域]]中的每一个输入变成唯一的输出。读 $y=f(x)$ 时，$x$ 是[[自变量]]，$y$ 是[[因变量]]，实际能取到的全部 $y$ 组成[[值域]]。

## 概念之间的关系

| 概念 | 要回答的问题 |
| --- | --- |
| [[自变量]] | 输入是什么，可以在哪个范围内取值？ |
| [[因变量]] | 每个输入对应的输出是什么？ |
| [[定义域]] | 哪些输入属于这个函数？ |
| [[值域]] | 在给定定义域和对应规则下，哪些输出能实际取到？ |
| [[单值函数]] | 每个输入是否恰好对应一个输出？ |
| [[多值函数]] | 是否有某个输入对应多个可能的值？ |
| [[复合函数]] | 把一个函数的输出作为另一个函数的输入时，哪些输入能完成两步运算？ |
| [[隐函数]] | 在选定范围内，方程能否为每个 $x$ 确定唯一的 $y$？ |

在一元实函数的学习中，确定一个函数需要给出定义域和对应规则。陪域约定输出所属的集合，值域则由定义域和规则确定。例如 $f(x)=x^2$ 在实数集上的值域为 $[0,+\infty)$，限制到 $[-1,1]$ 后，值域变成 $[0,1]$。[OpenStax《Review of Functions》](https://openstax.org/books/calculus-volume-1/pages/1-1-review-of-functions)

## 函数的四种特性

| 特性 | 判断方法 | 以 $f(x)=\sin x$ 为例 |
| --- | --- | --- |
| [[函数的有界性]] | 在考察范围内，能否用两条水平线夹住整段图像？ | $-1\le\sin x\le 1$，在实数集上有界。 |
| [[函数的单调性]] | 在指定区间任取 $x_1<x_2$，比较两个函数值。 | 在 $[-\pi/2,\pi/2]$ 上严格递增，在整个实数集上不单调。 |
| 奇偶性 | 先查定义域是否关于原点对称，再查 $f(-x)=f(x)$（[[偶函数]]）或 $f(-x)=-f(x)$（[[奇函数]]）。 | $\sin(-x)=-\sin x$，图像关于原点对称。 |
| [[函数的周期性]] | 沿 $x$ 轴平移固定距离后，整幅图像能否与原图重合？ | $\sin(x+2\pi)=\sin x$，最小正周期为 $2\pi$。 |

![[正弦函数的四种特性.png|720]]

图中两条水平虚线给出上下界，绿色曲线标出一个严格递增区间。两个橙色点的横、纵坐标分别互为相反数，显示出原点对称。两个相邻波峰的横向距离是一整个周期。

有界性和单调性都要说明考察范围。判断奇偶性时，如果定义域不关于原点对称，函数就既非奇函数也非偶函数。即使定义域对称，也要检验函数值，例如 $f(x)=x+1$ 在 $\mathbb R$ 上既非奇也非偶。

## 与反函数的联系

讨论[[反函数]]时，检查每个输出是否只对应一个输入，并留意限制定义域的作用。正弦函数在 $[-\pi/2,\pi/2]$ 上严格递增，每个输出都只对应这个区间内的一个输入，因此可以在这一支上定义[[反三角函数|反正弦函数]]。
