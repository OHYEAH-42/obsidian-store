# 三角函数公式

从式子里角的关系和运算形式出发，选用对应的[[三角函数]]公式。

| 看到的式子 | 可用的公式 |
| --- | --- |
| 同一个角的正弦、余弦、正切需要互换 | [[同角三角函数基本关系]] |
| 角可写成 $\frac{k\pi}{2}\pm\alpha$ | [[诱导公式]] |
| 正弦、余弦或正切的角是 $\alpha\pm\beta$ | [[两角和差公式]] |
| 角是 $2\alpha$，或出现 $2\sin\alpha\cos\alpha$ | [[二倍角公式]] |
| 角是 $\frac{\alpha}{2}$，或要化简 $\sin^2\alpha$、$\cos^2\alpha$ | [[半角与降幂公式]] |
| 同角正弦、余弦的线性组合 $a\sin x+b\cos x$ | [[辅助角公式]] |
| 两个三角函数相乘，需要拆成和或差 | [[积化和差]] |
| 同名三角函数相加或相减，需要提取公因式 | [[和差化积]] |

两角和差公式取两角相同，可得到二倍角公式。移项即可把余弦二倍角公式改写为降幂公式，再把角换成半角可得到半角公式。积化和差与和差化积可以通过换元相互改写。[OpenStax《Trigonometric Identities》](https://openstax.org/books/algebra-and-trigonometry-2e/pages/9-key-equations)
