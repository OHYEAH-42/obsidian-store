## 一、正则表达式(Regular Expression)：


### 作用：
正则表达式主要用于处理字符串，最常见的三个场景是：

匹配（Validation）： 检查一段文本是否符合规则（例如：检查用户输入的手机号是不是 11 位数字）。

提取（Extraction）： 从大段文字中找出你想要的信息（例如：从网页代码中提取出所有的图片链接）。

替换（Replacement）： 把文本中符合某种模式的部分换成别的（例如：把所有的空格换成下划线）。 
### 语法：

量词的语法：

？：表示匹配前面字符0次或者1次（可选）
 例如： apple？  会匹配 appl 或者 apple
 
\*: 表示匹配前面的字符0次或者多次（可选）
  例如： ab*c    会匹配 ac 或者 abc 或者 abbbbbbbbbbbbbc 

 \+ : 表示匹配前面的字符一次及以上
  例如：  ab+c  会匹配  abc 或者 abbbbc

 {n}: 表示匹配前面的字符正好n次
 例如： ab{6}c   会匹配 abbbbbbc

 {n，}： 表示匹配至少n次

 {n，m}： 表示匹配从n到m次


分组与选择:

()：表示匹配（）内的位一个整体，比如  a（bc）{3}会匹配 abcbcbc

 | ： 表示或，比如  cat|dog 会匹配 cat 或者 doh 

\\: 表示转义符，比如要搜索？ 就要写成、？

基础字符匹配：

\. : 点号会匹配除了换行符以外的所有字符

\d: 匹配一个数字，及等价于\[0-9]

\D: 匹配一个非数字

\w: 匹配字母，数字或者下划线（单词字符）\W:匹配一个非单词字符

\s : 匹配任意空白符（空格，制表符等等）
\S : 匹配一个非空吧kk
\[abc]: 字符匹配，匹配括号内的任意一个字符
      例如：\[a-zA-Z]  表示匹配所有26位字母且大小写

\[^abc]: 表示非，这里表示匹配除了abc以外的任意字符

\^: 只会匹配行首
    例如 \^a  会匹配行首的a

\$: 只会匹配行尾
	例如\$a  会匹配行尾的a



## 二、有限自动机(DFA/NFA)


### 定义：

有限自动机是一个抽象的数学模型，用于识别这一组字符串。
一个完整的FA包含五个要素：
- **$S$ (States)**：有限的状态集合。
    
- **$\Sigma$ (Alphabet)**：输入字符的集合（字母表）。
    
- **$s_0$**：唯一的初始状态。
    
- **$F$ (Final/Accepting States)**：接收状态集合（双圈表示）。
    
- **$\delta(s, c)$**：转移函数（在状态 $s$ 看到字符 $c$ 后跳转到哪个新状态）。

自动机的结构可以形式化地看作是一张有向图，称之为**状态图**
举个例子，完成「判断一个二进制数是不是偶数」的自动机如下：
![[Pasted image 20260414225024.png]]

NFA vs DFA

| 特性            | NFA(非确定性有限自动机)   | DFA(确定性有限自动机) |
| ------------- | ---------------- | ------------- |
| 转移唯一性         | 同一个字符可能有多个去向     | 同一个字符有且只有一个去向 |
| $\epsilon$ 转移 | 支持(不需要读字符也能跳转)   | 不支持           |
| 直观程度          | 更接近正则表达式，容易构造    | 复杂，难以手画       |
| 运行效率          | 曼                | 快             |
| 关系            | 每一个NFA都有一个等价的DFA | DFA是NFA的特殊形式  |

### NFA to DFA

- $\epsilon$闭包的概念：（我自己的话来说）在状态机中，从一个状态，到达某个状态(该状态之后没有ε的路径)，这个过程中不消耗任何输入(全为ε)，称之为一个ε闭包.

![[Pasted image 20260414232026.png]]

比如该图中，B到C，B到D都为一个ε，称之为：
- ε-closure(B)={B，C，D}
再比如，从G开始，到A，B，C，D，G，H，I都为ε，记作：
- ε-closure(G)={A，B，C，D，G，H，I}



> [!NOTE] 非确定性有限自动机的状态数量，以及有限
> 假设某个NFA有n个状态，那么它进入S(最终态)的子集的大小，最大为N
> 则不同子集的数量为$2^N$-1,可以看到它非常大，但是它有限

### DFA化简

化简方法：我们先将状态分为两组，非终态组G1和终态组G2，当两个状态的相同输入，跳转到相同组别时，则这两个状态可以化简为同一个状态

Ex：
ABCD四个状态，D为终态

| 状态  | 0   | 1   |
| --- | --- | --- |
| A   | B   | C   |
| B   | A   | C   |
| C   | C   | D   |
| D   | A   | B   |
则ABC可以分为G1组，D为G2组
ABC输入0都到G1组（G1->G1）
AB输入0到G1组(G1->G1)
C输入到G2组(G1->G2)
D输入01都到G1组(G2->G1)
由此可以看到AB是相同组，
C不同于ABC，可以分为G3
D为一组，故AB可以化简
